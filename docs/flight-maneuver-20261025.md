# 飞行机动性与对空（3.0.14，2026-10-25）

新战斗使用 V35。飞行等级代表空中机动性，飞行防御与对空攻击使用同一张表：L1–L10 为 3、4、5、6、7、8、9、11、13、15。

- 空中单位受到地面攻击时获得对应飞行防御；对空攻击增加同等级数值，正常攻击减防御自然相抵。原对空固定攻击加成由新表替换，不重复叠加。
- 对空伤害倍率与地对空额外射程成本保留原成长。空对空不额外增加飞行防御，落地或失去飞行来源后不再增加防御。
- `buff+飞行L7` 保留独立的飞行等级，实际授予临时来源；地面单位得到能力后仍需起飞，升空后提供 L7 防御。保存恢复保留等级与期限。
- V34 及以前的战斗继续使用保存的规则和原对空加成，不自动获得飞行防御。

共享攻防计算只增加飞行等级读取和查表；对空沿用原特质修正管线。没有新增等级差分支、寻路或候选枚举。`hold` 的警戒评估至多检查三个已观测、能够接近射界的对手，最多新增每名对手一次候选伤害预览。

## 正文格式核对

- 技能 `buff+潜伏L3+林地专精L5+防御L2` 可保留各附加效果独立等级；其中防御是技能效果。
- 佩戴 `潜伏L3+林地专精L5+2防御` 现已支持，分别保留 L3 与 L5，属性修正按最高 L5 换算；交换两项等级不改变属性修正。`防御L2` 仍是技能效果等级，不能当作 +2 点佩戴修正。
- 没有把点数修正解释成技能等级。新增的佩戴分项等级解析只用于建档和编辑，不增加战斗内计算。
