# 战斗终章：道具使用和效果

2026-10-16。终章在伤害来源之后增加最后一个事实段落「道具使用和效果」，并在实际发送终章时要求叙述最后交代本场道具的使用与实际效果。自定义结算提示仍保留；收兵后发送归档终章也带上这项要求。

每次成功使用一次性或充能道具时记录使用者、道具身份、实际消耗件数和本次结算效果。一次性道具区分使用次数与编队齐用的总件数；充能道具只记次数，说明不消耗道具本体。小战沿用该次行动的效果记录，会战在各项延后效果执行时分别收集，避免把同阶段其他技能的效果归到该道具名下。治疗、伤害、屏障、状态、回能及其他已有结算结果随战斗快照和归档终章保存。

终章汇总按使用者和道具的稳定 ID 区分，保留使用时的名称。未使用、未执行成功的道具与佩戴道具的被动效果不列为主动使用。旧战斗没有新记录时，仅从原有次数、携行余量和明确署名的日志补充可核实的信息；缺失的消耗数量或效果注明未记录，不从道具规格或战后状态补造结果。

验证覆盖小战与会战的实际用药件数、有效治疗量、屏障总容量、充能回能、攻击结算、快照恢复、归档重发、无道具与失败使用、旧记录回退，以及终章按钮在自定义提示下实际带出的内容。
