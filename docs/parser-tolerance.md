# 正文规格兼容

正文入口先规范写法，再使用现有机制和数值校验。内置世界书、战斗公式、手工表单和存档校验不变。

- 支持规格中的全角数字/正负号、空格、`Lv.5` / `level 5`、等级或修正外的括号、`伤害+3`，以及命中/精准、穿甲、持续时间等明确别名。
- 技能等级后的 `+击退` / `+恐惧` 归回机制组合。`+3击退` 保留击退机制，忽略没有对应引擎含义的独立加值并给出诊断；实际效果仍按技能等级计算。
- 防御、守护、屏障与加速等对应机制的防御/防护/速度修正转换为强度修正。不会把攻击技能上的不匹配防御修正换成伤害强度，也不会因此新增破防效果。
- 相同技能强化重复声明同一个值时合并，避免重复加成；冲突值不猜测。
- 新建单位和学习技能时，异常隔离到单条技能。未知可选强化可跳过并保留基础技能；完整性、等级或点数错误的技能跳过并留下诊断。
- `unit_set` 的技能/特质是替换列表：含无法识别条目时保留整个原列表，其他明确字段仍可更新。显式空列表仍表示清空。高级 `data` JSON 继续严格校验。
- 支持文字数组式技能/特质列表、常见字段别名、特质的加号或竖线分隔。诊断优先显示实际跳过/保留的内容。

单位身份冲突、不完整标签、非法生命值、装备等级及强化越界仍需修正。新建武器和物品的未知机制也不会按名字猜造。

验证：10 个相关测试文件、117 项通过；类型检查通过。包含生成/保存/重载、技能实际效果、旧列表保护和非法值拒绝。未运行全套浏览器冒烟。
