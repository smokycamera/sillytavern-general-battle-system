# 正文规格兼容

正文入口先规范写法，再使用现有机制和数值校验。强化别名与省略 `+1` 的写法共用引擎词表；战斗公式、数值范围、适用方向和存档数值校验沿用原规则。

- 支持规格中的全角数字/正负号、空格、`Lv.5` / `level 5`、等级或修正外的括号、`伤害+3`，以及命中/精准、破甲/穿甲、距离、持续时间等明确别名。
- `+1破甲`、`+1穿甲` 规范为 `+1穿透`，`+1距离` 规范为 `+1射程`。已知属性可省略正修正的点数：`+伤害+穿甲+距离` 等价于 `+1伤害+1穿透+1射程`；负修正仍须写出点数。
- 支持 `+1精度 伤害+3` 等混合顺序。`spawn.level` 内的全角符号、属性别名和省略 `+1` 同样规范化。
- 技能等级后的 `+击退` / `+恐惧` 归回机制组合。`+3击退` 保留击退机制，忽略没有对应引擎含义的独立加值并给出诊断；实际效果仍按技能等级计算。
- 防御、守护、屏障与加速等对应机制的防御/防护/速度修正转换为强度修正。不会把攻击技能上的不匹配防御修正换成伤害强度，也不会因此新增破防效果。
- 相同技能强化重复声明同一个值时合并，避免重复加成；冲突值不猜测。
- 新建单位和学习技能时，异常隔离到单条技能。未知可选强化可跳过并保留基础技能；完整性、等级或点数错误的技能跳过并留下诊断。
- `unit_set` 的技能/特质是替换列表：含无法识别条目时保留整个原列表，其他明确字段仍可更新。显式空列表仍表示清空。高级 `data` JSON 继续严格校验。
- 支持文字数组式技能/特质列表、常见字段别名、特质的加号或竖线分隔。诊断优先显示实际跳过/保留的内容。

单位身份冲突、不完整标签、非法生命值、装备等级及强化越界仍需修正。新建装备中写出等级的未知护甲机制会明确报错。`unit_set` 的空数值、隐式进制和非有限数值会被拒绝，不能把空值当作零。

## 自动短编号

单位为 `u1/u2/...`，武器为 `w1/w2/...`，护甲和盾牌共用 `a1/a2/...`；消耗品用 `c`，其他物品用 `i`，技能用 `k`，效果来源用 `s`，独立冷却组用 `g`。单位档案与库存界面显示公开编号。

编号与原存档身份的映射随聊天保存；排序、删除、重载均保留既有编号，删除后不复用编号。生成绑定冻结该次使用的映射，避免待处理回复更新到另一实例。内部身份、实例配方和历史引用继续稳定保存，旧真实身份与旧版哈希编号仍可读取。常见 `unit_id/item_id/equipment_id/source_id` 字段别名沿用相同识别；短编号支持大小写、全角字符和多余前导零。

提示注入、LLM准备请求和JEV战场引用使用公开编号；返回事件的 `id/source` 及 `unit_set.data` 内的技能、预备技能、冷却和效果来源引用在事务校验前还原。JEV候选使用请求内的 `o1/o2/...`，返回评分先还原再执行。机制定义、条件枚举、地图位置、名称和备注保留原含义。点名 `u10` 不会同时匹配 `u1`。

## 草稿恢复与错误位置

“识别可解析部分”根据当前输入逐字段恢复，保留整条单位事件、合法字段、可识别的技能／特质和合法修正，只删除错误部分。坏副武器不删除主武器；未知属性不阻断后续属性；物品品质和防护配置随可识别的规格保留。`unit_set.data` 逐键保留支持的内容。缺少必填值的单位仍留在草稿，供玩家补全，不把用于验证的临时默认值写进去。

该操作只更新本地草稿；点击“重新解析草稿”后核对结果并确认入账。其右侧的“查看错误位置”按文本顺序循环定位错误，选中相关字段或列表中的坏项，显示行号和原因；HTML 显示转义的标签仍对应原草稿位置。编辑或恢复草稿会重置跳转顺序。

## AI扫描与自动批准

队伍栏“添加单位”左侧新增“AI扫描”。确认框可填写附加要求，也可取消。扫描使用普通 LLM 副 API 的现有连接与最近正文层数设置，读取已完成的用户／AI 正文、当前档案及内置世界书格式和等级锚定，返回事件块；不在原聊天中插入事件，也不改写正文。提示词移除证据门槛措辞，保留规格及示例。取消、切换聊天或档案版本改变时不提交晚到的结果。

“自动批准”与旧剧情同步开关统一保存，允许全部13种受支持的战外事件：`field`、`spawn`、`deploy`、`unit_update`、`unit_set`、`learn`、`give`、`take`、`reforge`、`bless`、`affect`、`unbless`、`unaffect`。普通完整生成、玩家主动扫描和AI扫描均使用该设置，重复扫描不会重复入账。解析、身份、事实版本和存档事务校验继续适用。

## 占旗规则与战报

占旗和攻城任务连续控制满2个完整回合获胜，占领当轮不计，离开旗点重计。明确的占旗任务与旧进行中的占旗任务保留；界面可选择占旗战，普通野战默认仍为歼灭战。攻城只由攻方占领取胜，守方坚持至原期限获胜。

结束日志、结算卡、回合纪要、状态摘要、新增战况和终章明确说明占领取胜或守城成功。终章区分攻城战、守城战及占旗战；读档后的旧通用任务结束记录可根据战场快照显示真实胜负原因。停战／投降保留原结束原因。
