# 3.0.25 技能空档与连射预览修复

本地候选版本 3.0.25，新战斗规则 V40。修复不包含降低伤害、穿透上限、暴击或生命调整。平衡政策仅在[方案比较](balance-options-20261028.md)中试算，未写入正式公式。

## 技能相邻等级的实际变化

新生成配方在 V40 战斗中采用 `skills-v5`、`skill-v11.0` / `skill-zone-v8`：

| 机制 | 原来 | 新规则 |
| --- | --- | --- |
| 突进/后撤 | `2+floor(L/4)` 格 | L+1 格，即 2…11 格 |
| 闪现 | `1+floor(L/3)` 格 | L 格，即 1…10 格 |
| 净化/驱散 | L1–5 清1类，L6–10 清2类 | 最多清 L 类；同类各来源的清除语义不变 |
| 独立推/拉 | 射程 `2+floor(L/3)`，部分相邻级不变 | 投送射程 L+2；推力仍保留原阶梯、物理体量上限与坚韧抵抗，仍只推/拉1格 |
| 回能/耗能 | `1+ceil(L/3)` | `2+(L−1)/3`，2…5；保留资源上限和回能支付下限 |
| 授予不可分级特质 | 每4级多1轮 | 持续 L 轮；可分级特质仍按自身等级成长与原期限规则 |

位移不绕过路径、视线、定身、超载、借机、警戒或平台限制。会战继续按既有阵位距离换算，不能把小战多1格解释成会战必多走1个阵位。净化/驱散增加的是可解除种类上限，只有1类负面时不会制造多次收益；推力同样用于突破更强身体的阈值。这与穿透用于对抗更强防护的逻辑一致。

已将全部类别的合法单修饰词、范围变体及 L1–10 共 **5,040 次编译检查**重新跑过，所比较的效果、范围、实际精力报价、冷却及输出倍率没有相邻等级功能向量相同的情况。这个检查不代表每个技能在每种地图、免疫或资源已满情况下都会额外生效。

技能攻击精度改为每点 **1/3 判定值**；控制抵抗难度同步采用小数，并在临界骰面按小数概率结算。天然1/20和免疫继续有效。旧整数抵抗与随机数序列保持原逻辑。回能修正每点 **0.2**，士气修正不再提前整数取整。

这些是重新分配档位收益：原来 +1 精度已经提前得到完整 +1 判定，新规则 +1 为 +1/3、+2 为 +2/3、+3 为 +1；回能也从第一点提前取完整档改成连续兑现。不是对所有低点数配置单向加强。整格射程、整轮持续与充能次数仍有离散阈值，本次没有把每一点都变成额外1整轮硬控或额外1次道具。

## 连射预览

V40 对两三段、单体英雄之间且无盾、屏障、能量盾、附加通道、火炮弹种变化或不屈状态的稳定攻击，使用精确有限骰子分布：

1. 每段计入未命中、普通命中、暴击与随机整数取整。
2. 对各段伤害分布做卷积；目标倒下后停止，按剩余生命截断总损失。
3. 从总分布计算期望、方差、造成伤害概率、最大损失与至少命中一次后的平均损失。

不再用96个种子估算此类简单攻击。已复核 L1 步枪、能量武器的正负全部伤害点值在 D20/TW 下的预览单调性，并与12,000次独立完整连射结算比对。旧 V39 的同一案例仍为原抽样值，保证历史 AI 决策路径不受本次更改影响。

编队、可磨损的盾、屏障/能量盾、附加通道等复杂情况仍用96次抽样，仍是近似值；V40把每个攻击段、命中、伤害骰、展开取整和伤害取整分别固定为独立随机子流。配装修正使一次小数取整或命中抽样出现/消失时，不再错位后续的全部伤害骰。这只改预览采样，不改真实战斗随机源；V39保留原随机顺序。

已验证 D20/TW、有屏障及低剩余生命下 +0…+10 伤害/精度的预览单调性与输入只读。该方法减少比较噪声，不把复杂战况假称为精确期望，也不保证每个细小增量在96次估计中都显示不同数值。精确路径有生命、段数与骰子分布预算限制和有界缓存；不把一个预览结果强行取高来掩盖变化。

## 兼容与交付边界

- 只有新开的战斗由共享 UI/MCP 构造入口选择 V40。V39及更早快照继续读取保存 `rulesId`；不重写存档或历史开局。
- 已有普通生成技能按新战斗公式准备；定制、固定规格、道具授予及冻结主动道具保留各自数值，不重新编译。
- 剧情来源中的已冻结操作、已布置区域不重算。世界书、提示词及动态模板未修改。
- 本地构建不等于已发布 test/main；按正常渠道接受后再合入 test、验证并晋级 main。

关键实现：`engine/src/skill-model.ts`、`gen/generic-skills.ts`、`skill-upgrade.ts`、`skill-effects.ts`、`skill-movement.ts`、`zone-skills.ts`、`sequence-preview.ts`、`damage.ts`。针对性回归位于 `engine/tests/skill-progression-v40.test.ts` 与 `sequence-preview-v40.test.ts`。
