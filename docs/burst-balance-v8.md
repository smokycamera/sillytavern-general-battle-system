# V8 训练与单体武技增伤（v1.3.13）

桐人样例中的 `攻倍×7.431` 可由现有公式正常产生：L7 剑投影（含 +4 伤害和生成浮动）×1.70769、物理单体武技 ×2.2、L7 训练 ×1.72、近战特化 ×1.15。跨代额外倍率为 1。伤害骰 24 实际产生约178点伤害，目标只剩144生命，显示实际扣除144。英雄战报把生命损失再次显示为“减员144”是独立的界面问题，本版修复。

## 新战斗规则

| 项目 | V7 | V8 |
|---|---|---|
| 训练伤害倍率 | `1 + 0.12 × (T−1)` | `1 + 0.06 × (T−1)` |
| 自动生成的单体武器/盾牌技法基础倍率 | 2.2 | 1.5 |
| 命中、规避、人物生命、技能费用及冷却 | 原规则 | 保留 |
| 范围技能与独立法术的基础倍率 | 原规则 | 保留；直接伤害仍受新的训练倍率影响 |
| 穿透、防护、跨代额外倍率及编队余伤机制 | 原规则 | 保留 |

只在预览与实际攻击时替换自动生成武技的基础倍率。技能实例、正负强化、附加控制折扣、身份、精力和冷却账本不重写，因此重新读取或预览不会重复削减。明确自定义、固定威力技能保留其自定义倍率；训练输出按所在战斗规则计算。

新建战斗使用 `v8-overflow-d20` / `v8-overflow-tw`。已经进行中的 V2–V7 战斗保留原规则；开始一场新战斗即可使用调整，不需要重新创建人物或更新世界书。旧程序不认识 V8 战斗标记，回退程序时应使用升级前战斗存档，不能删改规则编号伪装旧档。

## 低中等级影响

| 人物训练等级 | 普攻、独立法术和范围攻击的伤害变化 | 自动生成单体武技的伤害变化 |
|---|---:|---:|
| L1 | 0% | −31.8% |
| L3 | −9.7% | −38.4% |
| L5 | −16.2% | −42.9% |
| L7 | −20.9% | −46.1% |
| L10 | −26.0% | −49.5% |

以上为未受剩余生命截断的伤害预算比例；最终整数伤害有概率取整。低级技能仍有高于普攻的伤害预算，但对厚甲低伤害目标，AI可能选择保留精力。

复现桐人样例时，同样的伤害骰24由约178降至96，144生命的佐助剩48。固定该配置，精确遍历8d6及概率取整，非暴击命中后的满血秒杀概率由96.1%降至6.1%。这不是整场胜率，也不保证暴击或重度强化不能秒杀。

## 验证与限制

- 139组候选数值对照：不同调整方式、L1/L3/L5/L7/L10、无甲至重甲、四种身体及正负强化。
- 120场完整小战对照：5个等级、轻/重甲、普攻/武技/法术、2个种子、V7/V8；全部结束。轻甲样本通常仍在约1–4轮内结束。
- 对重甲明显变慢的情况追加64场定向对照：L3/L5、剑/钝器、8个种子、V7/V8。L3剑对重甲平均4.63→8.50轮，L5为4.00→7.88轮；钝器分别为1.63→2.63、1.63→2.50轮。全部结束，破甲武器仍具优势。小样本不代表所有阵容的平均回合数。
- 35项重点回归通过，TypeScript类型检查与35文件安装包一致性核验通过。重点回归覆盖原战报复现、预览/执行一致、正负技能强化、控制折扣、四类身体、旧/新小战与会战快照恢复、编队溢出、面板技能选择及回合推进。
- `unified-replay.test.ts` 有3项既存失败：V5 human-four T1 步数59（夹具56）；V6 giant-four T6 回合32（夹具31）；V6 giant-unbreakable T1 回合22（夹具47）。未修改的主分支源码同样失败且数值一致，本次没有改写夹具来隐藏失败。

主要代价是同级剑对重甲战斗明显延长；高等级暴击、强强化与跨代优势仍可能秒杀。本版没有用统一伤害上限抹掉这些区别。

复现对局采样：`npx vite-node scripts/check-burst-pacing.ts`（120场），追加 `--heavy`（64场重甲检查）。这些脚本不加入自动CI。
