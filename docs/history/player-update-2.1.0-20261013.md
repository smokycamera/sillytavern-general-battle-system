# 通用战斗系统 2.1.0 更新公告

- **道具系统更新**：支持一次性、充能和佩戴道具，单位出场可直接携带。
- **治疗更省药**：纯治疗道具按编队实际伤量使用，只缺 1 点血时只消耗 1 件。
- **护盾按总量计算**：本次使用几张，就获得几张的护盾容量，全队共用。
- **技能位移补全**：支持突进、闪现和后撤，修复部分编队使用时卡住的问题。
- **特质与专精更新**：补充侦察、医护、对空等特质，五项地形专精支持 L1—L10。
- **战斗操作更流畅**：优化骑兵行动、地图点选和护盾伤害预览。
- **目标选择更稳定**：修复点选目标丢失，换装减少确认步骤。
- **界面更简洁**：精简重复说明，详细公式和规则可按需展开。
- **正文识别更宽容**：改善事件标签、属性和装备技能规格的识别。
- **道具交付更方便**：支持向指定单位交付，新增单位可直接登记随身物品。
- **档案与自动批准修复**：改善重进聊天后的档案读取和自动批准状态。
- **手机显示与世界书更新**：修复飞行标记裁切，更新内置规则和武器分类说明。

护盾示例：100 人编队使用 50 张 L3 屏障卷轴，获得 1150 点护盾；使用 100 张获得 2300 点，均持续 3 轮。重复施放取较强保护。

AI 扫描使用内置世界书；保存过的自定义修改会继续保留，可在设置中恢复新版默认文本。
