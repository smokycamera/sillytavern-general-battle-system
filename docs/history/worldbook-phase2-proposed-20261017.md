## 3. buff特质拟替换

```text
skills="汲血术:buff+吸血L3"
skills="复合术:buff+特质吸血+偷袭L3"
skills="护体术:buff+守护L8"
```

技能power、授予特质L和期限分开保存。新输入有效授予L等于技能规格L（省略为L1），不再乘第二次等级。组合技能只有一个末尾L，所有组成效果同级，规范化后去重；多个L混写明确提示拆分技能。

新授予特质的默认期限为1+floor((L−1)/4)：L1–4为1轮，L5–8为2轮，L9–10为3轮。单目标2+Σw SP，范围3+Σw SP；分级特质w=max(1,ceil(佩戴成本(L)/3))，其余沿已有权重，不再截为6SP。范围默认最多3个目标。短高长低来源独立到期，普通正面状态也不把最高强度和最长期限拼成一个来源。按状态种类驱散时明确一次移除此类全部来源。

### 3.1 佩戴品总点数限制取消（2026-10-17 用户修正）

佩戴品不再要求全部特质与修正的合计点数小于等于道具L；建档、正文解析、装备表单、导入与读档不因总点数拒绝或自动削弱效果。道具L继续表达规格，各效果自身等级、适用前提、来源撤销与同组取强照常生效。特质效果权重仍可用于临时buff的SP计价，不作为佩戴品总容量上限。已有冻结装备参数保留，不反推恢复历史曾被裁剪掉的数值。

## 4. 守护拟统一

本体与技能临时守护使用同一阶梯：5% / 10% / 15% / 20% / 25% / 30% / 35% / 40% / 42.5% / 45%。当前有效守护L同时作为防御规格进入跨代防护，与其他合法规格取强；不生成HP、不变成实物护甲、不提高通道抗穿。屏障仍是有容量、可耗尽的吸收层。

旧祝福状态保留其实际减伤、defensePower和期限，并标记旧版效果，与新版守护按减伤组和防御规格分别取强。原始“祝福”状态不因中文名称被猜成新版守护。

## 5. 治疗跨代拟补充

```text
P = 治疗技能 / 道具 / 区域的可信冻结规格，或本周期最高有效再生L
T = 被治疗单位level（再生取自身level）
P <= T+1：M=1
P > T+1：M=sqrt(A(P)/A(T+1))
名义恢复 = 基础预算 × 合法处理规模 × 医护倍率 × M
```

A使用现有规格锚点。护甲、守护、盾牌、身体、人数和治疗者level不参与P/T比较；身体/人数只保留已有处理规模和恢复容量。缺可信P的历史自定义效果按M=1。量与倍率保留精度，兑现时统一取整并受真实伤口/可救伤兵容量限制；不复活永久死亡、不凭空补员、不把溢出治疗变成护盾。

主动治疗、治疗品、治疗区域和明确的区域载荷共用预算解析器。区域冻结施放时医护倍率，每目标结算时读取其level，不额外乘施术编队人数。药品按跨代后的每件预算估算剂量，扣费和治疗一致。再生不乘施放医护，吸血不再次乘治疗跨代。战后恢复、回精力、直接设HP和屏障保留原规则。

## 6. P2新增十八类分级说明拟补充

下列L5说明来自与执行器相同的参数源；完整十级实际差异见[逐级差异矩阵](../traits-phase2-level-witnesses-20261016.md)。

- **医护**：L5：施放治疗×1.25，自身编队新伤亡可救75%；不重算过去永久伤亡，不抬高治疗规格
- **淬毒**：L5：合法动能攻击造成真实损伤后施加普通毒，基础毒伤×1，冻结效力与波及人数，结算3次；存续时不叠层、不续期、不替换，攻击降低1

- **工事**：L5：在据守位置防御+3、远程伤害减免30%；离开失效，工兵仅削减此来源
- **拒马**：L5：对机动目标攻击+2、伤害×1.25，正面固守时抗合法冲锋减伤50%
- **散兵**：L5：疏散时未被近敌牵制的范围伤害减免50%，溅射暴露剩余50%；编队近战展开×0.5、近战防御−1；可在正常激活开始选择疏散/收拢，额外动作不切换
- **游击**：L5：合法轻中装先攻+2、机动+1，脱离近敌时远程减伤25%
- **坚韧**：L5：控制抵抗+4，完全阻挡推拉，不免疫已经施加的失能
- **身法**：L5：合法地形额外成本剩余0%，脱离近战免借机触发；先攻+0、机动+0；会战困难地形行军使用同一成本，不跨墙/深水资格
- **工兵**：L5：结构伤害×1.5，攻击时削减目标工事提供的防御/远程减伤100%，不削真实护甲、盾牌或结构本体
- **近战特化**：L5：近战武器与物理技法攻击+2、伤害×1.15，独立魔法不生效
- **射击专家**：L5：全合法射击攻击+2
- **冲锋强化**：L5：任何合法冲锋攻击+3，合法冲锋伤害×1，不授予穿障碍资格
- **狂暴**：L5：固定防御−1；所有攻击+2，合法攻击伤害×1，不影响治疗、毒DOT或士气
- **对空**：L5：对空攻击+2、伤害×1.25；地对空额外射程成本小战0格/会战0阵位，不授予新投送方式
- **潜伏**：L5：潜伏规格L5参与确定性侦察对抗；仍需合法隐蔽条件，攻击/施法/近敌接触照常暴露，不穿墙或空间移动
- **侦察**：L5：侦察规格L5参与确定性反隐，真实可见目标曲射校射攻击+2，多来源取强；不提供额外夜视或穿墙，致盲时不反隐/校射

会战困难地形使用与小战同域的成本减免，进入实际行军疲劳；地形专精与身法各求合法成本后取低，不叠乘。散兵提供正常激活开始的疏散/收拢选择并锁定到下次正常激活，额外动作和受击预览不切换。侦察/潜伏只做确定性等级差比较，硬视线、烟幕、夜视和致盲优先。
