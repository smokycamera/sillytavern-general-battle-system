# 小战自动部署与随机扰动

仅优化新规则小战的自动选位。仍使用原有双方部署区和先锋前出范围，不改变会战阵位系统，不添加额外部署操作。

- 近战优先前排，常规远程优先后排，射程较短的远程优先中排。先锋优先使用合法的前出区域。
- 合法的明确位置最先保留，大型/载具优先预留完整格子，普通单位随后展开；有空位时减少同格挤占，满容量时仍允许合法共格。
- 选位兼顾掩体、困难地形、绕墙走出部署区的代价与同层友军拥挤程度。
- 远程观察前方公开格子的射界，复用实际友军遮挡规则：枪炮寻找射角，弓弩/法杖可越过友军，大体型可越过较小友军；墙体照常阻挡。曲射武器不按直射射界挑位。选位不读取隐藏敌军的位置，也不保证开局已有敌人在射程内。
- 大型远程预留整格后，根据完成部署的前排站位重新评估一次射界；明确位置不参与调整。

扰动采用独立的 `deployment-v1` 种子，并按战斗种子、单位 ID 和格子分别派生。格子扰动幅度为 0–1.5 分，常规离开优先排的代价为每排 5 分；强射界差异和拥挤等因素仍可影响排位。随机变化主要发生在质量相近的合法位置之间，不是完全随机落点。

同一战斗种子和名单可复现结果，不依赖名单数组的顺序；部署不消费先攻、命中和伤害使用的战斗随机源。生成室内地图预留位置时使用同一战斗种子。已开始战斗直接恢复保存的位置，重复开始或读档不重新洗牌。

部署先在副本上完成验证，容量不足或指定位置非法时整批拒绝，原始名单不被部分改写。测试覆盖固定种子/不同种子、前后排与分散、真实友军遮挡、墙体与掩体、混合体型满容量、先锋、室内名单、读档和战斗随机源独立性。
