## 单位与装备修正

以下采用用户原文，仅补标准 Markdown 表格分隔行：

```markdown
## 修正（可选）

- 修正为可选，代表特性或低于高于平均值的程度与缺陷或特化，取值范围-10到+10。
- 格式为“L等级±点数方向”，可连续写多个方向；每个方向取-10至+10整数
- 单位修正写在level中，如level="1+3精度+2生命"；装备、技能和道具写在各自规格后，如“穿甲重型精密突击步枪:步枪L5+6精度+4穿透+4重量”
- 同级修正不能替代技术跨代

| 对象 | 可用方向 |
| --- | --- |
| 单位 | 强度、伤害、精度、防御、生命、速度、士气、单通道伤害 |
| 武器 | 强度、伤害、精度、防御、穿透、射程、重量、单通道伤害、单通道穿透 |
| 护甲 | 强度、防御、防护、速度、士气、重量、单通道防护 |
| 盾 | 强度、防御、防护、士气、重量、单通道防护 |

- 单通道选动能、热能、奥术，如+5热能防护-3奥术防护。防御为闪避格挡，防护为抗穿；强度影响整体效果。
- 示例：weapon="精密步枪:步枪L5+6精度+4伤害"；armor="护卫甲:重甲L5+10防护"；armor="轻量化重型防弹衣：重甲L4-5重量-3防护"。
```
