# 3.0.18 技能目标与范围支援复核

## 最终行为

- V38环形以选定目标为中心，并包含主目标及同格、周边合法单位，保留原半径与最大目标数。该规则用于近战、法术及独立投射的环形；主目标仍须满足技能和实际武器的射程、感知与接触要求。
- 所有带几何的范围在目标数上限前优先保留合法主目标。V37及以前的环形、排序与快照继续按原规则读取。
- 范围支援可以把不需要当前效果的友军用作落点。例如中心友军满血时治疗周围伤员，中心已有防御增益时给周围友军施加增益，中心没有负面状态时净化周围单位。
- 选定中心仍检查阵营、存活状态、射程、视线、武器和控制约束；实际接受效果的单位仍逐个检查效果适用性与范围几何。无有效接受者时，在扣费前拒绝。
- 范围治疗按既有生命恢复规则处理濒死友军与合法起身位置，不能将阵亡者列为受益目标。旧式仅有burst的范围技能也使用对应资格检查。
- 范围buff已有真实条件与特质来源结算；本次补全中心选择与逐单位预览，覆盖攻击、防御、通道伤害、屏障、净化、回能和临时能力。持续期、同类叠加与驱散沿用既有规则。
- 原地释放的技能在扣费前锁定接受者，避免扣除精力后把原本无需支援的施术者加入混合屏障/回能的目标集合；带位移的技能继续在实际到位后判断几何与反应结果。
- 区域布置、召唤和道具的专有落点、消耗与冻结规则继续使用原实现，不将它们当作普通范围支援中心处理。

## 独立判定

- 小战每个受击目标独立进行d20攻击与伤害结算。
- 会战每个目标按其攻防独立计算命中概率并判定，仍使用会战原有概率制。
- 同一附带控制的DC来自技能规格；每个被命中的目标分别掷抵抗骰，使用自身等级、体型、抵抗和免疫。仅命中后或受损后触发的效果按该目标的结果检查。
- 固定随机序列验证了同一次技能中一人命中、一人未中，以及两人都命中后仅一人抵抗成功；逐轮与增量战报均保留各自结果。
