# 弓弩、法杖的友军遮挡 — 0.2.0-rc.4

弓弩（bow）和法杖（magic）的单位遮挡按长矛的阵营规则处理：可以越过友军占位，不能越过存活敌方前排，墙体等地形视线限制继续生效。它们不因此获得间接火力性质。

小战共用射击遮挡判定忽略这两种武器的友军阻挡；会战预备队的己方前线限制同步放行。法杖原有的敌方固守盾卫豁免移除。普通攻击、武器技能、副武器、AI 候选和读档后的判定均读取实际武器机制；旧机制标签兼容，不凭显示名授予豁免。

武器选择说明、固守提示与世界书已同步。步枪、直射火炮、曲射火炮及独立法术沿用各自规则，弓弩的最小射程和邻敌牵制限制保持有效。

验证：TypeScript 检查通过，99 个文件的 743 项测试全部通过；新增 9 项回归覆盖友敌前排、墙体与观测、普通攻击和技能的预览/执行一致性、拒绝时不扣资源、副武器读档、会战预备队、敌方盾卫和旧机制标签。既有冻结版本场景与存档兼容检查通过。原生安装文件已重新构建。
