# 战报、预览与物品说明精简，取消数量上限（2026-10-18）

只改文字和数量校验，不改任何结算规则；所有规则版本同时生效（战斗记录的文字变了，旧战斗读档后新产生的记录用新文字）。

## 现象

1. **战报漏出规则说明。** 战报是正文 AI 的输入，规则解释对它是噪音。最明显的是“固守”：每次固守都把整段规则拼进战斗记录（“面向最近可见威胁，正面防御提高2……独立魔法技能、空中射击、曲射火炮等间接火力及侧射可绕过盾卫的额外保护”）。类似的还有：
   - 压制：“目标反应停用、命中-2”；
   - 重伤：“（攻击/速度受损，3回合）”；
   - 破障：“（不结算单位伤害）”；
   - 溃退：“剩余N次机会”；
   - 指挥风格的打法说明；
   - 先锋部署的原因；
   - 挂盾的规则；
   - 区域伤害的“跨代毁伤×”；
   - 加速：“获得一次额外机动”。
2. **预览和物品说明解释过多。**
   - 行动预览：单人出手也写“有效攻击数 1”；突进/冲锋把整段位移规则写进预览；伤害详情重复主区数字；目标头部和成员生命面板重复同一组数字。
   - 技能效果行：召唤写“群体分摊同级单体的生命和武器伤害预算”，屏障写“重复施放取较强保护”，精力写“受当前资源与上限约束”。
   - 道具卡：
     - 标题已写“一次性道具”，说明里又写“一次性 ·”；
     - 特质整段十级说明塞进道具说明；
     - 写了“同方向只取最高一件”“一件一个效果”“编队齐用时每次最多消耗现员数件”；
     - 显示内部骰子“8d6”，这并不是实际伤害。
   - 远程武器卡的“伤害”格显示成“直射”（取错了字段）。
   - 护甲、盾的详情带着“部分穿透吸能强度×0.99；充分穿透后无额外减伤”“掩护单体攻击，范围与充分穿透绕过”“满足盾类技能前提”。
3. **数量上限。** 一次性道具每叠 1–9999；装备与佩戴、充能道具每批最多 64 件。

## 修改

### 战报（战斗记录）

| 事件 | 原来 | 现在 |
|---|---|---|
| 固守 | 剑士 固守，面向枪兵：面向最近可见威胁，正面防御提高2；……可绕过盾卫的额外保护。 | 剑士 固守，面向枪兵 |
| 压制 | A 压制 B：未结算生命伤害，目标反应停用、命中-2 | A 压制 B，未造成伤亡 |
| 重伤 | B 被重创，陷入【重伤】（攻击/速度受损，3回合） | B 被重创，陷入【重伤】 |
| 破障 | ……结构耐久 44→0，形成突破口（不结算单位伤害） | ……结构耐久 44→0，形成突破口 |
| 重整失败 | 重整失败，仍在溃退，剩余2次机会 / 机会耗尽，撤离战场 | 重整失败，仍在溃退 / 撤离战场 |
| 会战无处重整 | 无合法重整阵位，机会耗尽，撤离 | 无处重整，撤离战场 |
| 指挥（V19） | 指挥：我方 常规·均衡——按局势选择进攻、防守和支援 | 指挥：我方 常规·均衡 |
| 先锋部署 | 先锋部署：前出域已满或已位于先遣侧翼，保持阵位 | 先锋部署：保持阵位 |

| 区域伤害 | ……损失N点生命，跨代毁伤×2.3 | ……损失N点生命 |
| 加速 | X 使用加速动作，获得一次额外机动 | X 使用加速动作 |

面板战场上的说明不受影响：选“守备”时仍能看到固守说明，压制按钮上仍写着效果。

### 预览

- **主区**
  - 只有编队出手才写“有效攻击 N 份”，能估出减员时写“预计减员”。
  - 穿透对防护的数字移进“伤害详情”；主区只在打不穿时提示“无法穿透，不造成伤害”。
  - 目标头部写“现员 30/30人 · 每人72生命”；成员生命面板只在有成员带伤时显示。
- **伤害详情**：写普通命中、暴击；多组判定时写组数和每组命中率；再写穿透对防护、攻防合计和修正。删掉了与主区重复的平均伤害句。
- **技能效果行**（预览与单位页技能说明共用）：
  - 突进、闪现的落点已经写成“先突进至D6，以冲锋接敌”，不再重复位移规则；后撤写“出手后后撤至多N格，不触发近战借机”。
  - 召唤写“召唤一支N人编队（L5，近战），下轮行动”。
  - 屏障写“吸收N点伤害，持续N轮”。
  - 精力写“精力+N”。
  - 状态写“眩晕：跳过行动，40%生效，1轮”。
  - 区域写“火墙：半径1格，3轮，每轮伤害N，也会伤害友军”。
  - 状态说明去掉了“仅修正可造成的伤害，不绕过防护”等。
- **单位页技能说明**：武器技能写“以所持武器出手”，独立伤害写“伤害约N”（不再写内部骰子），状态写抵抗难度，推拉、驱散、特质授予各一句。
- **守备面板**：
  - 固守：“正面防御+2，移动或下次行动时解除；持盾时掩护同格队友。”
  - 警戒：“敌人进入射程时开火，占用本轮反应。”
- **压制面板**：“主行动1 · 战技点1。不造成伤害；目标命中−2，不能反应、固守或冲锋，持续2次行动。”

### 物品与装备说明

- **道具**：规格 + 用法 + 效果，例如“物理范围投射L4 · 占主行动，射程3格，伤害约N（范围）”。
  - 形态只在标题里写一次。
  - 特质只看规格里的名字，不再附十级说明。
  - 佩戴修正只在 L≠5 时补一句折算值，例如“佩戴L4+4防御 · 实际+3.5防御”。
- **武器**
  - “伤害”格修正为单段均值（远程武器原来显示“直射”）。
  - 标签“基础单段命中均值”改为“单段均值”。
  - 近战类别说明压成一句，例如“剑术攻守：命中+1，对近战防御+1”。
- **护甲**：强度修正只在不等于1时显示；“装备自动特质：重甲（先攻−1，无额外防御）”改为“重甲：先攻−1”。
- **盾**：删掉“掩护单体攻击，范围与充分穿透绕过”“满足盾类技能前提”和能量盾的过载规则说明。

### 世界书

- 条目 1：删掉“短兵器指匕首、短刀等”。删掉“qty为1—9999；装备逐件计，单批装备合计最多64件”，“不超过库存”并入 take 一行。阅读版由 `build:worldbook` 同步。
- `lorebook system explain.md`：give 一行改为“qty 是实物件数，默认 1，没有上限”。
- 没有动条目里的重复强调句（见报告末尾），由用户决定。

### 数量上限

- 一次性道具、spawn 的 items、give/take 的 qty、正文标签解析、库存编辑框都不再限制 9999，只要求正整数。
- 装备与佩戴、充能道具取消“每批最多 64 件”。它们仍逐件建档，写多少件就生成多少张卡。

## 验证

- **样例战报**（`artifacts/report-trim/sample.ts`，一场带固守、技能的小战）：固守行只剩“剑士 固守，面向枪兵”，重伤只剩“陷入【重伤】”，指挥只剩“常规·均衡”。
- **面板预览**（隔离构建）：
  - `items-v15` 夹具的物品卡见上文；远程武器“伤害”格显示“32.3生命”。
  - `skill-move` 夹具里冲锋预览只剩命中率、伤害、“先突进至D6，以冲锋接敌”和消耗，细节收进“伤害详情”；守备面板各一句。
- **测试**：类型检查通过。全量 2151 项，与 V19 基线相比没有新增失败，只有 `main.integration` 在全量负载下超时（上限 15 秒；单独跑基线 13.3 秒、本分支 13.8 秒，都通过）。
  - 写死旧文字的测试已按新文字更新：屏障跨等级改为检查换算后的容量、件数规则改为检查不再出现、召唤保留射程、区域保留穿透和“持续N轮”、护甲“强度×”、世界书不再含短兵器解释。
  - `unified-replay` 的 V5 human100 T3 只因“剩余N次机会”文字变化导致日志哈希不同，结算逐项一致，已更新该例的日志哈希。
  - `narrative-tools.integration` 单独跑在基线上同样失败（等待只给 1 秒），与本改动无关。
