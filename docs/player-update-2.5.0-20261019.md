# 通用战斗系统 2.5.0 更新公告

- **百兵谱**：新增巨剑、短兵器、巨型冷兵器、重型长兵器、弩、霰弹枪、火箭筒、喷射武器，以及小盾、中盾、大盾、能量盾；长兵器拒止、巨型冷兵器破盾、能量武器过热、负重等专属规则。
- **统帅**：双方指挥分新手到大师五档，另有均衡、积极进攻、谨慎、迂回、集中火力、伏击固守六种风格，只影响 AI 的判断，不加数值。
- **特质与控制**：更多特质支持 L1—L10，新增动能、热能、奥术抵抗；新增嘲讽、致盲、混乱、魅惑四种控制；治疗与护盾术对低等级单位有跨级加成。
- **等级锚定校准**：
  - 能量盾每份容量等于同级屏障，战舰等载具 ×6。
  - 高级护盾挡低级火力只消耗很少，低级护盾面对高级火力则更容易被打穿。
  - 屏障、攻防增益与士气技能的数值按等级锚定重新校准，L5 不变。
- **卡死修复**：带能量盾的单位被重武器击中后，面板提示“能量盾记录损坏”并无法继续，已修复。
- **散兵阵形说明**：“疏散 / 收拢”按钮写明效果，高亮当前选择，并显示是否生效。
- **三方小战**：支持第三方参战，单人单位最多 32 张出场。
- **AI 改进**：搜索、记忆威胁、火力分配和会战军令重试更可靠。
- **界面**：新武器类别都有专属图标，火箭筒改为 RPG-7 造型，巨剑改为德式双手大剑；战报和说明更精简。
- **世界书**：插件更新后内置默认文本自动刷新，已保存的自定义修改照常保留。

能量盾示例：L8 战舰的能量盾容量 288 点，每次激活回充 14 点，同级主炮一发不再直接打穿；L8 单兵护盾 48 点，挡 L5 步枪每发只耗不到 2 点。

旧战斗和战报按原规则继续；新开的战斗使用新规则。更新前请先导出存档，不要同时启用正式版与 test 版。
