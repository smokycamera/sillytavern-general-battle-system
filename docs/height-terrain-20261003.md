# 地形高度、视线与地形效果（2026-10-03）

现象：实际高度地图里，高度2的单位常被高度1的地形挡住视线；城墙、房屋在格子信息里显示“高度0”；高地只有固定的防御+1，站得再高也没有更多好处；浅水、沼泽、废墟对战斗没有影响。另外，战报末尾的状态摘要重复了单位提示词里已有的兵力、生命、武器和疲劳，以及“治疗不会补回其余缺员”。

## 原因

1. **视线把坡面当成台阶。** 每格自然地面按平顶方块处理，并取射线在格内最低的一点比较；视点只比地面高0.25级。坡面上相邻两级之间总有一个格角高过射线，于是坡脚看不见两格外的坡顶，坡顶也看不见坡脚。生成的山地图中，有高差的两格之间只有 11.5% 能互相看见。
2. **格子高度读的是站立地表。** 城墙、建筑、城门下面的地面是0，查看格子时就显示“高度0”。
3. **高地收益不随高差变化。** 地面单位只要比攻击者高就固定防御+1；城墙、塔楼上的单位另按“阵地掩护”+2，塔楼并不比城墙更有利。高处也不影响射程。
4. **地形效果有缺口。** 浅水、沼泽只影响移动和冲锋；实际高度地图的山地格仍按困难地形减少交战展开，但说明写的是“台地内部正常移动”；废墟瓦砾不提供掩护；桥上的单位按桥下的水面判定地形。查看远处格子时，“相邻进入花费”按选中单位所在格计算高差，远处平地也会显示“需经坡道或阶梯接近”。

## 修改

视线、居高和地形效果只用于实际高度地图（`spatialRulesVersion: 2`），没有实际高度的旧地图和旧存档保持原规则。战报摘要的精简对所有战斗生效。

### 视线

- 自然地形只在高于双方站立高度时遮挡视线。站得不低于坡面、台阶或山脊的一方能看过去；山脊高于双方时，仍然挡住背坡。
- 城墙、建筑、关闭的城门、岩壁和巨石仍是实体，按射线在格内的最低点判断。紧贴墙后的格子即使从山上也看不见，隔开一格就能看见。
- 视点高度由0.25级改为0.5级，与友军遮挡规则里人形单位的身高一致。
- 甲看得见乙，乙就看得见甲。茂密森林（射线穿过3格以上林冠以下）的规则不变。

### 居高

| 比对手高 | 防御 | 远程武器射程 |
| --- | --- | --- |
| 1级 | +1 | +1 |
| 2级及以上 | +2 | +2 |

- **防御**：非空中的守方每比攻击者高1级，防御+1，至多+2，修正名“居高”，近战和远程都适用。自然高地与城墙、塔楼平台按同一高度计算。
- **城垛**：站在城墙或塔楼上、且比攻击者高时，“阵地掩护”由+2改为+1，仍与固守等姿态取较高者。合计：城墙对地面+2（不变），塔楼对地面+3（原+2），塔楼对墙顶+2（原+1）。
- **射程**：远程武器和远程武器技法每比目标高1级，射程+1，至多+2；最小射程不变。独立法术、近战、空中射手和空中目标不受影响（空中仍按对空射程规则）。目标面板显示“居高射击：射程 +N”，超出时提示如“超出射程（距离10 > 射程7+居高2）”。射程底色仍只表示平面距离。
- AI 寻找射击位置、评估站位和估算技能收益使用同一套规则。

### 地形效果

- **浅水、沼泽**：没有航渡能力的地面单位站在其中“立足不稳”，攻击−1、防御−1，武器交战展开减少4人。桥上、空中和有航渡能力的单位不受影响。AI 站位会避开。
- **山地格**：不再减少交战展开，也没有攻击惩罚；高处收益只来自居高。
- **瓦砾**（毁坏的城墙、城门、建筑和废墟地标）：地面单位抵御一格以外的远射时防御+1，计入“阵地掩护”，与固守等姿态取较高者。
- **站立地形**：桥面上的单位按开阔地结算；城墙、塔楼平台上的单位不再受下方森林、水面等地形影响，城墙下的街道仍计入巷战。
- **格子信息**：城墙、建筑、塔楼、关闭的城门和岩壁显示顶部高度，例如城墙“高度1”、建筑“高度2”，塔楼建在高度1的地面上显示“高度3（地面1）”。远处格子的进入花费按它相邻的可通行格计算。

### 战报状态摘要

- “发送完整逐轮战报”末尾的战后状态、“发送状态摘要”和归档战报的摘要中，单位行不再列现员/人数、总生命、成员生命分组、武器和疲劳，装填只写“装填中”。保留位置、距敌、士气、持续状态、可救伤兵数、离场状态、SP 与已准备技能的冷却。
- 状态摘要和战斗终章中只写“可救伤兵N”，不再附“治疗不会补回其余缺员”。这些内容由同时发送的单位提示词提供，单位提示词保持不变。
