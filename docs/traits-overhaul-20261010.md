# 特质翻修：V13 traits-v1（2026-10-10）

基线：`153024e`（test）。新开的战斗使用新规则 `v13-overflow-d20` / `v13-overflow-tw`（在 V12 基础上增加 `traitModel: 'traits-v1'`）；进行中的 V2–V12 战斗与读档仍按原规则结算，单位上的 `traitModel` 由战斗规则写入，与 V12 的 `armsModel` 同一做法。档案里已有的特质 id 都保留，旧单位不需要迁移。

## 现象

内置世界书的特质表是按“全面战争”机制逐项堆出来的，48 项里有一批和单位字段重复、互相重叠或违反直觉，各题材常见的能力又缺了不少：

- **和单位字段重复**：老练、精锐与训练等级 level 重复；快速与 speed 重复；重甲、超重装甲由护甲自动产生，大型、泰坦巨兽由 body 决定，正文再写一遍要么被忽略，要么和实际装备打架。
- **互相重叠**：穿甲箭是破甲的子集；克制机动和拒马都要求长兵器，作用对象也一样。
- **名称带题材色彩**：林间行者、山地子民、原野游骑、巷战大师、远近双全、毒击……仙侠、科幻正文里很难对上号。
- **不符合直觉**：
  - 守城工事在任何地方都生效，相当于随身带着城墙；部队冲出阵地追击，防御照旧+3。
  - 拒马必须是长兵器，拒马桩、反坦克障碍、刺刀方阵都用不上。
  - 散兵只能是编队，个体游击手写了也不生效；步枪散兵线还得逐个手写散兵。
- **缺少常见能力**：对空、侦察、医护、非生物（机器人、构装、亡灵）、偷袭、吸血、抗控制、身法、天生护甲（龙鳞、炼体）、不屈。用 flash 跑仙侠、D&D、二战、科幻四类开场，正文想表达这些能力时只能写进 note，或者硬套守护、狂暴。

用户确认的新特质表（即世界书“技能与效果”里的 traits选）：

```
攻击：破甲、破甲大师、克制步兵、克制大型（含载具骑乘）、屠兽者、对空、狂暴、淬毒、偷袭、吸血、近战特化、射击专家、抵近射击
防护：守护、大守护、再生、坚韧（抗控制）、身法、天生护甲（护甲即肉身或鳞片）、不屈、工事（据守阵地）、盾墙、拒马、散兵、非生物（机器人、构装、亡灵）
士气：恐惧、恐怖、不溃、顽固、统率
机动：冲锋强化、践踏、游击、骑射（需坐骑）、先锋部署、潜伏、侦察、飞行、机械化、耐力训练
地形与工程：林地专精、山地专精、平原专精、巷战专精、夜战专精、航渡、登城（攀登城墙）、工兵
后勤：医护
```

用户另外要求：拒马不再需要长兵器；散兵和不屈各有个体与编队两种效果；天生护甲注释为“鳞片”而不是“鳞甲”。

## 修改

### 新增特质

新特质不会出现在旧战斗里，所以不需要规则开关，任何新单位都按下表结算。

| 特质 | 机制 |
| --- | --- |
| 对空 | 打空中目标攻击+2、伤害×1.25；地面射击空中目标不再额外损耗射程（小战2格、会战1阵距）。与克制大型、屠兽者同组取强，打飞龙不会叠两份 |
| 偷袭 | 出手前仍在潜伏，或目标正与己方另一单位近战时，武器攻击与物理技能伤害×1.5；独立魔法技能不受影响。小战与会战共用 `situational-traits.ts`，预览与实际结算一致，潜伏状态在出手暴露之前读取 |
| 吸血 | 造成实际生命伤害后回复其中25%：个体回复生命，编队只能救回已有的可救伤兵；打非生物与载具无效。战报记“吸血，回复N” |
| 坚韧 | 眩晕、定身、沉默、缴械、减速、惊惧的抵抗+4（d20 约多两成），不会被击退或拉拽；不影响伤害、中毒与士气 |
| 身法 | 轻中装的人形或大型身体：脱离近战不受借机攻击（受压制、减速、定身、眩晕或在空中时不行，仍受警戒射击）；森林、丘陵、碎石、浅水、沼泽、爬坡都按平地走，会战编队在森林山地也能纵深调动两阵位。深水、墙体、悬崖和敌军占据的位置照常 |
| 天生护甲 | 只让所写护甲的减益无效：不计负重，没有重甲/超重甲的先攻惩罚和移动−1，载具重装也不减速。防护和轻重档位仍按所写护甲：天生重甲照样算重装，游击、散兵、身法等轻装前提照常按档位判断（按用户要求，只做到让护甲减益无效） |
| 不屈 | 个体：每战一次，受到致命伤害时以1点生命坚持（战报“不屈，以1点生命坚持”）。编队：每战一次，本该溃逃时当场重整并按成功重整恢复士气，不计溃退次数 |
| 非生物 | 免疫中毒、流血与惊惧，不会士气崩溃；维修包可以修理（原来只能修车辆）。燃烧、眩晕、定身等照常 |
| 侦察 | 识破潜伏的距离翻倍（小战4格、会战2阵位）；己方曲射火力打它看得见的目标时命中+2（校射），多名侦察不叠加 |
| 医护 | 施放的治疗技能、治疗区域与治疗品效果×1.25；编队自身伤亡里的可救伤兵由每2名救1名提高到每4名救3名，零头跨次累计 |

### V13 改动的旧特质（只对新战斗）

| 特质 | V12 及以前 | V13 |
| --- | --- | --- |
| 工事（原守城工事） | 防御+3、受远程伤害×0.7，处处生效 | 同样数值，只在据守位置生效：开战时（或技能授予工事时）所在的小战格子或会战阵位。离开即失效，回到原位恢复；在别处原地完整休整一轮（不移动、不出手、不反应、没被压制），改在新位置构筑，战报“原地休整，重新构筑工事”；开战时没能构筑的（例如还在空中）同样休整一轮后构筑。与固守、盾墙、阵地掩护仍然同组取强 |
| 工兵（原攻城工兵） | 攻城环境攻击+2；结构伤害×1.5 | 不再凭环境加攻击；攻击时无视目标的工事加成；结构伤害×1.5 不变 |

| 散兵 | 只限轻中装地面编队：未被近敌牵制时范围伤害减半，代价近战展开减半、近战防御−1 | 个体也可以：未被近敌牵制时范围伤害减半，没有近战代价。编队同旧效果，另外榴弹溅射波及的人数减半。主武器为步枪、单发重步枪或能量武器的轻中装人形编队自动获得（显示为装备自动特质“散兵（步枪类编队自动疏散）”），火枪线列不会 |

旧战斗里这些特质的说明文字也保持旧版（`traitDescription` 按单位的 `traitModel` 选 V13 或 V12 说明）。

### 停用、并入与改名

- **停用**：老练、精锐、快速。正文写这些名字不再建档，解析给出提示；`spawn` 没写 level 时老练按 level=3、精锐按 level=4 代写，没写 speed 时快速按 speed=4 代写（写了的不覆盖）。已有单位身上的这些特质继续按原效果结算。
- **并入**：穿甲箭→破甲，克制机动→拒马，正文旧写法直接映射到新特质。
- **由身体或装备决定**：重甲、超重装甲、大型、泰坦巨兽不能手写，正文写了提示“由护甲决定”“由body决定”。
- **改名**（旧名继续识别，包括旧技能写法 `buff+守城工事`）：林间行者→林地专精、山地子民→山地专精、原野游骑→平原专精、巷战大师→巷战专精、夜战→夜战专精、守城工事→工事、攻城工兵→工兵、远近双全→抵近射击、毒击→淬毒。
- **各题材常见说法**（`TRAIT_ALIASES`）：御剑→飞行，神识、斥候、观察员→侦察，炼体、鳞片、甲壳→天生护甲，道心、韧性、霸体→坚韧，轻功、遁术→身法，噬血→吸血，傀儡、亡灵、机器人→非生物，反坦克、反装甲→克制大型，防空→对空，军医、卫生兵、医修→医护，黑暗视觉、夜视→夜战专精，威压、龙威→恐惧，伪装、隐匿→潜伏，等等。
- 新建技能不能再选停用或自动特质作为 buff 附加词；旧技能里的 id 照常解析。

### 正文容错：天生护甲写进 armor

用新世界书跑 flash 时，模型几次把天生护甲写成护甲种类，例如 `armor="远古龙鳞:天生护甲L8+6防护"`。旧解析把它当成一件武器，`+6防护` 不是武器的强化方向，整条 spawn 被拒，红龙和巨魔直接从战斗里消失。

现在 `armor` 写成“天生护甲/天生装甲/天生甲”或“天生轻甲/中甲/重甲”时：写了种类照用；只写天生护甲时按身体补种类（巨型→重甲、大型→中甲、人形→轻甲），同时加上天生护甲特质，并提示“「天生护甲」不是护甲种类，已按重甲处理并加上天生护甲特质”。`unit_set` 改已有单位又没写 body 时不知道身体，保留原护甲并提示，不猜轻重。

### AI：据守工事（小战）

工事改成只在阵地生效后，原来的 AI 并不知道“离开阵地就没了工事”，守军照常前出、搜索，工事形同虚设。用分层地图（现在开战生成的地图都是）跑成对对照：同一张地图、同一个种子，守方有无工事各打一次，每个场景 80 局，攻方从对面进场，歼灭战。

| 守方胜（/80） | 步枪 2v2 | 弓 2v2 | 刀盾 2 攻 弓 2 | 弓1剑2 攻 剑 2 |
| --- | ---: | ---: | ---: | ---: |
| 无工事 | 40 | 37 | 35 | 17 |
| 工事 + 原 AI | 39 | 38 | 35 | 20 |
| 工事 + 新 AI | **44** | **44** | **40** | **18** |

原 AI 下工事基本不起作用（与无工事相差在 ±3 局以内）：守军的离开主要发生在第1回合，开战时看不见敌人（地形挡住视线），AI 进入搜索，走出工事去找人，接敌时早已没有工事。步枪 2v2 里原 AI 守军 565 次行动有 160 次离开工事，新 AI 为 691 次里 134 次；另取 40 个种子分类，新 AI 下的离开是：工事里没有射界、走出去能打到人（步枪 62 次、弓 42 次），弓手换位 27 次，追击全部溃逃的敌人 3 次，不再有看不见敌人就出去搜索的情况。

改动（`SmallBattle.autoGridAction`）：

1. **看不见敌人时不出去搜索**，留在阵地等敌人来。
2. **离开阵地有代价**：按威胁最大的已知敌人（含刚失去视线的）打它一次时工事挡下的伤害计入每个离开阵地的选项（移动、冲锋、加速移动、起飞）。足够划算的出击（例如补刀、追击溃兵）照样会离开。
3. **被压制时不死守**：敌人打得到它、它在阵地上却打不到任何敌人（例如近战守军挨弓手的箭）时不计这项代价，照常权衡出击或后撤。

试过但没有采用的做法：

- **让据守单位原地不动，等敌人进入射界**（原地不计“靠近敌人”的位置分）：近战守军被弓手白白射杀（弓1剑2 攻 剑2 守方胜 7/80），刀盾攻弓手出现 16 局平局拖到回合上限。
- **把离开的代价算成所有敌人合计或两轮交火**：守军更死板，步枪 2v2 守方胜降到 36/80，弓1剑2 攻 剑2 降到 8/80。

工事在小战里的收益不大（胜率多 5–9 个百分点），因为 7×13 地图上主动权和地形往往比固定阵地重要：攻方可以抢占高地、林木掩护，守方的开战位置多在开阔的底线。会战里编队本来就很少离开阵位，工事很强（见下）。

会战 AI 没有改：24 局对照中据守编队离开阵位的比例在 3%–4%，步枪 2v2 守方胜 6/24 → 24/24，弓 2v2 3/24 → 24/24，与 V12（工事处处生效）相同。

### 伤害预览缓存（顺带修正）

AI 估值和面板的伤害预览共用一份 96 次抽样的缓存，键里为了复用会去掉格子与阵位。工事加入后，“在不在阵地上”取决于格子，于是单位挪开阵地后的预览会借用阵地里的抽样结果：AI 以为走出阵地也照样受保护，面板也会显示偏低的伤害。键里现在记“是否在阵地上”，不记格子本身。V12 及以前的单位从不记录据守位置，键不变。

### 面板

- 配装页的特质选择器与世界书同一分组和名称；已有单位身上的停用特质单独列在“旧特质（已停用，可取消）”。
- 单位详情里，前提不满足的特质标“（未生效）”并给出原因，例如个体写了骑射却没有坐骑；停用特质注明“训练程度由level表达，旧特质继续生效”。
- 装备自动特质显示步枪类编队的散兵。
- 工事状态：小战行动栏和单位详情显示“据守工事：离开即失效”“已离开工事：回到原位，或原地完整休整一轮重建”“尚未构筑工事：原地完整休整一轮构筑”；移动预览的落点不在阵地上时先提示“离开工事阵地，工事随之失效”。正文事实清单同样带上这一项（`works`），叙述者能知道守军还在不在工事里。

### 世界书与说明

- 内置世界书“技能与效果”的 traits选 换成用户确认的新表；示例 `buff+守城工事L1` 改为 `buff+工事L1`。
- `lorebook system explain.md` 的特质逐项机制表按引擎数据重新生成，分六组，另列停用与自动产生的特质。
