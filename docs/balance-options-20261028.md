# 减少秒杀与攻防修正的平衡方案

## 方向与已实施工作的区别

技能空档与简单连射预览已在 3.0.25 本地候选修复，见[修复记录](skill-preview-fixes-20261028.md)。**本报告以下伤害、暴击、承伤与生命政策均未应用到正式公式。**

穿透具有突破更高规格护甲的价值。此前“对当前目标完全穿透后暂时不再增伤”的统计，不能外推成“穿透修正没有意义”，更不能据此硬砍所有来源的穿透。本轮候选全部保留原穿透、防护和跨代压制曲线。

目标应是：同等规格、投入接近且准备了适用防御时，不频繁从满血被一次行动击倒；装备跨代、投入明显领先、攻击未防护通道、埋伏与集火仍能造成重大威胁。一次行动击倒率、命中后的击倒率、多人集火与整场胜率分别衡量。

## 穿透跨级能力的实测

L4训练、L4大剑普攻，对同为L4训练但穿不同规格中甲的目标；无其他修正：

| 目标护甲 | 武器+0穿透 | +5穿透 | +10穿透 |
| --- | ---: | ---: | ---: |
| L4中甲：普通命中均值 | 23.70 | 43.10 | 43.10 |
| L5中甲：普通命中均值 | 5.17 | 12.93 | 23.70 |
| L6中甲：普通命中均值 | 0 | 0 | 5.17 |

同级目标上 +5→+10 暂时用不到的穿透，在L5甲上仍显著增强，+10还能对L6甲从无法穿透变成有限损伤。每点+0.2抗穿差保持，单位训练与装备规格保持独立。后续 UI 应表达“对本目标已完全穿透”，不能把它标成全局无效属性。

## 候选机制

### A：同类正增伤相加，保留不同机制乘区

仅把本体、武器、技能、佩戴的同类正增伤合并：`1+Σ正增量`，替代它们彼此乘算。负修正仍独立乘入，穿透、等级压制、场景与特质的既有机制保留。**不设置新的总×2硬顶**，避免再次让新增点数突然失去价值。

例如 ×1.26、×1.15、×1.50 目前合成 ×2.1735，A 为 ×1.91。单来源的有效点数继续增长，但来源越多，不再指数放大。代价是多来源进攻构筑的上限降低；特质、增益等其他乘区仍需独立审查，不能声称A限制了所有爆发。

### B：暴击均值由约2倍降到约1.5倍

本轮模拟保留双倍伤害骰，再将暴击伤害预算乘0.75，保持普通攻击不变。主要减少低概率尾部秒杀，不提高命中。不能解决普通命中本来就超过满血的配置；也会降低匕首等暴击定位，需要配套检查其技能与收益。

### C：防御修正同时提供小幅承伤韧性

防御仍降低命中，在此之外，按正向防御修正点数提供 `承伤倍率=1/(1+0.025×点数)`。例如+4为×0.909、+10为×0.8，对已经命中的暴击也有效。这里取本体、武器、护甲、盾的防御修正总点数，佩戴按等效判定点折算；不拿基础防御值直接代入。

优点是“防御堆得高但天然20照样原额秒杀”的尾部能被控制，防御与伤害修正存在持续对抗。代价是防御同时影响命中和伤害，可能压过专项防护；高投入防御、治疗和守护叠加必须防止拖长战斗。该式仅为待调参数，不是已确认规则。

### D：基础耐久增加25%

维持伤害、穿透、命中和修正系数，基础生命×1.25。直观地拉低所有攻击的单次致死比例，也会抬高所有无修正单位的耐久。代价是治疗、再生保底、屏障相对地位、编队成员耐久及会战长度都会联动；不能只改生命后宣称完成平衡。

D的表格是对目标生命统一放大后的攻击级敏感性分析，没有伪造出已实现的新生命模型或连续对局胜率。

## 标准风险案例的精确结果

训练L4、大剑L4 `+4伤害+3穿透`、L3近战技能 `+3伤害+2穿透`、全额奥术转换、L4佩戴 `+10伤害`；目标L4中甲 `+4防御+3动能防护`，108生命。攻击端22正点、目标7点，**这个表是高风险不对等配装，不是等投入胜率证明**。

| 方案 | 普通命中均值 | 目标生命 | 普通命中击倒率 | 每次发动满血击倒率 |
| --- | ---: | ---: | ---: | ---: |
| 当前 | 120.43 | 108 | 73.03% | 28.37% |
| 仅A合并增伤 | 105.83 | 108 | 45.95% | 19.70% |
| 仅B暴击1.5倍 | 120.43 | 108 | 73.03% | 28.37% |
| 仅C防御韧性 | 109.48 | 108 | 54.05% | 22.30% |
| 仅D生命+25% | 120.43 | 135 | 23.77% | 12.61% |
| A+B+C | 96.21 | 108 | 23.77% | 12.53% |
| A+B+D | 105.83 | 135 | 6.07% | 6.40% |
| A+B+C+D | 96.21 | 135 | 0.75% | 3.71% |

只降暴击对这个案例几乎不起作用，因为普通命中已经具有致死级伤害。要将这类明显偏进攻的配置也压到低秒杀率，必须同时控制正常命中的总伤害/承伤比，代价是进一步放慢投入接近的对局。

若同一攻击对抗22点防御：原护甲7点、本体+5生命、L4佩戴+10生命，实际215生命。当前普通命中击倒率为0，每次发动击倒率4.14%；仅B降至0.31%，A+B降至0.009%，A+B+C约0.000052%。攻防投入接近时，现有生命与防护已经有强烈作用，不能用22对7的情况抹去它。

## 28,800次候选测量的适用范围

十级、6类近战武器、4护甲类型、原通道/奥术、6套修正配置、10种当前或候选政策，共 **28,800 次精确单段分布测量**。同一次施放计入未命中、普通命中、天然暴击、随机整数取整及满血截断；没有把命中后的击倒率冒充发动概率。

同正点数12/22/40配置在各自480个基础场景中，当前规则平均发动击倒率约为 **1.28% / 1.26% / 0.38%**；22攻对7防为 **15.72%**。这只是该均匀网格的平均值，不能当玩家总体发生率；点数也不是系统已确立的跨来源经济价格，技能有精力和行动成本，护甲是被动常驻。

A+B+C 下，22对7的平均发动击倒率约9.97%；再加D为6.11%。同22点配置的平均期望生命损失比例则由当前14.95%降至10.87%，全套再降至8.68%。这些表明全套并不是无代价修正：耐久与恢复构筑会更强，战斗更慢。

本轮未把10种候选实现为正式规则，也未进行这些候选的完整AI对局、回血拖延与多段/范围攻击验证。此前544局属于当前基线，不能挪作候选方案的胜率证据。

## 建议

**优先考虑A+B+C作为较小范围的方向，保留D作为更强调低秒杀率的耐久档位。** A处理来源乘算，B处理暴击尾部，C让防御修正能对已经命中的重击提供回报。若要求上表22对7的失配组合也很少秒杀，则全套D更接近目标；同时必须接受普通对局变长并重新验证恢复。

不建议直接给单次伤害加“最多扣30%/50%生命”的硬帽，也不建议把天然20改成无视护甲。前者容易让多段攻击绕过上限并削掉跨代毁伤，后者会让防御进一步失去意义。

装备专项防护与通用防护还应单独建立效能/成本差：现行装备每点都+0.2，专项覆盖更窄却没有数值补偿；佩戴已有专项更强的先例。但专项增强不能代替生命或韧性应对不匹配通道，后续应再测通用与专项各自的合理收益，不能简单把两者都翻倍。

正式采用前的验收：标准同级、接近投入配置的普通命中满血击倒率接近0，包含暴击的每次发动率可先以1%–3%为项目试验目标；较大规格/投入优势仍保留击倒能力；适用目标上的每点穿透、防护、伤害与生命保持正确方向；持续对局有反应窗口且不会被恢复无限拖延。这些是GBS候选目标，不是其他游戏规定的通用阈值。
