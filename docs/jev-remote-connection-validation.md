# JEV 远程连接验证（0.2.0-rc.9）

此次更新在酒馆面板内增加 TypeSafe/JEV 与 OpenAI 兼容直连，支持 URL、API Key、模型列表拉取和选择、手动模型 ID；保留旧本地桥接连接。新安装默认地址为 `https://api.typesafe.ai/v1`，默认模型为 `jev-latest`。

## 已验证

- TypeScript 类型检查通过。
- 扩展定向回归：13 个测试文件、109 项测试通过，包含 15 项远程连接测试以及 TypeSafe/OpenAI 两种协议的实际战斗控制器测试。
- 上下文及战斗行为：另外 10 项测试通过。
- 原生扩展构建成功，核心副本校验通过，已同步可安装的 dist 文件。
- 覆盖基础地址与完整端点规范化、自定义路径、两类模型列表与去重、认证失败、无效列表、跨域错误提示、旧连接保留、会话密钥存储、所选模型传递、评分与场景结果校验。

## 尚未验证

- 原生浏览器冒烟测试尝试启动，但运行环境没有 Playwright Chromium 可执行文件；没有获得页面点击测试结果。
- 未使用真实用户 API Key 调用官方或第三方模型。远程服务需要支持所选协议，并允许酒馆来源的浏览器跨域请求；仅拉取列表成功不能证明决策接口兼容。

官方接口依据：[模型列表](https://docs.typesafe.ai/models)、[决策接口](https://docs.typesafe.ai/api)。
