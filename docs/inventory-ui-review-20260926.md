# 战阵界面改进与验收记录

日期：2026-09-26。基于 0.2.0-rc.13；本次修改位于 PR #15。U1—U8 已全部得到用户批准并实施。

## 装备页现在如何工作

- 当前单位的已装备物品放在最上面，随后是其随身物品，最后是公共库存。
- 不显示其他单位持有的物品；选择“无主物品”时只显示公共库存。切换单位会关闭不再可见物品的编辑预览。
- 剧情参考的全选与全不选只影响当前显示的物品。自己的未装备物品可放回公共库存；天生武器属于自身，不能转送或改造成外部武器。
- 已装备卡片突出“卸下”，备用装备突出“装备”，消耗品突出“使用”。归属、改造、删除等操作收在“其他操作”中。

## 自然语言与控制技能

玩家界面的“buff/debuff”改为“增益/减益”，“HP/SP/XP”改为“生命/精力/经验”；快照、投影、持久化、候选、宿主等开发用语按实际意思改写。服务连接的详细说明默认折叠，保留必须识别的服务名称和配置项。

技能编辑提供眩晕、定身、沉默、缴械、惊惧、减速、击退、拉拽八个快捷按钮。实际点击眩晕后可生成技能、设置等级并预览。正文也可直接使用“眩晕”这类中文效果名，无须填写新的必填属性。

## 检查范围

Computer Use 查看的是当前构建的原生插件，运行于本地测试酒馆页面；数据为巡林队长、后备守卫和敌方哨兵等测试档案。没有读取或改写真实聊天。检查了1440×1000桌面、390×844窄屏、深浅主题、物品编辑、护符入库与装备、控制技能按钮。

这是浏览器窄屏模拟，并非手机实机验收。对比度数字针对本次调整的主要颜色组合，不等同于所有页面均已完成无障碍认证。
