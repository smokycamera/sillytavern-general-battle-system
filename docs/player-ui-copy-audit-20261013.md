玩家界面文案审查 · 2026-10-13

检查对象为当前工作区中实际接入玩家界面的源码，包括战场、队伍、配装、战报、设置，以及它们调用的显示函数。以下为修改前的审查记录，行号对应审查时的源码。

用户批准后已落实下列精简：结果去重、完整规则和公式按需展开、道具形态说明随选择变化、换装预览仅突出变化、技术元数据移入详情，以及旧导航和标签更新。配装卡保留原编辑入口，按用户后续指示将“改造”改名为“编辑装备”，窗口标题、确认操作及配装指引同步更新。编辑流程和剧情装备改造处理保持原功能。

验证结果：15个相关测试文件共140项测试通过；末次调整后配装、战术和会战的24项测试复查通过。TypeScript检查、原生扩展构建和构建产物一致性检查通过，63个打包文件与当前源码一致。

发布前基于最新 `test`（`da53832`）合入界面修改，保留目标选择保持和直接换装修复。14个相关测试文件共141项通过；类型检查、扩展构建和63个打包文件一致性检查通过。

主要问题是同屏重复结果、在操作位置讲完整规则、向玩家解释存档实现，以及旧界面用语残留。标注“优先”的项目影响主要操作；其余项目适合随后精简。

1. **优先：会战预览重复显示命中与伤害。**
   位置：`panel/src/formation-view.ts:67`、`:72`，`panel/src/main.ts:1790`。
   条件：当前会战任务有攻击预览。上方数字区显示“命中率／命中后伤害”，下方 `massOrderPreviewText()` 再输出“至少命中一次／命中后伤害”。两处属于同一预览，常规布局都可见。
   建议：保留数字区；下方只说明本轮任务占用、疲劳、预计移动、附加效果和具体受阻原因，移除重复概率与伤害。
