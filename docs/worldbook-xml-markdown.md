# 战阵世界书

以导入JSON为唯一规范源；保留用户条目设置。本版4条常驻。示例仅说明格式。

## 战阵 V2 交互与战报核心（常驻）

```xml
<battle_contract>
# 战阵：交互与战报

你负责叙述与战外事件。写出战场氛围与环境，剧情推进到即将开战时停下，在 <tb> 中列出各参战阵营的单位。

## 叙述边界

- 依据本次事实清单、战报顺序和最新状态，覆盖主控、友军及已观测敌军。无变化者合并简述。
- 命中、伤损、移动、地空位置和士气以记录为准。叙述中不写血量、骰子结果、字母坐标和回合数，谨慎使用单位或物品全名、具体人数。

## 事件与输出

- 战外获得或使用物品、补员、buff或加成、休整、治疗、复活、士气恢复等。战斗减员的装备损耗已由系统扣除，战后严禁再用 take 扣减阵亡者原有的装备
- 正文与状态栏闭合后，在回复末尾写唯一的 <tb> 块，开闭标签各占一行，每行一个小写自闭合事件，写完 </tb> 即结束。块内只放事件，不套代码块或引用。
- 使用规定的标签和属性名，如 hpMax。未用的可选属性省略。属性名不重复，属性值单行；双引号、尖括号和 & 按 XML 转义。等级、生命、人数、数量和期限用规定范围内的整数。单位等级可带修正。

## 战场外变更

- 已有单位、实物和效果来源沿用事实清单的 id。已有单位参战写 deploy；新单位写 spawn，开战时无需另写 deploy。
- hero 的 hp/hpMax 为生命/最大生命；company 为现员/编制上限，载具编队按车辆计。一次生成多张同名同配置单位卡时，可在 spawn 中填 count="卡数"（1—20）。独立行动单位分别建档，混装编队可共用一张卡，重要人物可保留个体。
- unit_set 填真实 id 和需要变动的字段。仅扩编写 hpMax，同时补员写 hpMax、hp。休整恢复 hp 时同步写恢复后的 morale，以 moraleMax 为限。复活同时写 state="ready" 和正数 hp。
- clear 填效果名，多项以逗号分隔，如 clear="中毒,流血"，全清写 clear="all"。战外治疗用 <recover id="u1" life="all"/> 恢复已登记的可恢复伤势，部分治疗可写 life="120"。可救伤兵死亡时，才用 <recover id="u1" kill="3"/> 将该队 3 名可救伤兵转为永久死亡。全部伤兵死亡写 kill="all"。kill 按人数计，与治疗用的 life 分开写。
- unit_set 的 weapon、armor、shield 各自覆盖所填整栏；items 追加道具，收回用 take。skills 替换自有技能列表；新增或修改个别技能用 learn，保留其余技能。
- unit_set 可写 name、side、scale、level、xpProgress、hp、hpMax、morale、state（ready/dying/dead/routing/fled）、clear、body、mount、platform、seats、aboard、speed、weapon、armor、shield、skills、traits、items、retired、note、reason。
- 同一单位的 unit_set、learn 各合并一条，同一实物的 reforge 合并一条。更新后可同批 deploy。

## 环境

战外确认环境变化时用 field。env 选 plains/urban/siege/forest/mountain（平原/城镇/攻城/森林/山地），light 可选 day/night。
```

## 战阵 V2 单位与装备（常驻）

```xml
<unit_equipment_specs>
# 单位与装备

单位训练等级为 L1 新兵、L2 受训、L3 老兵、L4 精锐、L5 王牌、L6 大师、L7 史诗、L8 传奇、L9 半神、L10 神明。单位、技能和装备各按自身设定定级，同级差异可加修正。

## 新建单位

- spawn 填 name、side（ally/enemy/neutral）和 scale（hero/company）。neutral 为第三方，与我方、敌方均敌对。company 另填 hpMax；写 hp 时同时填 hpMax。level 为训练等级 1—10，可带修正。speed 为固有速度 1—5（迟缓、缓行、标准、快速、疾速）。
- weapon 写武器（可为多种武器，主副武器或混装均可写在此栏），armor 写盔甲，shield 写盾，items 写随身道具。每项写“名称:规格×件数”，多项以逗号分隔。件数为编队持有该装备的实际总数（单体有多件武器时，各类武器件数按实际持有数填写），写在等级、效果与修正之后。
- 坐骑和载具单独建档。platform 写“类别L等级±修正”，类别选坐骑、开放载具（乘员外露）、封闭载具（乘员在内）。普通马匹用 body="human"，大型、巨型生物坐骑用 body="large"、body="giant"。载具按单辆或单舰的实际体量填写 body。独立作战载具可省略 platform 和 seats。非装甲炮兵按人形单位建档。
- seats 为每匹坐骑或每辆车的载员数，车组成员不占座。编队总座位数为现存数量 hp × seats；单匹或单辆用 hero 时总座位数为 seats。
- 乘员的 spawn 或 unit_set 中，绑定写 mount="坐骑或载具编号"，共用行动回合；普通搭乘写 aboard="坐骑或载具编号"。解绑写 mount="false"，离开写 aboard="false"。已有平台填事实清单中的 id，同批新建填该批次中唯一的单位全名。
- skills、traits 沿用“技能与效果”的写法，可分级特质写等级。近战、射击和盾牌技法按实际可用的相应装备发动。技能和特质本身不写件数。原文未提及时，可补充符合设定的技能与道具。

## 装备规格

- 武器机制选天生武器、轻型投射、爆破装置、剑、巨剑、短兵器、斧、巨型冷兵器、钝器、长兵器、重型长兵器、投掷冷兵器、弓、弩、火枪、步枪、霰弹枪、单发重步枪、机炮、直射火炮、火箭筒、曲射火炮、能量武器、喷射武器、法杖。
- 巨斧、大锤等双手劈砸兵器归巨型冷兵器；戟、关刀等归重型长兵器；投石索、手枪等归轻型投射；半自动、全自动枪械及轻中机枪归步枪；重机枪归低级机炮；单兵火箭归火箭筒，导弹归火炮；火焰喷射器等归喷射武器，普通施法武器归法杖。
- 盔甲类型选无甲、轻甲、中甲、重甲、超重甲；盾选小盾、中盾、大盾、能量盾。装备规格为“机制或类型L等级±修正”，L 取 1—10。

## 道具规格

道具效果取自规格。主体等级紧接类别，可分级效果各自标级。新增物品用 add 的 spec、qty 写规格和数量；reforge 写已有实物 id 与新 spec。

- 一次性：写“名称:类别L等级+附加词”，可分级效果各自标级，使用后消耗。如治疗药水:buffL3+治疗L3、手雷:物理范围L4+投射、烟雾弹:烟幕L2。
- 充能：在技能机制前加“充能+”。如火球魔杖:充能+魔法范围L5+热能。次数修正每点增减1次，每战至少1次，如多充能火球魔杖:充能+魔法范围L5+热能+2次数。
- 佩戴：写特质、属性修正或屏障。如夜视镜:夜战专精L5、守护戒指:佩戴L4+4防御、精灵斗篷:潜伏L3+林地专精L5+2防御、屏障护符:佩戴L4+屏障L4。
- 佩戴屏障每战首次入场自动获得一次，持续至破碎或战斗结束；同类取强，战内不自动恢复。
- 佩戴修正方向：伤害、精度、防御、生命、速度、士气、动能伤害、热能伤害、奥术伤害、动能防护、热能防护、奥术防护。
- 一次性、充能道具的机制与修正方向按“技能与效果”。
- 金币、材料、钥匙、信件等不写spec。

## 共用可选配置

生物体型：body=human/large/giant。
载具体型：smallvehicle（汽车）、mediumvehicle（坦克）、largevehicle（常规战舰）、hugevehicle（巨型星舰）、giantvehicle（死星等天体级巨构）。
载具武器稳定器：stabilized=true/false
护甲侧重防护：protection=balanced/kinetic/thermal/arcane（均衡/动能/热能/奥术）
武器属性：enchant=none/thermal/arcane（均衡/热能/奥术）

## 物品事件

| 事件 | 必填 | 可选与含义 |
| --- | --- | --- |
| add（新增） | item | spec：规格；qty：数量；to：接收单位，不写则入公共库存。支持武器、护甲、盾牌、道具和剧情物品。打扫战场所得按实际收回的物品与数量填写。 |
| add（增加数量） | id（实物） | qty：增加数量。 |
| give | id（实物） | to：一个或多个接收单位，不写则移回公共库存；qty：每个单位的数量。不同数量分写多条give。 |
| take | id（实物） | qty：扣减数量；note：原因。仅用于战外主动出售、丢弃、赠予或剧情消耗；战斗减员造成的装备损耗已由系统自动结算，严禁因单位阵亡、减员调用 take 扣减其装备 |
| reforge | id（实物）、spec | name：新名称。支持装备及各类道具。 |

add、give、take 可写 note。add（新物品）/reforge 可用 body、stabilized、protection、enchant 等该种类支持的配置。

## 修正（可选）

- 修正为可选，代表特性或低于高于平均值的程度与缺陷或特化，取值范围-10到+10。

- 单位修正写在 level 中，如 level="1+3精度+2生命"；platform 沿用单位修正，如 platform="封闭载具L5+4防御-1速度"。装备与道具的修正写在数量前，技能修正写在规格末尾。
- 同级修正不能替代技术跨代
```

## 战阵 V2 技能与效果（常驻）

```xml
<ability_effect_specs>
# 技能与效果(不同等级之间相差巨大，谨慎选择，善用±修正)

## 技能：spawn.skills或learn

新建填spawn的skills；已有单位明确学习/修改时用learn，必填id、skills。traits必须选择L等级(除了明确不能分级的那类)

- 每项统一写“名称:类别L等级+附加词”，无附加词时写“名称:类别L等级”。主体等级紧接类别，每个可分级效果也必须明确写L1—L10；按等级锚定选择，数值修正写在整项规格末尾。如“春风:buff范围L7+治疗L7”“穿心箭:物理单体L3+射击”。
- 机制以物理单体、物理范围、魔法单体、魔法范围、单体召唤、群体召唤、buff、debuff、火墙、毒雾、烟幕、治疗区域、陷阱之一开头。冲锋写“冲锋:物理单体L4+近战+突进L4”；只移动自己时可写“疾行:突进L3”“瞬步:闪现L3”“脱身:后撤L3”。
- 限定武器类型时，在物理单体/物理范围及其等级后以+连接近战、射击或盾牌；连接投射表示无需特定武器的远程技能，不连接则为通用技能。如“快速攻击:物理单体L2”“穿心箭:物理单体L3+射击”“飞石术:物理单体L4+投射”。魔法默认奥术，改热能时写“寒潮:魔法范围L6+热能+减速L3”。
- buff附加词：攻击、防御、伤害、动能防御、热能防御、奥术防御、动能伤害、热能伤害、奥术伤害、守护、加速、振奋、治疗、净化、回能、士气、屏障（屏障为护盾）；或直接附加下列规范traits名（如buffL1+飞行L1）。完整示例：“飞行术:buffL1+飞行L1”“构筑阵地:buffL1+工事L1”。
- 减益/伤害附加词：虚弱、攻击、防御、易伤、减速、定身、眩晕、缴械、沉默、诅咒、惊惧、士气、士气低下、重伤、中毒、流血、燃烧、驱散、耗能、击退、拉拽、嘲讽、魅惑、致盲、混乱；"攻击、防御、士气"表示降低。
- buff/debuff类别后可加范围，附加战技表示非魔法。buff/debuff须明确写出主体及效果等级，如“强攻:buffL4+攻击L4”“虚弱术:debuffL3+虚弱L3”。投送、能量、战技、效果均计入附加词。
- 物理范围、魔法范围附加词:扇形、直线、环形、连锁
- 主体等级和效果等级可以不同，均须明确填写。如“寒潮:魔法范围L6+热能+减速L3”表示范围魔法伤害L6、减速L3；“震慑旋斩:物理范围L4+近战+环形+惊惧L2”表示范围攻击L4、惊惧L2。治疗、控制、增益、位移和可分级traits均须明确标级；即使与主体同级也重复写出，如“春风:buff范围L7+治疗L7”。近战、射击、盾牌、投射、热能、奥术、战技、扇形、直线、环形、连锁只表示方式、通道或形状，不单独分级；不可分级traits仍按下列目录填写。
- 主体L是技能基础等级，各效果L决定对应效果强度；持续时间按各效果的规则及持续修正计算，buff主体等级不单独指定持续时间。
- 位移附加词，任何类别可加：突进（冲锋）出手前沿路线接近，近战从远处突进按冲锋结算；闪现出手前瞬移到视线内落点；后撤出手后拉开距离。
- 攻击、减益技能不加治疗、增益或traits，需要时分成两项技能；先锋部署不作技能效果。
## 获得与解除效果

- 单位获得持续增益、减益或外部授予能力时，使用effects属性。新单位写在spawn中，已有单位使用effect事件，id沿用单位资料里的编号。
- 每项写“effects=名称:buffL等级+效果L等级”或“effects=名称:debuffL等级+效果L等级”效果词、traits名及数值修正沿用技能规格。多个效果项以逗号分隔，每个可分级效果分别标L等级。
- 使用effects时，期限三选一：rounds或battles填1—99整数，或permanent="true"。等级决定效果强度，期限决定保留时间。
- 解除效果使用clear，按名称填写，多个以逗号分隔；clear=all解除全部当前状态与效果。

示例：
<spawn name="被祭司临时祝福的战士" side="ally" scale="hero" level="3" effects="风神赐福:buffL3+攻击L3+飞行L5" battles="2"/>
<effect id="u1" effects="风神赐福:buffL3+攻击L3+飞行L5" battles="2"/>
<effect id="u2" effects="寒霜侵蚀:debuffL2+减速L2" rounds="3"/>
<effect id="u1" clear="飞行"/>
<effect id="u2" clear="all"/>
```
