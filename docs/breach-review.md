# 分层城区/攻守城复查：1.6.1-rc.1

基底：PR #62，`c6495ebb5331a89069e19c6b79dee9315e605488`。这是测试候选版，不合并或替换 main；旧版安装与 test 版不可在同一宿主同时启用。安装前导出聊天及战斗存档。

## 已修正

**慢速通行。** 分层地图的合法地形单步费用，最多等于单位完整的基础移动力，而不是剩余移动力。移动力1可以耗尽该点跨过瓦砾、工事或其他可通行困难地形；移动力2只剩1时，仍不能进入费用2的地形。完整墙体、敌军占位、缺少航渡的深水、定身不因此失效。登城消耗主行动及 `min(2, 基础移动力)`。寻路、AI、预览、执行、UI共享规则。旧未分层地图沿用原费用。

**破障预算。** 之前已有1.5/1/.45/.18四档粗分类，本版是细化既有系数，并非从无到有。18种武器分类各自具有工程效率；结构只结算耐久，不冒用单位士气、暴击、毒伤、经验或护甲穿透。装备等级决定结构损伤基准，训练等级不自动升级武器。每次有效攻击的预算：同级标准墙耐久÷5×武器破障系数×装备伤害/强度/通道强化及固定波动×工程专长×有限编队接触正面×近战体型强度。单位人数不会无限放大同一墙段伤害；巨人体型不再无端放大远程炮弹。召唤群体保留分摊的攻击预算。

**结构行动合法性。** 手持武器缴械、实际射程、装填、近距离禁止展开、直射单位遮挡、长兵器近战阻挡均在预览及执行入口统一检查。独立法术不再借随身迫击炮获得曲射视线；缴械不再误禁天生武器与独立法术。空中或墙顶近战拆地面结构须先合法落地。无损伤攻击不扣空行动，未知mode被拒绝。技能仍正常扣SP、冷却和次数，武器技能也消耗对应装填。

**武技预算。** 高等级武器不能令低等级武技跳过技能等级上限；已有武技倍率中的通用强化不再重复叠加，专项通道强化与当前单体武技规则只作用一次。

**AI及路线。** 一个被深水/岩障隔开的缺口，不再令全体攻军误认为已有通路。普通城区的破障候选须确实缩短接敌路线，且绕路收益能覆盖拆除行动成本；无关民居不再因便宜的破坏分数吸引AI。对敌方占据的掩体和明确破障任务仍可攻击。施法拆墙计入资源机会成本。断桥救援/塌墙落点采用两步以内的真实连通搜索，不穿越完整墙体、岩障或敌军。

**指挥风格。** PR62已经对所有新分层战棋地图使用加强权重，不仅攻城。旧6%倾向在新图通常先放大至15%；激进攻击另加10%，机动相关移动加7%，偏好按0—4档作用。这里是候选行动效用分的偏置，不是命中/伤害加成。本版补齐新会战的评分版本保存，原13种风格不再有部分仅名字生效；旧会战快照不被自动改写。破障行动标明实际远程/近战类别，火力风格能正确识别，攻坚与破障偏好也直接影响候选。防区/预备队只适用于真实城防，海陆各类单位不会凭风格获得不存在的技能。无额外LLM请求或输出字段。

## 暂不增加海洋、太空环境枚举

本次不加入只有名字的场景。海岸/港口/舰船甲板局部战场可继续使用现有水域、桥/平台和城区要素表达；这不等于已有完整海战。完整海洋需要航行平台、登船/运输、失去船体后的生存与部署规则，不能把“航渡”直接当远洋舰艇能力。太空舰内走廊可用城区抽象，开放真空则需要独立推进、惯性/高度、舱体、减压及生存规则，不能把地面飞行直接改名。先稳定当前城战；未改环境解析器和内置世界书来声称支持这些场景。

仍未实现逐材质专属抗性、现场建造/修复、多层建筑内部、真正海空太空平台尺度切换。结构范围攻击仍不额外结算周边单位伤害，避免同一次动作重复结算。这些不属于已完成项目。
