# 3.0.8 边缘墙段与CI回归

用户明确缺口位于靠地图边缘墙段的两个端头。线状城墙原来只连各格格心，再用44宽墙身封端；端头在最外格时仍距图边28个SVG单位，画面看起来留下两处开口。现在仅对真实存在且完好的边缘端头，沿原连线补到该格的地图边界；横竖与斜线共用处理，墙身、顶面和垛口保持一致。内部断点、已毁边缘格不会被延长或重新接上。显示读取实际结构，不修改保存地图。浏览器复核图保存在本地artifacts/ring-boundary-20261025/preview.png。

ring在四个边角的分区样例使用关闭城门、零破口，检查城外地面不可进入任何城内格；双重墙触边、实际相邻墙头移动和快照恢复保留验证。不增加门楼连桥，不改提示词。

3.0.7的CI共8项失败，其中3项是新增失败，另外5项为既有unified-replay基线。新增问题分别为：

- 旧式中央城市的front不再转换为围合，扩成全地图后没有可用城门。恢复原中央保护；编号分区front的开放设计不受影响。
- 双重围城在东西侧占地较窄时静默降级单墙。明确请求两层且非compact时返回容量错误，让既有生成循环扩大地图；compact继续保留原单墙回退。
- 旧楼梯测试把不在正面frontage上的外墙误判为内墙。改用完整城区外缘识别外墙，保留“外墙楼梯通夹道、内墙楼梯通城内”的断言。

Release channel gate的失败还包含时序问题：任务检查固定的PR head，但main在合并后已经前进到该PR自身的合并提交，旧head不可能包含它。改为验证PR事件记录的base SHA，保留test必须包含晋级基准的要求。

本次运行相关定向检查、类型检查、原生构建与verify:dist；按此前授权发布test及main，不等待CI。未改历史失败允许列表，不把未运行的完整CI称为通过。
