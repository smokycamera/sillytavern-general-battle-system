# 技能系统审计：位移技能、解析纠错与冗余计价（V14 skills-v1，2026-10-11）

基线：`153024e`（test）之上的 V13 特质翻修与装备去重（与本改动同批推送，是它前面的两个提交），下文“改动前”都指这两个提交之后的状态。新开的战斗使用新规则 `v14-overflow-d20` / `v14-overflow-tw`（在 V13 上增加 `skillModel: 'skills-v1'`）；进行中的 V2–V13 战斗与读档仍按原规则结算。新增的位移写法和正文解析修正只影响新写的技能，不需要规则开关。

## 现象

按“全不全、对不对、有没有重复”三方面过了一遍技能写法、编译、战斗结算、AI 与正文解析，并用正文常见写法实测（`artifacts/skill-audit/narrative*.ts`）。

### 不全面：没有任何“移动自己”的技能

- 效果原语只有伤害、治疗、状态、授予特质、推/拉目标、驱散、资源、士气、召唤、屏障和持续区域，没有施术者自身的位移。冲锋只存在于普通动作里（还要求机动兵种或冲锋强化），技能里写不出来。
- 正文写 `冲锋:物理单体+冲锋L4`、`冲锋L4`、`突进:物理单体+突进L5`、`闪现:buff+闪现L5`、`瞬移L6`、`跃击:物理单体+跳跃L5` 全部被丢弃（“未支持的技能机制”）。
- 世界书自己的示例 `冲锋:物理单体+近战L4` 只是原地一记近战技法：名字叫冲锋，但目标必须已经贴身，不会移动、不算冲锋。
- 想要“回马箭”“后撤步”只能写 `buff+身法`（只授予脱离不吃借机的特质，本身不移动）。

### 有误

1. **作用方向相反的效果照单全收。** 解析器允许任何类别加任何效果词，执行时效果一律打在技能目标身上：
   | 正文写法 | 实际效果 |
   | --- | --- |
   | `吸血斩:物理单体+治疗` | 砍敌人一刀，再给这个敌人回血 |
   | `物理单体+飞行` | 打完让敌人获得飞行 |
   | `debuff+屏障` | 给敌人加护盾 |
   | `buff+眩晕`、`buff+燃烧` | 晕倒/点燃自己的友军 |
2. **旧预制技能名被当成新写法。** 正文里出现旧版九类简称或旧技能名时，落到旧蓝图上，而且按名字互相包含去猜：
   | 正文写法 | 改动前得到 | 问题 |
   | --- | --- | --- |
   | `护体:防御L3` | 铁壁 | 必须持盾，法师学了用不了 |
   | `诅咒L5` | 诅咒之箭 | 变成伤害法术，不是减益 |
   | `冲撞:冲击L4` | 冲击波 | 魔法推人 |
   | `盾L3` | 盾击 | 包含“盾”字就算 |
   | `重击L5`、`横扫:旋风斩L5` | 旧蓝图 | 与新通用机制两套数值并存 |
3. **授予后没有作用的特质。** `buff+先锋部署` 能学会、能施放、能扣精力，但先锋部署只在开战部署时生效，战中授予什么也不做。

### 冗余

1. **“守护”有两份。** 增益效果“守护”（祝福：减伤，随等级缩放、带防御规格）和特质“守护/大守护”是同一种减伤，同组取强、不叠加。写 `buff+守护` 得到的是前者，世界书却把守护也列为可授予的特质名；授予特质不随等级变强，L1 的 `buff+大守护` 就有 −40% 减伤，同价位的增益守护只有 −12%。
2. **复合状态以一项的价格压过单项。** 技能每加一个效果词按一项计价（效力按项数开方分摊、抵抗难度每多一项 −2、精力 +1）。但几个状态本身就改两项属性：
   | 状态 | 改动 | 被它压过的单项 |
   | --- | --- | --- |
   | 诅咒 | 攻击−2、防御−2 | “攻击”（失准，攻击−2）、“防御”（破绽，防御−2） |
   | 重伤 | 攻击−2、先攻−1 | “攻击” |
   | 惊惧 | 攻击−2、士气−10 | “攻击”（对无免疫目标） |
   | 士气低下 | 攻击−1、士气−15 | — |
   | 振奋 | 攻击+1、士气+10 | — |

   同类修正取强、不叠加，所以写“攻击”或“防御”的减益在诅咒面前毫无理由存在；`debuff+攻击+防御`（两项）比 `debuff+诅咒`（一项）更贵、更弱。
3. 旧版预制技能（`bp-*`）、更早的固定模板（轨道打击等）和通用六类机制三套并存。前两套只为旧存档保留，但正文新写的旧技能名仍会落到 `bp-*`（见上）。

## 原因

- 位移：技能效果原语里没有施术者位移，执行器与 AI 也没有“先移动再出手/出手后再移动”的结算顺序。
- 方向相反：解析器在识别效果词时把类别外的词也纳入候选（原意是容错），编译器再按类别决定目标阵营，所有效果都作用在同一目标上。
- 旧名：正文解析在通用机制解析失败后按旧蓝图精确名、九类简称、名称互相包含依次兜底，直接返回旧蓝图。
- 冗余：特质库与状态库各自扩充，技能词表把两边都收进来；计价只数效果词个数，不看一个状态实际改几项。

## 修改

### 1. 位移技能（新写法，不需要规则开关）

新增效果 `move`，三个效果词，任何类别都能附加：

| 效果词（别名） | 时机与方式 | 小战 | 会战 |
| --- | --- | --- | --- |
| 突进（冲锋、冲刺、突击、飞扑、扑击、前冲） | 出手前，沿可走路线 | L1–3 走2格、L4–7 3格、L8–10 4格；地形照常计价；途中照常触发借机与警戒 | 一个阵位 |
| 闪现（瞬移、传送、闪烁、瞬步、缩地、影步） | 出手前，直接落位 | L1–2 1格、L3–5 2格、L6–8 3格、L9–10 4格；落点须在施术者视线内、可落脚，不跨平台层；不触发反应 | 技能能走3格以上时两层，否则一层 |
| 后撤（撤步、后跳、跃退、脱离、翻滚、后退） | 出手后，沿可走路线 | 与突进同格数；自动退到离已知敌人最远处，同样远时朝本方后方；不触发近战借机，仍受警戒射击 | 退一层，远离敌军 |

- 射程强化同样延长位移；减速时突进/后撤少走1格；定身、眩晕时不能位移。技能位移不占本回合移动点，用完还能照常走。
- 出手前位移只在需要时发生：原位已能出手就不动；否则找最近的、能对目标出手的落点。找不到落点时整次不扣费。
- **冲锋**：以实际近战武器出手、目标原本不在接触距离、确实移动了、路线没有涉水/沼泽/碎石/工事，且自身没有疲劳惩罚、没受压制、没减速，就按冲锋结算——冲锋强化、拒马固守、践踏等照常生效，战报写“突进至D3，冲锋”，体力消耗（疲劳）与普通冲锋一样多算1点。不要求机动兵种或冲锋强化（技能本身就是训练）。
- **单写位移词**是只移动自己的技能，目标是落点（小战选格子、会战选阵位）：`突进`、`闪现`、`后撤`。单写 `冲锋`（也包括突击、飞扑、扑击）= `物理单体近战+突进`。物理技能里写冲锋类词而没写投送方式时按近战。突进与闪现都是出手前的接近方式，同一技能只取最后写的那个。
- 计价：位移算一项附加效果（伤害分摊照常，精力+1）；只有位移的技能冷却2。V9 起的耐力模型按“2+⌈L/2⌉+(效果项数−1)”报出实际精力：冲锋 L5 为6点（同级普通近战技5点），闪现 L6 为5点。突进、后撤是身体动作；闪现默认是法术（沉默时不能用），加“战技”写成非魔法的瞬步。
- 战报顺序：出手前的位移在技能本体之前，后撤在之后；会战里位移与效果同步生效，后续任务看到的是到位后的阵位。随队人物在会战里随所属编队行动，不能独立位移。
- AI：小战从当前位置和候选走位点评估突进/闪现出手（按落点计算命中与伤害、途中反应损失、落点受击与冲锋加成），出手后后撤按落点与原地的位置评分、受击估计之差计入；只有位移的技能先按位置评分粗筛6个落点再细算，主要用于被贴身时无借机脱离。会战按位移后的阵位估算，单纯位移按机动的同一口径减去技能消耗。

### 2. 正文与面板解析纠错（只影响新写的技能）

- **方向相反的效果不再成立。** 攻击与减益技能不能附带治疗、增益或授予特质，增益技能不能附带伤害或控制；召唤、烟幕、治疗区域、陷阱按阵营生效，任何类别都能带。面板与严格解析拒绝这类写法；正文容错剔除冲突的词并逐项说明，例如“吸血斩:物理单体+治疗L5：已忽略「治疗」——写在攻击/减益技能里会作用到敌人，请另学一项技能”。剔除后什么都不剩的增益/减益整项不采用，不会悄悄换成默认效果。已学的旧技能照常结算，面板编辑时没改动的效果名沿用原定义。
- **旧技能名换成通用机制**并留下说明（呼叫援军、亡者苏生没有通用对应，保留原定义）：防御→增益防御，士气伤害/恐怖嚎叫/攻心之计→减益范围惊惧+士气，士气鼓舞/战歌/勇气号角→增益攻击+士气，重击/致命刺杀→物理单体近战，旋风斩→物理范围近战，破片手雷→物理范围投射，奥术箭/圣光惩击→魔法单体，诅咒之箭→魔法单体诅咒，烈焰风暴→魔法范围热能，冰霜新星→魔法范围热能+减速，铁壁/圣盾→增益防御，治愈之光/战场急救→增益治疗，束缚术→减益定身，盾击→物理单体盾牌+击退，冲击波→魔法单体击退。单写一个效果词时先按增益、再按减益理解（`诅咒L5`→减益诅咒，`加速L3`→增益加速，`飞行L5`→授予飞行）。
- **先锋部署**不再作为技能效果（说明“只在开战部署时生效”）；**守护、大守护**写成技能效果时按增益守护处理，强度随技能等级（说明“「大守护」作为技能效果按「守护」处理”）。已学的旧授予技能照常结算。
- 单位编辑器的效果候选加了冲锋、物理单体近战+突进、物理单体射击+后撤、魔法单体闪现、突进、闪现、后撤，说明文字补了位移用法。

### 3. V14 计价（skills-v1，只对新战斗）

同时改两项属性的状态（诅咒、重伤、惊惧、士气低下、振奋）按两项附加效果计价：效力、抵抗难度、伤害分摊与精力消耗都与分别写两个单项一致。按状态实际改动的属性项数计，规则一句话就能说清，不另设权重表。

| L5 技能 | V13 | V14 |
| --- | --- | --- |
| debuff+攻击 | 精力3，失准×1.00，DC13 | 不变 |
| debuff+攻击+防御 | 精力4，两项各×0.71，DC11 | 不变 |
| debuff+诅咒 | 精力3，诅咒×1.00，DC13 | 精力4，诅咒×0.71，DC11 |
| debuff+重伤 / 惊惧 / 士气低下 | 精力3，×1.00，DC13 | 精力4，×0.71，DC11 |
| buff+振奋 | 精力3，×1.00 | 精力4，×0.71 |
| 物理单体近战+诅咒 | 武器倍率1.98 | 武器倍率1.78 |

表里的精力是技能自带的标价；V9 起的耐力模型按“2+⌈L/2⌉+(效果项数−1)”报出实际消耗，V14 下这个项数同样按两项计：L5 诅咒实际 5→6 点，与“攻击+防御”相同。

做法与 V12 `armsModel`、V13 `traitModel` 相同：`prepareSkillModel` 按战斗规则给单位写入或清除 `skillModel`，`upgradeCombatSkills` 只在统一伤害模型且带 `skills-v1` 时把技能重建为 `skill-v7.0`（区域技能 `skill-zone-v4`），从原始配方重建一次，身份、等级、强化与冷却账本都保留。读档的旧战斗没有这个标记，已编译的技能原样结算。

## 验证

生成脚本都在 `artifacts/skill-audit/`（本地，不入库）。

- 冻结：在改动前状态的独立工作树与改动后分别跑 `frozen-skills.ts`（3 个场景 × 6 个种子 × V12/V13，AI 对战共 36 局、149 次技能施放，覆盖近战/范围/定身/燃烧/治疗/诅咒/击退/拉拽/惊惧/攻防增益/毒箭/火墙/飞行/召唤/守护/屏障/重伤/沉默/士气低下/振奋/易伤/连锁/会战惊惧与治疗），每局数值事件流与终局状态的哈希全部一致；V13 特质翻修的冻结场景（`artifacts/traits-overhaul/audit.ts --frozen`）与当时记录逐字相同。
- 新测试 `engine/tests/skill-movement.test.ts`（9 项）：写法与别名；冲锋从3格外接敌并带冲锋强化、贴身时不算冲锋；位移先于出手记入战报、不占移动点；够不着/被定身时整次不扣费，贴身时定身不影响出手；闪现与后撤不吃借机、突进吃借机；后撤朝本方后方退；AI 先走位再冲锋、远程被贴身时闪现脱离；会战突进冲锋、闪现两层、后撤一层、突进不能一次走两层；正文剔除与旧名说明；V14 诅咒与“攻击+防御”计价一致（含耐力模型实际报价），V13 不变。
