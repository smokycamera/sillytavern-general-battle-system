## 喷射火力

新开战使用 V34。喷射武器的普通攻击与武器技法伤害乘2，对剩余人数多于1的编队再乘1.25；单体英雄与只剩一人的编队不吃群体加成。预览、AI评分和实战共用同一修正。仍每战3次，主副武器分别计燃料；扇形目标、会战范围衰减、惊惧、燃烧和燃料箱破裂维持既有规则。燃料箱爆炸的显式伤害不乘2，也不吃群体加成。旧战斗仍从原规则编号恢复，不改写实物配方。

顺带修正两处同路径问题：对结构喷射也检查和消耗燃料，不能无限破墙；抽样预览缓存区分格子喷射与会战波及，避免同一输入先查小战后查会战时错误复用伤害。

## 两栖优先

有效“两栖”与“航行”同时存在时，按两栖处理：保留合法陆地部署，可以水陆移动和使用原本合法的平台/桥梁路线；载具、骑乘和武器图标按原规则显示。只剩航行时恢复水域限制及船图标。统一影响移动、部署、寻路、地图容量和副API单位机动信息的判定，不更改世界书正文。

## 墙门攻击与堵路反馈

整轮 `attack` 接受 `target` 指定单位，或 `cell` 指定已探索且完好的结构。程序接近合法攻击位置，选择可用主副武器或直接伤害技能，沿用射程、视线、友军遮挡、行动、资源和耐久校验。保存的意图保留结构格，目标毁坏后不擅自转去其他区域。

寻路未找到完整路线时记录实际执行反馈，包含目标及当前可见的墙门、单位占位、地形或高度连接阻碍；不会把隐藏单位或未见结构当作原因公开。路线存在但本轮移动/行动额度不足则单独记录为暂时限制。完全无法靠近时也会记录，不再静默停住。

最近一轮与当前轮的己方失败事件会保留在指挥观察中，避免被最近12条事件窗口挤掉。逐轮指挥在下一轮收到；局势变化模式可因新出现的不可通行反馈重新规划一次，暂时额度不足不触发该重规划。不会每个单位都重新询问。

## 两步生成各5次

开战决策与地图布置各自最多5次请求（含首次）。第五次决策成功后，地图布置仍有完整5次；地图失败保留已成功决策，仅重做地图。第五次地图失败才按已有规则采用可生成部分或本地回退，航行无水同样等到第五次。

每步保存最多5组失败原回答及对应错误，决策通过 `state.previousAnswers`，地图通过已确认的“此前失败回答”行回传；错误摘要也保留至5条。首次/手动重试预算独立，历史仅在相同聊天、正文、设置和有效期内复用，成功、取消或上下文变化后清空。无效JSON保留原返回文本。连接、密钥、超时错误不重复请求；战斗中的指挥重试仍沿用3次，不被本次开战预算影响。
