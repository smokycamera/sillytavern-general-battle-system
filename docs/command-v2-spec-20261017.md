# 2.3「统帅」执行规格（规则 V19 / command-v2）

日期：2026-10-17。设计：Claude。起点：2.2 合入后的 test 最新提交（规则 V18）。

同日按用户意见修订：

- 风格不加数值，只改变单位行为；
- 去掉统帅加成；
- 不引入新的指挥官机制；
- 水平只通过 AI 的决策质量体现，并且决定风格执行得多极端。

执行规范见 [executor-rules.md](executor-rules.md)，全部适用。总计划见 [next-update-direction-20261017.md](next-update-direction-20261017.md)。10-17 复核后修正的地方，列在总计划的"本次审查修正"一节。

## 目标

本版**不给任何数值**：不加命中、防御、先攻、士气、移动或伤害，不改单位属性。

- **水平**：只体现在 AI 决策上。同样的部队，大师明显打得比常规好，新手明显吃亏。
- **风格**：只改变 AI 的打法，包括在什么距离交战、何时推进、先打谁、队形松紧、多怕暴露、何时撤退、怎样增援。每种风格都要有自己占优和吃亏的局面。
- **两者的组合**：水平决定风格执行得多极端。新手会把倾向放大，例如"新手 + 积极进攻"会不顾一切地莽；大师则按局势收着用。
- 水平和风格要在界面上看得到。

## 现状

**指挥档案**（`engine/src/commander-profile.ts`）：

- 水平只决定 AI 估值的随机误差：新手 ±18%、常规 ±10%、熟练 ±5%、专家 ±2%、大师 0；
- 风格只是给某类候选加 6%–25% 的偏好，其中几对风格的计算公式完全相同；
- 10-15 审计里，五档胜场是 37/31/31/32/35（各 60 场），看不出强弱。

**本版不改动、保持原样的机制**：

- **统率特质**：指挥光环，在小战 3 格、会战 1 阵位内让友军士气+10，并抵消恐惧压力；
- **我方指挥官**：花名册的"设为指挥"（⚑）。会战里指挥倒下后，我方转为自动军令；胜利时指挥官获得指挥经验。

## 1. 数据

水平和风格直接读战斗上已有的 `commanderProfiles[阵营]`（已随快照保存），不往单位上另写字段。

- 单位按它当前所属的阵营取档案：被魅惑而换边的单位，用新阵营的档案。
- 没有档案的一方按"常规·均衡"处理。这是 V19 的行为变化：现在没有档案时，`commanderScores` 不加估值误差，城战团队分工按纵深防御取预备比例；V19 起统一按常规（±10%）和均衡处理。

战斗中另外记录以下三项，随快照保存，供风格的反击、拦截、增援判断使用：

- 本轮已被各方攻击过的目标；
- 本轮攻击过各方的单位；
- 各单位在本轮开始时的位置。

### 2.1 水平和风格怎样相互影响

**新手**：风格倾向放大 1.5 倍，危险只按一半估计，估值误差最大。

| 风格 | 新手的表现 |
|---|---|
| 积极进攻 | 不顾一切地莽：冲进就绪的长枪范围，孤军追击残敌 |
| 谨慎保全 | 畏缩不前，宁可原地挨打也不推进 |
| 伏击固守 | 敌人已经打上门了，仍然死等 |

**大师**：风格倾向打七折，危险按 1.5 倍估计，没有估值误差，还会做配合预判和方案比较。

| 风格 | 大师的表现 |
|---|---|
| 积极进攻 | 看准有利时机才冲，冲之前先用远程或控制开路 |
| 谨慎保全 | 稳步推进，不放过安全的击杀机会 |

**常规、熟练**：按风格本来的样子执行。

### 2.2 配合预判

**适用的候选**：会给目标施加以下效果之一的动作：

- 眩晕、定身、致盲、缴械、混乱、魅惑、嘲讽；
- 压制；
- 破绽、易伤；
- 击退或拉拽，使目标进入己方拒止范围。

**后续攻击 f(友军, 目标)**：一次有界的预览，不重跑友军的整套候选生成。

- **小战**：
  - 友军当前所在格能合法攻击目标，就用这一格；
  - 否则取它本次激活移动力内能到达、能合法攻击目标、路径代价最小的一格（同代价取格号小的）；
  - 都没有则 f = 0；
  - 在这一格对目标做一次 `previewAttack`，f = min(目标剩余生命, 期望伤害) + conditionValue；
  - 每个友军的可达格在一次决策内只算一次。
- **会战**：该友军对目标的 attack、volley 两种军令各做一次 `orderPreview`，取较大的值，算法同上。

**"下一个友军"**：

- 小战：本轮尚未行动的己方单位中，先攻顺序最靠前、并且对该目标 f > 0 的那一个；
- 会战：本轮能合法攻击该目标的己方编队中，f 最大的那一个。

只算一个友军，不往下递归。

**加分**：候选分 + 配合预判系数 × P × Δ。

- Δ = f(友军, 效果生效后的目标) − f(友军, 效果生效前的目标)。"生效后的目标"是目标的副本加上该状态（`applySkillCondition`）；击退、拉拽则把副本移到落点。
- P 是该候选预览给出的命中或生效概率，与现有 `skillEffectValue` 计算控制价值时用的概率相同。

### 2.3 方案比较（只有大师）

**会战**（在 2.1.1 的火力预算之后做）：

1. 先按现有顺序（单位 id 排序）贪心分配完全部军令。
2. 再试"改派"。按得分从高到低，最多取 10 条己方攻击军令 A→X。对每一条，找另一个己方编队 B 和另一个目标 Y，满足：
   - A→Y、B→X 都合法（`v2OrderReason` 为空）；
   - B 原来没有攻击军令，或原军令得分低于 A→X。
3. 计算总价值：Σ（击倒概率 × 目标价值 + 期望伤害）。
   - 击倒概率用 2.1.1 的 `killProbability`；
   - 目标价值取目标当前生命（编队按成员生命）。
4. 改派后总价值提高就保留。

**小战**：

1. 取分数最高、并且与最高分相差不超过"比较阈值"的候选，最多 3 个。阈值初值 10%，是 §5.1 的旋钮。只有一个候选时不比较。
2. 对每个候选 c，算"下一个友军"（§2.2 的定义，但不要求它能打到 c 的目标）的最佳后续攻击 V(c)：
   - c 是攻击、目标为 X 时：V(c) = max( max_{Y≠X} f(友军, Y), (1 − p) × g )。
     - p = `killProbability([c 的预览], X 的剩余生命)`；
     - g = min(max(0, X 的剩余生命 − c 的期望伤害), 友军对 X 的期望伤害) + conditionValue。
   - c 不是攻击时：V(c) = max_Y f(友军, Y)。
3. 选"候选分 + V(c)"最大的那个。

**预算**：每次大师决策额外的预览调用，不超过 3 ×（可见敌人数 + 1）次。

## 3. 风格：只改变行为

风格不给任何数值。每种风格是一组行为参数（§3.1），每个参数取值对应 AI 候选评分里的一项（§3.2）。

在 command-v2 下，`commanderScores` 用下式取代原来的风格偏置：

```
候选分 = 原分 + scale × (s × 风格执行系数 × Σ(行为项) + 估值误差 + 偏好项)
```

- **scale**：沿用现有 `commanderScores` 的 `Math.max(1, 本次最高候选分)`，所以最高分为负或为 0 时也有定义。
- **s**：全局风格权重，初值 1，范围 0.5–2.0，步长 0.25。
- **风格执行系数**：见 §2。
- **估值误差**：沿用现有的确定性哈希扰动。
- **偏好项**：玩家写的 risk、counterattack、breach 三项照原来的方式加分，每级步长从 0.025 改为 0.05。
- 原来的风格偏置（`bias` 和 tactical-v2 的各项加成）在 command-v2 下整段不用。

### 3.3 名词定义

| 名词 | 定义 |
|---|---|
| 接近度 | 这次移动缩短的、到最近可见敌人的距离 ÷ 移动力，截断在 0–1 |
| 暴露度 | 落点的来袭期望伤害（已乘来袭估值系数）÷ 当前生命（编队用当前成员生命总和），截断在 0–1 |
| 不在同一侧 | 以该敌人为原点，已缠斗友军的方向与落点的方向点积 ≤ 0 |
| 前沿区域 | 距我方任一单位 4 格以内 |
| 进入前沿区域 | 敌人本轮开始时不在前沿区域，现在在 |
| 第二线 | 落点到某个已接敌友军的距离为 2–3，并且落点到最近敌人的距离比该友军大 2 以上 |
| 后撤 | 移动后到最近可见敌人的距离比移动前大；会战中为后撤军令 |
| 接敌 | 与敌人相邻；会战中为阵位距离不超过 1 |
| 核心单位 | 本方当前生命最高的英雄（同分取 id 小的）；没有英雄时，为人数最多的编队。只供"核心固守"使用，与指挥官无关 |
| 远程、火炮、施法目标 | 主武器带 `ranged` 标签，或有魔法伤害技能 |
| 被友军缠住 | 现有的 `flanked` 判定（`situational-traits.ts`） |

**会战换算**：

- 格子距离改为阵位距离；
- "贴近同一敌人，且不在同一侧"改为"与已接敌友军攻击同一目标，且所在阵位不同"；
- "2 格内"改为"同阵位或相邻"。

### 3.4 实现

小战和会战的候选生成器给每个候选附上计算行为项所需的特征。只加以下字段：

- **目标相关**：目标 id、是否被缠住、本轮是否已被攻击、是否为远程/火炮/施法单位、是否在工事中、是否在核心单位附近、本轮是否攻击过己方、本轮是否进入前沿、击倒概率；
- **落点相关**：接近度、暴露度、是否后撤、最近友军距离、到核心单位的距离、是否在前沿线或第二线、路径与敌方近战单位的最小距离；
- **自身相关**：是否远程主武器、射程和触及内是否有敌人、当前生命比例、是否接敌。

行为项写成纯函数 `styleTerms(style, features)`，与估值误差、配合预判分开。

**必测**：对 `styleTerms` 写一个表驱动测试。§3.2 每个非零取值一行，验证在对应特征下得到表中数值，其他特征下为 0。

### 3.5 与其他控制的先后

| 情况 | 决定 |
|---|---|
| 玩家手动操作的单位 | 不受风格和水平影响 |
| 我方托管战术（`allyTactic`：积极、固守） | 照旧。积极的攻击加分在风格项之后加；固守只保留原地候选，这个限制优先于任何风格 |
| 区域职责（`regionalOrder` 的守点、占领、城防分工）和任务目标（夺点、护送） | 照旧决定候选的目标格，风格只在候选之间调整分数；守点按 §8 第 8 条（10-18 修订） |
| 被魅惑、混乱的单位 | 按现有控制规则行动；被魅惑的单位按当前阵营的档案估值 |

### 4.1 打法说明（照抄）

| 风格 | 说明 |
|---|---|
| 均衡 | 按局势选择进攻、防守和支援 |
| 积极进攻 | 尽快接敌，优先打能击倒的目标，不惧暴露 |
| 谨慎保全 | 保持射程，结伴推进，避开暴露位置，伤重就撤 |
| 迂回机动 | 贴近敌人，围攻已被缠住的目标，从侧面加入 |
| 集中火力 | 远程保持射程，集中打同一目标，结伴推进 |
| 伏击固守 | 敌人进入范围前按兵不动，避开暴露 |
| 稳步攻坚 | 结伴推进，优先打工事里的敌人和破障，掩护工兵 |
| 渗透袭扰 | 绕开敌方近战，直扑远程、火炮和施法单位 |
| 游击消耗 | 保持在敌方近战触及之外射击，伤重就撤 |
| 前沿坚守 | 在前沿结成战线，拦截进入前沿的敌人 |
| 纵深防御 | 分层布置，第二线接应，伤重的单位后撤 |
| 机动防御 | 预备队向被攻击的友军增援，反击来犯之敌 |
| 核心固守 | 守在核心单位身边，优先打接近它的敌人 |

## 5. 验收

### 5.1 水平窗口

**设置**：

- 双方同阵容、同为均衡风格，只改变水平；
- 阵容使用 `artifacts/weapon-review/mixed.ts` 的 6 套；纯英雄阵容只跑小战；
- 小战每套 24 个种子 × 交换阵营；会战每套 12 个种子 × 交换阵营。

| # | 对局 | 目标胜率 |
|---|---|---|
| T1 | 大师 vs 常规 | 58–75% |
| T2 | 专家 vs 常规 | 53–68% |
| T3 | 熟练 vs 常规 | 50–62% |
| T4 | 新手 vs 常规 | 25–45% |
| T5 | 大师 vs 新手 | ≥68% |

另外要求单调：五档对常规的胜率随档位上升。

**旋钮**：

| 旋钮 | 初值 | 范围 | 步长 | 管哪个窗口 |
|---|---|---|---|---|
| 新手估值误差 | 0.18 | 0.12–0.30 | 0.03 | T4 |
| 大师比较阈值 | 10% | 5%–25% | 5% | T1；§5.4 的性能窗口优先 |
| 大师来袭估值系数 | 1.5 | 1.0–1.5 | 0.25 | T1；只在比较阈值用完仍不达标时才动 |

- 大师比较阈值调大会更常触发比较，性能超限时就停在最后一个不超限的值。
- T2、T3 不单独设旋钮，只报告。

### 5.2 风格窗口

**比较方式**：

- **有利场景**：我方分别用该风格和用均衡各打一组，敌方为常规水平；敌方风格为均衡，下表另有注明的按注明。用该风格时的胜率要比用均衡时至少高 8 个百分点。
- **通用镜像场景**：2 剑+2 弓 vs 2 剑+2 弓，平原。该风格对均衡的胜率要在 40–62% 之间，保证没有通吃的风格。
- 双方都是常规水平。
- **样本**：只靠行为拉开差距需要更多样本。小战每组 48 个种子 × 交换阵营，共 96 局，误差约 ±5 个百分点。

| 风格 | 有利场景（我方 vs 敌方；地图） |
|---|---|
| 积极进攻 | 4 名近战英雄（剑、斧，中甲 L5）vs 4 名弓手（轻甲）；平原 |
| 谨慎保全 | 4 名步枪英雄 vs 4 名近战英雄（敌方积极进攻）；平原 |
| 迂回机动 | 4 名近战 vs 4 名近战，配置相同；平原 |
| 集中火力 | 4 名步枪 vs 4 名步枪；平原 |
| 伏击固守 | 我方 4 名弓手在森林中防守，敌方 4 名近战须穿过森林；森林 |
| 稳步攻坚 | 我方 4 步枪 + 1 爆破 vs 敌方 4 步枪据守工事；城镇 |
| 渗透袭扰 | 我方 4 名轻甲剑 vs 敌方 2 名剑盾前排 + 2 名弓手后排；森林 |
| 游击消耗 | 我方 4 名轻甲弓手 vs 敌方 4 名重甲剑（速度 2）；平原 |
| 前沿坚守 | 我方 4 名矛兵（中甲）防守 vs 敌方 5 名剑进攻；平原 |
| 纵深防御 | 我方 4 名剑盾防守 vs 敌方 6 名剑进攻；平原 |
| 机动防御 | 我方 2 名骑兵 + 2 名弓手 vs 敌方 4 名剑（敌方迂回机动）；平原 |
| 核心固守 | 我方 1 名法杖英雄（生命最高，即核心单位）+ 3 名剑盾 vs 敌方 4 名剑；以法杖英雄是否存活判胜负；平原 |

**会战抽查**：四种风格各用一个 3 对 3 编队场景，平原，默认阵位，L5、T5，每个编队 20 人（另有注明的除外）。要求比均衡至少高 5 个百分点；每组 24 个种子 × 交换阵营。

| 风格 | 场景（我方 vs 敌方） |
|---|---|
| 积极进攻 | 3 个剑编队（中甲）vs 3 个弓编队（轻甲） |
| 集中火力 | 3 个步枪编队 vs 3 个步枪编队，中甲 |
| 纵深防御 | 3 个剑盾编队防守 vs 3 个剑编队，敌方每队 30 人 |
| 机动防御 | 2 个骑乘剑编队 + 1 个弓编队 vs 3 个剑编队（敌方迂回机动） |

**调参顺序**：

1. 先调全局风格权重 s；
2. s 定下后，仍不达标的风格，把它最主要的一个行为项（§3.1 中该风格与均衡不同的第一个参数）权重调一档（±0.05），只调一次；
3. 还不达标，标"已实现但未达标"。

调参途中的运行用 1/4 样本，初值和最终复测用全样本（执行规范 §4）。

## 8. 10-18 接手修订

实现时补的决定。第 8 条是用户 10-18 提出"防守没必要蜷缩在点里"后定的。

| # | 决定 | 原因 |
|---|---|---|
| 1 | 本轮记录保留本轮和上一轮两条：小战在每轮开始、会战在军令执行开始各开一条。"本轮被攻击过、攻击过本方"取两条合并；"进入前沿"用较早一条的开始位置 | 小战按先攻依次行动，先动的单位看不到上一轮后动的敌人；会战军令在执行前定好，只能看上一轮 |
| 2 | 来袭估值系数乘在：小战的落点来袭、途中反应的损失与阵亡风险、固守减伤、工事价值；会战的拒止反击与离场反应。位置评分里的启发项（贴身距离、离开接触计数）不乘 | §2 只说"来袭/威胁估值项" |
| 3 | 会战换算按约 2 格折 1 阵位：4 格→2 阵位，"3 格以内"→1 阵位，"3 格以上"→2 阵位，第二线的 2–3 格→1 阵位、"大 2 以上"→1 阵位以上 | §3.3 只写了"2 格内=同阵位或相邻" |
| 4 | 会战"后撤"是落点离最近敌人更远的机动（如后撤一列），不是撤离战场军令 | `retreat` 军令是撤离战场 |
| 5 | "火力预算判定必倒"：己方已下达攻击的击倒概率 ≥95% | 2.1.1 的火力预算是连续值 |
| 6 | 配合预判的 P 取该技能第一个控制状态的生效概率；生效后的目标按（友军、目标、状态、推拉落点）只预览一次；预算用完时不加分 | 多状态技能；守住 §2.3 预算 |
| 7 | 夹击里"移到不同侧"一项不再要求移动：小战照旧只在移动候选上判断，会战按 §3.3 是"与已接敌友军攻击同一目标且阵位不同" | 会战攻击不一定移动 |
| 8 | **守点：防区是锚点不是笼子**（只在 V19）。适用正文"驻守、占据"的防区，以及有攻守方的夺点里守方的目标格；对称夺点、城防分工不变。① 到防区路径代价不超过自身移动力的格子都算防区内，位置评分不因离开防区扣分，超出部分照旧每格扣 1.5；② 敌人站上防区格时取消这段活动范围，必须上点争夺或把它打下来；③ 活动范围内的单位被射手攻击过（本轮或上一轮），从活动范围内哪一格都打不到它，而敌方近战一次激活内打不到防区时，去打两次激活内够得到的那名射手，射手倒下、看不见或敌方近战逼近就回防区 | 夺点规则只要求攻方站上点时守方能及时争夺；站在开阔的点上被射手白打没有意义 |
| 9 | §3 的 scale 改为 max(1, 最高候选分, 最高分 − 中位分)；大师比较阈值也按这个 scale | 机动时最高候选分常为负，原式 scale=1，风格项和估值误差只值零点几分，而候选之间的位置分差有 5–10 分；首轮全样本测量里多种风格与均衡胜场完全相同 |
