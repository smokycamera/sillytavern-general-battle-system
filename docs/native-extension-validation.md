## 数据与运行边界

- 只针对可靠身份的单角色聊天，群聊和临时聊天暂不支持。
- 不自动采纳旧 localStorage 镜像；当前聊天旧变量是迁移数据源。
- 事实写入须经宿主读取接口确认；缓存中的值或单独一个 resolved Promise 不作为持久化成功证据。
- 已知保存失败、吞错、写入后抛错、慢保存期间切聊天及刷新恢复有测试。宿主保存 Promise 永不结束时不会继续战斗写入，可刷新后从已写入的恢复记录核实；当前没有后台强制取消宿主写入的能力。
- 关闭面板保留表单并暂停全自动；停用扩展移除入口、面板、注入和订阅。
- 100 次面板开关保持单 iframe 和固定监听数量；暂不公布没有实测依据的速度或内存百分比。
