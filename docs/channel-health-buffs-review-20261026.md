# 3.0.16 通道修正、生命道具与增益复核

本次按已确认的世界书改动实现通道伤害、佩戴生命和充能次数，并修复解除效果后单位详情仍显示来源的问题。新战斗使用V36，旧战斗保留保存的规则；实物道具继续使用冻结配方。

## 数值与结算

- 单位、武器的通道伤害使用各自现有等级修正步长和倍率上限，技能保留每点5%的换算，佩戴品读取其冻结实际效果。正修正可增加原攻击没有的通道；负修正不会独自产生伤害。
- 动能、热能、奥术防御及伤害buff复用普通防御、强击的基础幅度、等级效力、组合分摊和持续修正；同通道同类取强，各自到期并支持驱散。物理是动能的同义写法。
- 新增通道共用原攻击的命中、暴击和伤害骰，分别计算防护、穿透、抵抗和跨代倍率，共用屏障与能量盾。最多增加两个通道，不增加攻击包或96次预览抽样的数量。
- 非余伤传递攻击的所有通道作用于同一批暴露成员，原通道造成减员后不会重新选择新成员；能量盾重击每个攻击包只计算一次。
- 生命佩戴品按同级佩戴伤害的锚定比例增减当前生命与上限。例如L5的+10生命为+67%；脱下后活着的个体或成员最低保留1生命，死亡不复活，编制人数不变。升级后重新计算比例。
- 次数每点增减每战1次，最低1次；持续仍调整效果期限。已增加次数的充能道具能通过库存、档案及战斗存读档验证，次数耗尽后拒绝使用。

## Review 修正

- 排除佩戴通用伤害被误判为新增通道，避免普通伤害道具凭空产生额外伤害类型。
- 换装以档案当前生命为准，避免旧快照生命覆盖刚写入的事实。
- 充能次数只保留在实物配方与实际使用额度中，不放进已学技能修正方向；兼容道具简写和手动改造表单。
- 单位详情只展示有效来源，已撤销、到期或不再装备的来源继续保留在存档中供身份与重放使用。
- 按确认将效果表换成四条示例，补上特质标题，删除过时的大守护解释及“两种能量不并用”；修改前全文分别保存在`docs/prompt-backups/`。
