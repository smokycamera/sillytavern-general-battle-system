# 上下文配置与 JEV 状态

JEV 指挥尚未完成，本版已撤下战场、准备页和设置页的 JEV 连接、测试、扫描及切换入口。设置只保留不可选择的 `jev指挥功能(未完成，勿选)` 提示。旧聊天即使存有 JEV 模式，也使用内置自动战斗；旧连接记录保留供恢复。

当前可用的是“设置 → 上下文与开战配置 → 普通 LLM 读取上下文”。填写 OpenAI 兼容服务的 API URL、API Key，拉取并选择模型，也可直接填写模型 ID。无需填写转发地址或选择请求途径。网络请求自动使用宿主支持的通道；服务本身仍须可达并兼容 OpenAI 接口。

配置即时写入独立的本机存储，URL、Key、拉取的模型列表、模型选择和读取层数不属于聊天或角色卡，不随其切换、清空或删除而改变。旧版 OpenAI 连接可自动复制过来；不把 TypeSafe 地址当成普通 LLM 接口。主动清除浏览器站点数据或更换设备不属于聊天删除，会失去该设备的本机配置。

开战前读取最近 1–100 层已完成的用户/AI 消息；一层是一条消息，每条截取末尾最多 6000 字符，不读取思考内容。模型从支持的具体选项中选择双方指挥能力、风格、小战/会战、地形、昼夜、地图和胜利任务。优先遵循明确设定；信息不足时结合身份、行为、任务与场景自行作出合理判断，不提供 unknown 选项，也不会因置信度低于 0.6 而覆盖模型选择。只有没有可读取正文时沿用准备设置；请求失败或返回不支持的选项时不开始战斗，可重试或改为手动。取消、切换聊天、变更连接或准备数据后，迟到的答案不能开始战斗。

选择出的双方指挥配置只作用于内置自动行动的候选排序，并随本场快照保存。能力改变估值误差，风格提供有界偏好，不改命中骰、伤害、单位属性或手动命令；未开启 LLM 或没有可读取正文时沿用内置自动决策。战斗期间不会再次调用模型或更改地图。

同目录其他带日期的 JEV 验证文件属于历史记录，不代表当前界面提供这些入口。
