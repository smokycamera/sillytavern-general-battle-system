# 可选 JEV 指挥模式

当前发布版本为 **0.2.0-rc.8**，内置 JEV **0.2.3**。原有自动 AI 保留为默认；新安装与旧存档不会自动切换到 JEV。

## 更新与连接

在酒馆扩展管理中更新本插件并刷新页面。配套 `smokycamera/jev-general-tactic-system` 服务也需更新至 **0.2.3**，执行 `npm ci`、`npm run build` 并重新启动。仅更新插件无法启用新服务接口。

服务 `.env` 配置 `TYPESAFE_API_KEY`、`JEV_SERVICE_TOKEN`、`JEV_ALLOWED_ORIGINS`。在酒馆“设置 → JEV 指挥”填写服务地址（默认 `http://127.0.0.1:4317`）和 **JEV_SERVICE_TOKEN**，点击“保存连接并测试”。连接状态会显示是否支持开战上下文选择；这里不填写模型 API 密钥。

在准备界面或战场工具栏选择“JEV 指挥”。现有单次自动行动、敌方自动行动、全自动战斗与会战结算入口沿用。可随时暂停、收起面板或切回“原有自动 AI”；切换不会重掷正在进行的战斗。V1 旧规则继续使用原 AI。

## 同一次请求选择敌方与场景

设置页提供以下项目：

| 设置 | 行为 |
|---|---|
| 我方指挥水平 | 手动指定我方五档能力，现有自动策略作为我方风格偏好 |
| 敌方指挥：根据上下文 | 根据当前敌方的明确设定选择新手、常规、熟练、专家、大师及 14 维风格 |
| 敌方能力／缺省档位、风格／缺省偏好 | 手动模式的实际配置，或自动模式信息不足时的默认配置 |
| 战场与任务：开战时根据上下文 | 选择平原、城镇、攻城、森林、山地，昼夜，标准／室内地图及胜利任务 |
| 战斗形式：按上下文与编制 | 选择逐单位的小战地图或编队会战，也可手动固定 |

开战时将上述自动项目合并为 **一个 JEV choice 批次**。只需已有 JEV 密钥，**不需要额外配置 TEXT 文本模型**。本轮增加的是已有引擎选项的选择和落地；地图格子、地形生成、合法部署与胜负仍由酒馆引擎负责，未加入模型自由绘图。

胜利任务包括歼灭、攻城夺点、我方护送、拦截敌方。护送／拦截／夺点及室内场景自动采用支持这些规则的小战地图；会战采用现有歼灭结算。编制不支持会战时采用小战，室内地图容量不足时采用标准地图。手动会战与手动特殊任务冲突会提示调整，不悄悄改写任务。护送对象沿用主控或首个我方单位；拦截使用首个敌方单位。

修改准备界面的地形、光照、地图、任务或攻守方，会切换为手动场景。需要恢复自动选择时，将“战场与任务”设回“开战时根据上下文”。旧档明确指定的室内地图或任务默认保留手动选择。

## 上下文与战斗中更新

默认读取最近 **6 条已完成的 assistant 消息**，共享“最近消息数”和已配置的消息角色；每条最多使用末尾 6000 字符。窗口为 0 时不读取、不请求。原生接口保留消息边界；历史独立面板只能使用适配器提供的最近文本。

没有明确证据时保留原设置，不凭人物姓名或伤害数值推断大师能力。能力与风格选择要求置信度至少 0.6；场景接受合法候选，模型选择 unknown 时保留默认值。敌方配置与场景随本场战斗保存，重复消息窗口不会重新判定；信息不足而采用默认配置后，新正文到达时可补充识别。

场景、地图和胜负规则在开战时冻结。已有上下文指挥配置仅在**新消息明确描述指挥官更换，或其能力／性格状态变化**且变化置信度至少 0.8 时更新。一般伤亡、行动或情绪描写不会让敌方每回合换性格；更换指挥者清除前任偏好，原指挥者状态变化保留未提及的维度。

“正文目标提取”是独立的旧功能，默认关闭，仍需 `TEXT_API_URL`、`TEXT_API_KEY`、`TEXT_MODEL`；它只补充目标与环境提示。关闭它不影响上述 JEV 开战判定。

## 保存、取消与回退

小战推进一个激活，会战保留玩家明确军令并补齐其余军令，再交给原引擎结算。计划、回执、指挥配置与战斗快照一起保存。开战判定等待期间可暂停；聊天切换、消息改变或存档代次变化会丢弃未提交结果，取消不会创建半场战斗。

开战上下文服务不可用时沿用准备设置；战斗评分不可用时回退原有 AI，并暂停评分探测 30 秒。每个自动激活／会战轮次最多 10 次模型请求，上下文判定与正文提取计入同一调用上限；普通动作主要在本地选择。

保存失败沿用既有 journal 回滚／核实流程，重试不重新请求模型或掷骰。刷新恢复已保存配置与计划，全自动不会自行打开。密钥不进入 dist、计划、战报或聊天存档；服务令牌仅存浏览器会话。不自动向聊天发送 JEV 决策。

## 核心维护边界

`vendor/jev-core/source.json` 记录核心来源提交和文件校验。通过 `node scripts/vendor-jev-core.mjs <核心仓库路径>` 同步已提交源码，构建前检查哈希；不手改副本。许可证沿用本仓库 LICENSE 原文。

JEV 0.2.3 仅增加通用“宿主提供问题与候选值”的选择接口、校验和服务网关。酒馆的敌方提示、场景名单、阈值、手动优先、地图约束与存档全部留在本插件。核心没有新增酒馆模式分支或重写调度器。

rc.7 已有的无接触搜索、移动目标绑定、全组距离选敌、有限历史和置信度加权继续保留。模型接收本阵营最近 24 条 JEV 操作与回执，并非整场完整战报；普通行动仍在本地执行。

本轮验证见 [rc.8 定向验收](jev-context-validation-20260922.md)，上一轮广泛战斗验证见 [rc.7 指挥验收](jev-command-validation-20260922.md)。本轮未重复全量战斗测试或对用户实际聊天运行测试。
