## 4. 未覆盖情况、规格外发现、未达标项

**规格修订**：实现时补了 9 条，写在规格 §8（本轮记录取两轮、来袭系数的落地范围、会战距离换算、会战后撤、必倒阈值、配合预判的概率与缓存、夹击不要求移动、守点、scale 取分差）。第 9 条是测量后改的：原 scale 在机动时为 1，风格项只值零点几分，首轮全样本里多个风格与均衡同种子逐步相同。

**未达标原因**

- 大师（T1、T5、单调）：没有数值加成时，大师比常规多的只有无估值误差、来袭加权和有界的方案比较。常规的 ±10% 误差多只翻转分差很小的候选，代价本来就小；混编阵容没有控制技能，配合预判用不上。两个旋钮走完范围都没有可测影响。要让大师明显更强，需要新的决策能力（例如整轮的集火分配：把方案比较从“下一个友军”扩到本轮全部未行动友军），属于新设计，需用户决定。
- 风格：①部分有利场景里均衡的打法已经与该风格一致（积极进攻对弓手时同种子逐步相同）；②几个场景胜率贴近 0 或 100%（谨慎 96%、纵深 4–8%、核心 92–96%），+8 不可能；③会战里近战编队只走兜底推进，风格没有作用点；④规格第二步“主行为项 ±0.05”没做：在 1/4 样本误差 ±14 个百分点下测不出效果。镜像里机动防御三轮都偏高、核心固守都偏低，可能是真实差异，待全样本确认。
- X2：骑乘长兵器对长兵器加弓手时，冲锋本身就有利，新手·积极反而赢得更多。

**规格外发现**

- `generatedLayeredField` 在个别种子下抛 `BattlefieldPlanError: 水域覆盖任务目标且没有合法岸上目标`（首轮测量里 T1 混编阵容出现），测量脚本改为换地图种子重试；面板开战遇到同样地图会直接报错。
- 会战近战编队的接近机动不经评分（兜底路径），指挥风格无法影响会战近战的推进节奏。
