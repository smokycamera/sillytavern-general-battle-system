2026-10-17 用户明确要求取消佩戴品总预算上限，因此覆盖原规格中“佩戴品总效果点数不得超过道具L”的要求：

- 正文不再为了凑预算自动减少属性修正；合法的组合特质完整保存。
- 移除装备表单的“预算x/L”和预算说明。道具规格、各效果的等级/适用条件、同组取强与来源撤销继续生效。
- 特质权重保留供临时buff的SP计价使用；它不再作为佩戴品的总容量限制。
- 已保存效果原样保留，不反推恢复历史上曾被旧解析器裁掉的数值。

用户另要求内置世界书先列出拟改项，由用户决定。本轮没有写入两个内置世界书文件、其阅读版或dist；工作区原有这些文件的修改继续保留。拟改内容单独保存到 `worldbook-phase2-proposed-20261017.md`。

## P2-A：输入、来源、守护与治疗基础

新规则为 V17（D20 / TW），冻结 `traits-levels-v2`、`skills-v2`、`healing-grades-v1`、`activation-controls-v1`。V16及以前规则常量保留，旧战斗恢复以快照规则为准。新通用技能使用独立配方/效果版本；历史冻结技能、道具与区域不因读取而重编。

新traits/bless省略L为1；历史省略为5。历史强名称保持兼容映射；新输入显式L优先，技能先规范名称再由唯一末尾L确定全部授予等级。规范化后去重，多L混写明确提示拆分。旧强名称从新选择目录移除，注册表与可信历史读取仍保留。

临时特质的等级、期限、来源分别保存；默认期限 `1+floor((L-1)/4)`，单体 `2+Σw`、范围 `3+Σw` SP，不再统一截断到6SP，默认最多3目标。高阶短效/低阶长效分别到期，普通正面状态也不拼接最高强度与最长期限。按种类驱散的界面说明明确一次移除此类全部来源。

永久和临时守护共用减伤阶梯，当前有效守护L进入防御规格取强；不改变实物护甲或通道抗穿。冻结旧blessed继续保留实际减伤、规格和期限。屏障保持独立容量。

治疗纯函数只比较可信冻结P与受术者level T，按一档缓冲后的平方根规格预算比计算；不读护甲、守护或治疗者训练来抬高P。精度保留到恢复兑现，历史缺可信P按倍率1。

## P2-B：恢复、毒性与心理

主动治疗、治疗品、治疗区域和再生进入同一治疗比较规则。确定性同P治疗片段先合并再兑现；药品估件与执行共享跨代后预算，剂量只乘一次。区域冻结施放医护，各目标每周期读取自身level。再生不乘医护，吸血不二次跨代。

再生以万分之一精度保存单位余量，合法正常周期结算；失能暂停，满血、没有恢复容量、全部来源消失、死亡/离场与新战斗清零。伤兵按每次真实新伤亡及当时医护比例记账，百分比余量保存；旧分组余量封存，不补记历史永久伤亡。

普通毒冻结施加时强度和覆盖人数，现存普通毒排他、不续期、不替换；实际DOT与AI使用冻结强度。恐惧压力分级，L8/9/10额外惊退DC12/14/16；同阶段最高DC一次检定，以真实单位id记本战已应对来源。

## P2-C：其余战斗特质

十八类P2特质全部接入统一参数源：再生、医护、淬毒、恐惧、工事、拒马、散兵、游击、坚韧、身法、工兵、潜伏、侦察、射击专家、冲锋强化、狂暴、近战特化、对空。

低级工兵先部分削减工事来源，再与其他固守来源取强，不削真实护甲。身法与地形专精分别计算合法成本后取低，不叠乘；小战寻路/爬坡/借机与会战行军疲劳使用对应等级收益。低级身法不免费取消借机附带状态。射击专家只减明确掩护和移动命中惩罚；武器协作不抬高武器规格。

散兵新增疏散/收拢入口，两种战场的AI和面板使用同一入口；部署可选，正常激活开始选一次并锁定，快照保留，加速不解锁。

## P2-D/E：感知与控制

潜伏/侦察采用确定性等级差与距离；致盲的自身感知限制优先于夜视、共享视野和反隐。控制施加DC为8+L，接入坚韧等现有抵抗。嘲讽、混乱、魅惑消耗一次目标正常激活，致盲两次；施加后待激活，正常激活固定约束，结束消费，加速沿用。

共用控制模块处理硬限制及魅惑>混乱>嘲讽的优先级。手动动作、AI、会战旧军令、范围目标及反应遵守同一约束。嘲讽允许实际范围包含来源，隐藏来源不泄漏位置。混乱从自身能感知且普通武器可达的目标等概率选一次并保存；不能技能/道具或重选，加速攻击同一目标。AI估值不抽随机数，按合法动作和临时关系计算。

魅惑只接收未随队独立hero，角色保持真实side/归属/位置/随队容量；临时关系用于战斗敌友、治疗/光环与近战反应。来源死亡/离场或施术方实际生命伤害解除，包括攻击、DOT与区域伤害。胜负、XP与归档仍读取真实归属。战后清除控制和战内决定。
