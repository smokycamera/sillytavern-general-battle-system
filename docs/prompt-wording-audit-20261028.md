## 佩戴改造UI与机制联动

- 改造界面直接列出上述12种方向，效果说明明确特质、属性修正和开战屏障的填写方式；旧实物若已有通用防护修正，仍显示并保留兼容字段。
- 增加屏障和独立特质等级的填写示例；充能次数说明改为由效果与次数修正决定。
- 佩戴修正按道具等级换算，同方向取强，不再误用武器/护甲的每点0.2档说明。
- 复核发现原表单只回填特质名称，漏掉屏障，也抹去混合特质等级。修复后保留屏障L、各特质L和独立道具主体L，再交由同一规格解析器编译；普通未标级效果继续使用表单规格等级。
- 新增实际库存预览/提交回归：L4道具、L6屏障、L3夜战专精、L5林地专精，增加奥术防护修正后各原有效果保留，确认前不写入。
