# V10 连续跨级毁伤：26,400场实验

日期：2026-09-28。基线提交 `069c4c0f0973a3c99ebda56cf94d5d31e7ab835f`（1.3.16）。新版本1.3.17。

## 选择

采用 tail2：相邻等级不再免于跨代毁伤；额外放大只在差距超过1级后渐进趋向2倍。保留防护、盾牌覆盖、有限屏障、单位训练等级防守下限和伤害溢出。不是所有伤害直接翻倍，不修改内置世界书、HP、人数、SP或疲劳，也不绑定单位与装备等级。

这是本次固定阵容、引擎AI和明确权衡下的选择，不宣称是任意玩家阵容下的全局最优公式。

## 公式

P=武器/伤害技能规格；D=单位等级、实际通道防护映射规格、无甲装备规格、有效守护中的最大值。屏障规格仅在自身吸收阶段生效；盾牌不把自身等级借给全身。

沿用预算 B(L1…L10)=[4.5,10,24,60,150,420,1400,6000,40000,400000] 及小数等级几何插值。令 g=P-D，h=clamp(穿透-抗穿,0,1)，R=B(P)/B(D)。P≤D时新公式全部返回1。P>D时：

|方案|跨级倍率M|
|---|---|
|V9 baseline|P≤D+1时1，否则1+h(√(B(P)/B(D+1))-1)|
|root：仅取消保护|1+h(√R-1)|
|literal2：取消保护后总倍率×2|1+h(2√R-1)|
|bonus2：仅额外增伤×2|1+2h(√R-1)|
|ramp2：全等级差渐进放大|1+h(√R-1)(1+g/(g+2))|
|**tail2：采用**|**1+h(√R-1)(1+t/(1+t))，t=max(0,g-1)²**|

literal2在微小正等级差处会跳变。tail2的额外放大项在差1级处平滑接入；0<g≤1时已经有√R的真实压制，不是重新设置相邻保护。h保留真实穿透门槛，不能靠等级倍率把未穿透的攻击强行视为穿透。

已穿透且无盾牌覆盖混合时：

## 试验矩阵与计数

探索6方案×2400=14400；独立种子复核4方案×2400=9600；最终V10正式实现再运行2400，合计26400次完整战斗。最后2400是实现一致性重放，不是新独立场景。单次攻击采样、单元测试和无效初始化不计入。

每组2400=50阵容模板×6环境×2模式×2种子×2方位。环境：平原昼间、平原夜间、森林、山地夜间、城镇、攻城夜间。小战使用真实生成7×13地形及SmallBattle.autoAction；会战使用宏观阵位环境和MassBattle.autoOrders/resolveRound。没有调用外部LLM，也不是单击伤害估算。

覆盖L1–L10同级、相邻装备差、单位与装备同时相邻升级、跨2/3/9级、近战/弓/火器/能量/独立法术/范围/火炮、无甲/重甲/盾牌/预置屏障和守护、飞行/大型/巨型/载具、±10强化、2对4、48/100人编队。默认会战编队20人。阵位交换时反转小战地形并交换攻守，但部署仍由引擎完成，不宣称完全消除阵营偏差。

先前预试发现普通人形独立英雄会战不合法，以及第四编队挤占中路前排的问题；修正为合法大型/巨型平台及第四队侧翼部署后重跑。探索5个方案各24条outnumbered:mass初始化拒绝记录被合法重跑替换，manifest保留修正说明。最终11组全部2400个有效已结束战斗，无未结束战斗、无生命数据校验错误。预试和修正记录不重复计数。

所有曲线共享输入种子；决策分化后随机数消费顺序可能分化。复核种子偏移104729，复用预先确定的模板，是独立种子而不是未见场景验证。选择准则先于查看复核结果记录：同级不变、无非法数值和无穷战斗、保留穿透门槛与旧规则，在相邻秒杀率和大跨度/编队效率间权衡；不以混合总体胜率排名。
