# 战报状态行、终章减员、预设正文与繁体兼容（2026-10-03）

现象：

1. 发送战报时，“完整逐轮战报”末尾和“状态摘要”的单位行不写兵力，却写 `SP17.12/18`；“新增战况”的【最新状态】和“战斗终章”把编队写成 `现员93/120人，总生命6754/8760；92人 73/73生命；1人 38/73生命`，英雄写 `生命65/105`。
2. 终章【伤害来源】里，成员生命编队只有 `累计造成2006生命损失`，看不出损失了多少人。
3. 使用 Izumi 1002 预设时，解析器把回复读成 `<tb>`、`<htmlcontent>`、`<type>`、`<disclaimer>`……`<advice>`、`</tb>`，再接真正的事件块，并报出10条“暂不支持事件”。
4. 用繁体写的 `劍L3`、`輕甲`、`範圍射擊`、`統率`、`敵方` 等无法识别。

## 原因

1. 上一轮精简状态摘要时去掉了兵力和生命，只保留 SP；终章和新增战况沿用成员生命的完整写法。
2. 终章只按生命累计；持续伤害和坠落的日志也没有记录减员数。
3. 三处叠加：
   - 该预设把思考开标签 `<konatan_planning~>` 放在预填充里，回复从思考内容开始，只有闭合标签 `</konatan_planning~>`。解析器只认成对的 think/thinking/analysis/reasoning，整段思考被当成正文。
   - 思考复述世界书规则时写了“输出<tb>规格的交战双方建档”。这个 `<tb>` 被当成事件块起点，一直延续到真正事件块的开标签，中间的 `<type>`、`<disclaimer>`、`<options>` 等包装标签都被当成未知事件。
   - 聊天显示的折叠也从这个 `<tb>` 开始，到真正的 `</tb>` 结束，把整段正文折进“战阵事件”卡片；AI扫描和副API准备则把整段思考当作正文发给副API。
4. 武器、护甲、技能、特质、效果和枚举的词表都是简体。

## 修改

### 战报状态行

- 编队写 `剩余总人数93/120`，载具编队写 `剩余总数10/12辆`；英雄写 `血量65/105`。不再显示 SP、总生命、成员生命分组和成员耐久。
- 适用于“完整逐轮战报”末尾、“状态摘要”、“新增战况”的【最新状态】，以及“战斗终章”的开局和结束状态。“完整结算”没有状态段，保持不变。已归档战报保存的是当时生成的文字，不改写。
- 成员生命分组仍在单位资料（单位提示词）里提供。

### 终章减员

- 成员生命编队：`累计造成2006生命损失，减员27人`，载具按“辆”；含持续伤害时为 `累计造成…生命损失（含灼伤），减员N人`。英雄只写生命损失；旧人数模型的编队仍写 `N人减员`。
- 持续伤害和坠落的日志记录增加这次的减员数。只影响新记录，战斗过程和结果不变。更新前保存的记录没有减员数，该行写 `减员至少N人`。

### 预设正文兼容

- 思考区：除 think/thinking/analysis/reasoning 外，名称含 planning、thought、reason、cot、plan、思考、思维、推理的标签（如 `<konatan_planning~>`）也按思考处理。开标签在预填充里、正文只有闭合标签时，从开头到第一个这样的闭合标签都是思考。闭合标签名字写错（`<thinking>…</think>`）时，用其后第一个思考闭合标签收尾。
- `<tb>` 开标签后的第一个非空字符是 `<`（紧跟事件）才算事件块；规则复述里的“输出<tb>规格……”只是提及。
- 事件块内，只有自闭合或带 `名称=值` 属性的未知标签才提示“暂不支持事件”；`<options>`、`<type>`、`<advice>` 一类包装标签和网页标签（div、font、style 等）不提示。块外只提到 `<spawn>`、`<deploy>` 而没有属性的，不算事件。
- 聊天显示折叠、AI扫描、副API准备和“本场相关”单位判定使用同一套思考区与事件块判定。

### 繁体兼容

- 事件属性先把繁体换成简体再识别，范围包括武器、护甲、技能的规格段，特质、效果，枚举（我方、敵方、個體、編隊、人形……），环境（平原野戰），数值单位（120人、5級），以及是、否、無。名称、说明、编号和 data 保持原文，`軍官指揮刀:劍L3` 的名称仍是“軍官指揮刀”。
- 对照表来自 Windows `LCMapStringEx(zh-CN, LCMAP_SIMPLIFIED_CHINESE)` 对 CJK 基本区逐字转换的结果，共 2,473 对；去掉简体也常用的捍、著、瞭，补上後、麼以及剑、炮、锤、愈的异体，共 2,479 对（约16KB）。台湾写法“砲”按“炮”识别。
