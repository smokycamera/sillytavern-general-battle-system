# 分层城区与攻城系统 v1.6.0

## 范围与协议

以主分支 `1a859a64c6be3dc9259359030a2bee67fe947ed3` 为基底，保留参战名单替换修复。只为新生成战场启用 `layerVersion: 1`；旧地图、旧随机回放保持旧地形与指挥评分路径，不重新生成。

地面 `tiles` 是 terrain，`structures` 是对应格位实体，`overlays` 是道路/瓦砾。现有烟雾、火焰等技能区域继续使用有持续时间的 battleZones，与地图显示和观察规则合用；不复制第二套持续伤害。所有结构行动从预览到执行共用校验。静态地标最多5个，普通墙段与填充街区不占名额。

普通副 API 在开战前仍只有一次调用。原场景/指挥/VIP字段保留；11个旧地图选择字段不再发送，改为答案顶层 `battlefield`，地标最多5个、偏好最多3个。有限接受旧式返回仅作为读取回退，不发送旧地图问卷，也不触发返工调用。第三方 OpenAI-compatible 传输与原有响应格式降级机制保留，不再受 JEV 地图协议限制。

允许 compact/standard/large、五种城防骨架、九种内城路网、密度、水域、门配置、结构级别与相对锚点。模型不能返回可执行命令、逐格数组、结构HP或偷偷改变单位能力。无效可选字段各自回退；场景、指挥和VIP仍需合法。显示名称需要来自已筛选正文，不采纳隐藏推理、HTML或无依据名称。

## 地形、城区与城防

新增街道、浅水、深水、沼泽、自然岩壁。城市普通地块以 street 为底；明确的公园/制高地地标可以形成自然地形例外。巷战大师在分层图按实际 street 位置生效，不再把整个 urban 战区当作同一种脚下地形。森林与山地适应、道路、工事、水面、飞行、射线、部署读取同一组格位规则。

urban 与 siege 使用同一个可组合城区生成器，但普通 urban 没有强制外围城墙和占点任务。城市尺寸9×15、11×17、13×19；默认按棋子数量选择，而不是单位等级或编队人数。五种城防骨架为正面战段、封闭据点、临河、依山和破损城防；实际街道受九种路网驱动，主街、联络路、街区、庭院、门位和布局偏置均有随机变化。护城水面当前表达本战区的前沿壕水，不是完整三维城市环形水系。

工事有正面、完整度、跨越成本与防护；夺取后双方同样可用。城墙按格位独立耐久，破坏后留下瓦砾和真实突破口。门有关闭/开启/毁坏状态，操作消耗主行动，关闭前检查门洞占位，开启后双方均可通过。高处采用有限墙顶/塔楼平台，不是多层室内建筑。

城防L1—L10单独锚定为临时、简易、正规、重型、要塞、超凡、史诗、传奇、半神、神造。等级由明确材料与强化决定，不跟随参战者自动缩放。标准墙耐久为 `80 × 2.2^(L−1)`，门0.65、工事0.5、普通掩体0.25等类型系数；同级基准钝器人物约5个有效主行动破墙，门约3—4次。武器类别、工兵、体量及有限接触正面影响破障效率。

破障是独立、确定性的结构伤害，不把墙当活人套士气、毒、流血、经验或人数结算。直接伤害技能可以指定结构并正常扣SP、冷却和次数；本版不对结构攻击额外附加范围内单位伤害。修复/建造工事、材质专项抗性、多格建筑共享耐久及建筑内楼层不在本版中实现。

## 特质与墙顶交互

新增 `航渡`（water-crossing）和 `登城`（siege-assault）；都进入单位特质目录。航渡允许深水移动并降低浅水/沼泽消耗，模型不能凭地图需要授予该能力。深水通路使用真实桥梁；桥位衔接既有接敌路径，不仅随机撒桥；桥毁或能力失效会结算落水与近岸落点，不留下永久非法位置。

登城允许从相邻墙外与墙顶守军近战，并在落点合法时攀上平台。攀登需要主行动与2移动，不能直接穿过敌军或超容量占位，不能规避借机/警戒反应；普通单位使用内侧梯道。墙毁后处理顶部单位的落点与坠落生命伤害。地面、墙顶、飞行区分占位与近战高度；归档不把墙顶位置带入新战斗。

旧“守城工事”单位特质仍保持原来的无条件防护；地图结构工事是另一对象，不把旧buff改为凭空造建筑。已有攻城工兵另对破障效率生效。

## 目标、任务与本地AI

攻城核心由实际城内布局决定，以相邻合法区域占领；区域内换位不清空进度，敌我争夺暂停，攻方全部离开清零；飞行、墙顶、失能和溃退者不能占点。守方仍只在守满期限后获得防守胜利。urban 歼灭不因街区生成变成攻城夺旗。

本地守军具有前沿、火力、预备队和核心警戒任务。完整城防优先前沿分区；已知突破口调动预备队，核心受威胁时允许合理收缩。任务只使用友军、公开地图和已观察敌人，不读取隐蔽单位位置。攻军分配门/侧墙目标，选择破障、攀登、开门或突入；合法高等级墙体不会被“通路修复”自动挖开。

指挥模板扩充到13种，含稳步攻坚、渗透、游击、前沿、纵深、机动、核心固守等。reserve/risk/counterattack/cohesion/breach偏好限制为0—4整数、最多3项，影响任务与行动而非单位属性。任务采用确定性分配与局部威胁反馈；不是神谕式全图最优规划，也不保证任何等级/兵种配比都有合理胜率。刻意设置的高等级城防不会被静默降级来迁就攻方。

位置候选先廉价筛选，再对最多12个优选位置和原位进行昂贵攻击/技能预览；寻路使用稳定最小堆并保持旧代价/格号排序。无逐回合API调用。
