# 屏障预览性能与对空目标规则（v1.3.20）

基线：`5395b9b64b34a976fe9b49d8e4703a1afbf16b5c`（v1.3.19）。本次不修改内置或外置世界书，不修改屏障容量、持续时间、防御规格、骰子或技能资源平衡。安装产物 `dist` 与源码一起构建。

## 1. 屏障后的回合卡顿

热点位于 `damage.ts` 的 `previewMemberAttack`：多段攻击/编队命中屏障时，每次预览都会克隆攻守单位并用96组固定种子完整模拟攻击。AI比较走位、目标、防守收益与技能时对等价状态反复执行这段昂贵的计算；这发生在同步AI阶段，不是网络等待。

改为有界的数值结果缓存，保留原96组种子及全部结算统计。键包含完整攻守战斗状态、屏障、生命分组、装备、规则、距离、地形、外部修正及状态/特质表内容。只有没有方向性姿态时省略已经通过距离与地形输入表达的坐标；存在固守姿态则保留坐标，避免正面与背面误用。同一状态复用计算，生命/屏障变化马上形成新键；上限128条和2097152个键字符，值不保存活单位引用，也不写入存档。另在无法使用技能时不执行无意义伤害预览。

| 英雄（双段射击） | 314.6 → 12.8 ms | 214.3 → 74.7 ms |
| 20 人编队 | 1120.2 → 41.5 ms | 666.8 → 245.2 ms |

复现：在基线与候选都运行 `BENCH_OUT=report.json npx vite-node scripts/benchmark-barrier-preview.ts`，比较每一项 `outcomeHash`，而不是用墙钟阈值做易抖动的CI门槛。

## 2. 曲射火炮禁对空：采纳

当前武器体系没有专用防空弹道能力，故曲射火炮限定为对地支援，直射火炮、步枪、弓弩、法杖等仍可在射程内对空。这是本游戏当前机制选择，不是声称现实所有间接火力都绝不可能对空。

按实际 `indirect-cannon` 机制、兼容机制标签，以及旧 `cannon + indirect=true` 判定，不猜武器名。只禁止攻击实际 `airborne=true` 的目标；仅拥有飞行特质但已落地者仍可被曲射攻击。主副武器、依托武器的技法、范围技法附带目标、压制、警戒反应、自动行动和会战军令均沿用共用判定。独立魔法攻击不因手持迫击炮而被误判为炮击。

## 3. 地面对空距离加值：采纳固定预算

- 小地图：射程距离 = 原战斗距离 + 2格。
- 会战：射程距离 = 原阵位距离 + 1阵位。
- 空对地、空对空、地对地不加；曲射禁对空优先于距离检查。

当前只有空/地两层，没有连续高度。采用固定射程预算比虚构三维高度或按武器射程百分比扣减更直观，也不会让长程武器承担更大的绝对扣减。普通7格弓弩对空可覆盖平面5格；4格投掷武器保留平面2格，仍可应对靠近的飞行单位。

有限射程的敌对远程武器技法、独立法术/控制统一计入高度，友方支援、自身、区域落点、全域技能的原规则不变；武器技法即使标成全域也不能绕过实际武器射程或曲射限制。跨层同格仍使用现有战斗距离下限1，再加高度预算。

只改变射程合法性，不改变移动寻路、接敌、观察距离、范围半径或伤害预览中的距离修正；不再叠加新的命中惩罚。UI保留几何距离，并显示“距离 + 对空 = 射程距离”，AI走位目标、技能估值、手动执行和反应攻击消费相同规则。
