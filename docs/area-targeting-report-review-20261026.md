# 3.0.17 范围技能与战报复核

## 已复现问题

- 小战魔法范围的主目标距施术者6格，第二单位紧邻主目标、距施术者7格。原代码在范围几何检查后，再用施术者的选定目标射程检查每个波及对象，导致第二单位从预览和执行集合中同时被排除。
- 指令堵路和移动额度不足反馈带有`intentFailure`结构化数据，但其事件种类为`condition`，逐轮与增量战报因此将其当作实际状态变化输出。
- 小战仅记录`area`、缺少`burst`标记的技能，目标集合已经按几何计算，但预览与部分效果执行仍只检查`burst`，存在显示和执行不一致。

## 最终实现与复核边界

- V37区分施法选定目标与独立范围的实际波及对象。选定目标保留射程、感知与合法性检查；波及仍检查阵营、有效状态、控制约束、实际效果适用性和几何连通。武器技法的射程、接触、屏蔽与装填规则不放宽。
- 共享几何检查保留形状、半径、最大目标数，并检查空地层、高度和墙体遮挡；连锁逐段检查。无二维地图的会战也保留空地层区别。
- 普通近战范围保留当前主目标圆心，环形保留V33起的施术者圆心；不重新编译或改变已冻结技能的数值。
- `intentFailure`仅在面向玩家和正文叙述的压缩输出中省略，原始日志、指挥观察与重新规划依旧可用；已归档文本不重写。
- V37注册为独立规则，由共享开战入口供UI与MCP创建新战斗。V36等历史快照继续按原规则读取和结算。

## 验证

- 固定场景回归覆盖小战魔法范围射程边缘、扇形、直线、环形、连锁、近战、独立投射、范围治疗、防御、屏障、回能、净化、临时特质与控制。
- 核对预览不修改快照、预览目标与实际伤害记录一致、额外单位真实扣血、逐轮与增量记录包含受击者；核对墙体、空地层、目标数与主目标射程限制。
- 核对会战边缘波及、V36快照与冻结技能保留、普通近战和环形的不同圆心，以及指挥反馈仍存在于原始记录。
- 最终相关回归为12个测试文件、146项用例，包含本次21项定向回归。类型检查、原生扩展构建与`verify:dist`通过；原生浏览器冒烟使用本机Chrome通过，覆盖开战、保存、归档和面板生命周期。
- `verify:compatibility`的两个历史脚本未通过：`verify-recovered-scenarios.ts:27`仍要求最多5个预备技能，而当前实现为6个；`verify-native-compatibility.ts:64`的冻结快照比较缺少`activationStarts`、`aiRevision`和加速状态等后加字段。已在本次改动前的`origin/test`（`051727a`）独立导出源码中复跑，两项以相同断言失败；本次不修改历史脚本和允许失败列表。
- 按用户要求依次晋级到test和main，不等待远程CI；本地检查与远程CI结果分别报告，不将未完成的CI描述为通过。
