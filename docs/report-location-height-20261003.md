# 战报的地点与高度，结尾状态不再列技能（2026-10-03）

现象：

1. 实际高度地图上，战报只写格子和地形，不写高度。弓手站在高度2的北坡往高度1射击，逐轮战报、新增战况和终章里都看不出谁在高处，主叙述只能按平地写。
2. “地标”一行张冠李戴：`地标：北坡｜D3〔北坡〕(山地)、D6〔旧哨所〕`，旧哨所被列在北坡名下；第二个及以后的地标没有名字。
3. 新增战况的【最新状态】完全没有位置；逐轮战报的布阵行写内部格子序号，如 `我弓手@87`；环境写英文 `环境：mountain`。
4. 连续移动只有落点是开阔地时才合成一行，进了山地、掩体就一格一行；新增战况完全不合并，同一次移动写三四行。
5. 逐轮战报结尾和状态摘要的我方单位行列出已准备的技能和冷却，例如 `剑客(D4·未定位敌军) 血量32/56 [重伤1轮]｜雷霆一击冷却2·秘传·影步`：这场只用过雷霆一击，没用过的秘传·影步也出现在战报里；战斗结束后还写着“未定位敌军”。

## 原因

1. 战报的位置标签沿用格子、地标、地形三项；高度只在地图格子信息里显示。
2. 地标行取第一个地标的名字，再把全部地标的格子接在后面。
3. 【最新状态】与终章共用一套单位行，只写兵力和状态；布阵行直接拼接格子序号；环境行原样输出存档里的英文键。
4. 合并移动靠匹配“格号→格号”结尾的文字，落点带了地形后缀就匹配不上；新增战况逐条压缩，不跨条合并。
5. 状态行的“当前姿态”里包含我方已准备技能及冷却，这是面板操作用的信息，被原样带进了战报；战斗结束后仍计算距敌。

## 修改

高度只写在有高低差的实际高度地图上（某处地面高于0，或有城墙、塔楼平台、抬高的桥面）。整张图都在高度0、或没有实际高度的旧地图，不出现“高度”二字；会战没有格子，写阵位。其余格式整理对所有战斗生效。已经写进存档的旧战报行保持原文。

### 位置与高度

- **单位位置**：状态摘要、逐轮战报结尾写 `我弓手(C10·崎岖地·高度1·距已知敌4格)`，地标格写 `敌枪手(D3〔北坡〕·山地·高度2·…)`。写的是单位站立的高度：城头守军写 `城头·高度1`，墙脚的敌人写 `高度0`，平地上的塔顶写 `塔顶·高度2`。空中单位不写数字，事件行里写“上空”。战斗结束后不再写距敌。
- **移动**：每一步记录起止格和两端高度。战报把同一单位连续的逐格移动合成一行，高度有变化时写出起点高度：`敌枪手 C2(高度2)→D4(高度1)`、`我弓手 D10(高度0)→C10(崎岖地·高度1)`；没有变化时只写落点高度。攀上城头写 `登上城防平台 D4(高度1)`。
- **攻击**：双方站立高度不同时写 `居高（高度2→1），命中32生命…` 或 `仰攻（高度1→2），未中`，同高、空中不写。速射合并行补写“生命”和减员，与单发行一致：`2段/2中，损失45生命（1120→1075），减员0·含暴击`。
- **环境与地标**：`环境：山地｜高度按层计，约一层楼，0为地面`；地标逐个写名字、至多4个格子、地形和高度范围：`地标：北坡 D3（山地·高度2）；旧哨所 D6（高度0）`。夜战写“夜间”。
- **布阵**：`布阵：我弓手 D13(高度0)，我步兵 D11(高度0)，敌步兵 D3〔北坡〕(山地·高度2)…`。
- **新增战况**：【最新状态】每个单位写位置，小战如 `我方 我弓手(C10·崎岖地·高度1)：血量56/56，可行动`，会战如 `我方 步一(中军前列)：…`；有高低差时标题附高度说明。连续移动和速射在本次待发送的范围内合并，不跨过已发送的部分；战斗结束归档时也按已发送的位置分段，之后从归档补发不会重复已发出的移动。
- **战斗终章**：新增【战场】一节写环境与地标；开局单位按开战时的地图写位置，结束单位按当前地图写位置。

### 技能

状态摘要、逐轮战报结尾和归档摘要的单位行不再列已准备技能和冷却。技能仍在单位资料里，技能真正使用时照常写进战况。战斗结束后，单位行只保留“空中”，不再写受压制、固守、装填中。
