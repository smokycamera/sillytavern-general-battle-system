## 控制技能

在“队伍 → 添加单位或编辑档案 → 技能”中，可直接点击眩晕、定身、沉默、缴械、惊惧、减速、击退、拉拽。填写中文效果也可以。原有名称仍兼容，不要求正文AI学习新的必填字段。

| 效果 | 战斗影响 |
| --- | --- |
| 眩晕 | 跳过行动；会战中不能下达行动命令 |
| 定身 | 限制移动、起飞与冲锋，仍可使用允许的攻击和技能 |
| 沉默 | 限制魔法技能，普通武器动作仍可使用 |
| 缴械 | 限制手持武器攻击；拳脚、爪牙等天生武器仍可使用 |
| 惊惧 | 降低攻击与士气；不溃单位能抵抗惊惧 |
| 减速 | 减少移动并降低先攻，会战中不能冲锋 |
| 击退、拉拽 | 在空间规则允许时推动或拉近目标 |

技能等级影响威力或抵抗难度；控制不是必定成功。眩晕等不利状态可被净化。

现有技能格式可直接写成：

~~~xml
<learn id="已有单位的真实编号" skills="震慑:眩晕L3,缚足:定身L3,封魔:沉默L3"/>
~~~

这只是格式说明；实际使用时必须填写已存在单位的编号。

## 武器范围

保留原有14类，只新增三类：

| 新增类别 | 用途与规则 |
| --- | --- |
| 投掷冷兵器 | 标枪、飞刀等；短距离、单手、负重1，可抵近使用 |
| 单发重步枪 | 高单发威力，比普通步枪多1点穿透；射后装填一回合，抵近射击命中降低3 |
| 天生武器 | 拳脚、爪牙等；不占双手和负重，不受缴械影响；已有持有者后不能转送给别人 |

武器仍沿用“名称:类别L等级”的格式。没有增加枪管、口径、弹匣、子类别等必填项目。

## 第一批战斗补充

增加回能、净化、强攻、屏障、投掷炸弹和车辆维修等消耗品，以及两个通用配件栏。配件可提供被动特质或有限次数的主动能力，卸下即取消能力；物品使用量和技能已用次数随战斗保存。

屏障吸收有限伤害，扇形、直线、环形、连锁采用不同目标选择方式。火焰、毒雾、烟幕、治疗区域和陷阱可放置在空地或阵位。火焰与毒雾会误伤友军；同一区域对每个单位每轮最多触发一次。屏障剩余强度可以在单位详情查看。

临时掩体、可破坏炮塔、通用吸血、复活和控制权转移仍为后续内容。多次攻击遇到屏障时，预览给出固定样本估计；实际战斗逐次结算。

## UI

装备页只显示当前单位物品与公共库存，并按已装备、随身物品、公共库存排序。卡片只突出主要操作，详细规则可以展开。桌面使用侧边编辑器，窄屏使用独立编辑面板；深浅主题同时应用到外层窗口。

界面与常用提示改用自然语言，开发用语按实际意思重写。协议键名、服务名称和必要配置项保留原格式，以保证已有记录和外部服务仍可识别。
