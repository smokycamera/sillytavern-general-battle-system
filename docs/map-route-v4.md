# 地图生成 v4：路网、语义地标与可测的战术空间（v1.5.0）

## 选择与范围

采纳五项建议的方向，但不把“随机格子数量更多”当作成功标准。保持六种基础地形、四种合法地图尺寸、战场快照 version 2 和现有战斗数值规则；新地图的生成记录为 version 4，旧 v3 记录或没有生成记录的实际 tiles 不重建。

### 1. 路网先于地形，不再保留固定双贯通线

`route-graph.ts` 先从九种有界拓扑选择图：主路与双支路、Y 型分叉、汇合再分叉、中央主路与单侧迂回、外围环路、三路并行、多条曲折窄路、横向联络网、主路与院落支巷。节点位置、朝向与镜像受种子扰动，再把边栅格化为真实通路。共享主干、交会与支路端点均被允许；狭小地图上的路径可能因栅格化部分重合，并不声称无限种独立拓扑。

主路以现有 open 格表达较快但暴露的接近；支路保留森林、高地、掩体和崎岖地的移动/防御差异。道路不是额外地形类型，也没有隐藏移动加成。城市与室内由墙段构成街区，路口邻近区域优先放置可以利用的阵位。

完成填充后，本地算法检查连通、部署空间、目标合法性，并依次假设任意一个非部署通行格被阻塞：若这会切断双方全部接敌通路，只在造成问题的区域开最小代价缺口。最终地图至少保有两个物理接敌通道，不要求“标注为道路”的两条线从头到尾互不相交。该保障不是保证任意数量单位同时堵路后仍可通行。

### 2. 不开副 API 也有地标

本地概率为 40% 无明显地标、45% 普通地标、15% 主地标。类型随环境选取，包括开阔地/院落、掩体阵地、林地、岩脊、崎岖地与残垣废墟。普通地标最多 3×3，标准地图主地标最多 3×5；保留部署、主路和出口后，实际范围可能较小。主地标组合核心地形与周边接近地形，不额外叠加属性。

地标记录的是实际成功落地的格子。废墟用现有 wall/rough/cover 组合；自然环境的废墟表现不凭空加入建筑墙段。所有选择由独立地图 RNG 决定，不消费战斗骰子，也不改单位装备。

### 3. 副 API 与语义名称

沿用「由 LLM 设计地图」独立开关，不新增一排重复开关，也不影响战场规模/VIP 两个开关。复用同一次开战上下文请求，新增可选 `design_topology`、`design_landmarkscale` 枚举选择。旧模型只返回原九项合法字段仍可用，缺失/非法的新枚举回退本地选择或普通地标。

答案顶层可附加 `landmarkLabel`，如 `废弃钟楼`。必须是本次已选、已去除思考标签的正文窗口中的原文短语，最多 32 个字符；控制字符、标记、过长值和没有正文依据的名称不会进入地图。地图开关关闭时忽略模型自作主张的地图字段。非法名称不连带丢弃合法地图/VIP。

地标通过 actual cells 连接地图标识、格子详情、战况/移动文案和 JEV 的地图位置标签；称作“钟楼”的高地不会凭名字增加射程、防御或技能。已有护送/拦截 VIP 选择、取消、超时、切换聊天后的过期回答保护不变。额外字段增加 token，但没有新增请求轮次。

### 4. 地形更有意义

森林、高地、崎岖地、掩体仍分别使用现有的移动、攻击适应和防御规则。加入少量自然硬障碍后，平原、森林、山地的硬遮挡射界不再全部等同于一张无障碍矩形：平原显示「巨石」、森林显示「密林障碍」、山地显示「岩障」。

自然硬障碍内部复用 `wall` 的地面阻路/直射遮挡规则，普通 forest/hill 格并未变成墙。空中单位仍按已有飞行规则越过。名字区分自然障碍和建筑墙体，地形详情明确其实际效果；没有伪造水域、可破坏建筑、多层高度或可穿透树林机制。

v4 地图的内置 AI 站位小权重评分会根据已观察敌人考虑掩体远程保护、森林对远射的保护、高地防御、地形适应惩罚、潜伏位置与飞行状态。不会读取隐藏敌人，也不是新增战斗加成。旧地图沿用原来的掩体站位评分，减少回放行为变动。

### 5. 结构审计，而非只有 seed 去重

`engine/src/small/map-metrics.ts` 仅用于离线审计/测试，不在每回合和每次渲染计算。`npm run audit:maps` 输出 `docs/map-route-v4-metrics.json`。指标定义包含：

- 全部同尺寸地图对的格子相似度；3×3 空间分区的阻挡、移动阻力、防护与高地覆盖差异；各地形连通块及重心。
- 实际路网交会区域与横向联络段数、可通行格上的狭窄区域、单格关键割点、精确顶点容量最大流得到的替代通道数。
- 双方最短接敌步数/移动成本、八方向平均 LOS、掩体覆盖及重心、双方到目标与地标的最小移动成本。

距离统计以双方部署边缘为起点，不冒充特定已部署单位的距离。LOS 按现有墙体 supercover 规则，不包括单位遮挡、夜间观察限制。v3 没有显式路网，旧版分支/横向联络采用 open 格代理，不把这个代理与 v4 的设计路网直接当成等价比较。

本次固定种子审计：每环境 160 张 × 6 类 = 960 张本地随机图，另对每种路网以 40 个相同种子做城市图单因素对比（360 张），合计 1,320 张。另对主分支 v3 同样的 960 张种子图做基线比较。

| 环境 | v3 平均格子相似度 | v4 平均格子相似度 | v4 平均 LOS 的样本范围 | v4 替代物理通道范围 |
|---|---:|---:|---:|---:|
| 平原 | 52.3% | 44.5% | 3.09–3.94 | 4–7 |
| 森林 | 45.4% | 43.3% | 2.61–3.94 | 3–7 |
| 山地 | 45.6% | 42.9% | 2.42–3.94 | 2–7 |
| 城市 | 49.6% | 46.0% | 1.73–3.94 | 2–7 |
| 攻城 | 48.3% | 45.3% | 1.53–3.41 | 2–6 |
| 室内 | 56.6% | 55.7% | 1.27–2.26 | 2–5 |

相似度下降说明地形分布更分散，不直接等于游戏更好。宏观空间差异在平原、森林、山地、城市和攻城有所增加；5×7 室内的提升有限。九种路网的固定条件样本中，Y 分叉的平均交会区域为 1，横向联络网为 6；前者接敌移动成本均值约 13.15，后者约 12；射界、掩体占比也不相同。所有统计是空间代理指标，不是玩家可感知乐趣或胜率平衡的证明。

## 回归与复现

- 原有 2,400 张环境/布局/尺寸/种子压力矩阵继续验证连通、复现和单格封堵绕行。
- 新增 1,440 张强制九拓扑矩阵，检查图边对应实际合法格、接敌代价及实际替代通道容量。
- 1,200 张本地地标概率/范围抽样；240 张六环境宏观差异门槛；自然硬障碍 LOS、主地标范围、名称不影响 tiles 的测试。
- 模拟副 API 覆盖有据名称、幻觉/标记拒绝、思考标签过滤、独立开关、单请求、旧模型缺字段、无效 VIP、取消与过期响应。
- 保存/恢复、损坏可选展示元数据、JEV 位置标签、战况文本、飞行/地形适应和地图 UI 有专项测试。

地图展示的独立浏览器夹具为 `scripts/map-route-v4-browser.mjs`，覆盖足迹标记、详情、战况/JEV 名称、保存恢复与手机视口。

完整执行计数及已知主分支失败见 `docs/map-route-v4-validation.json`。本 PR 不修改生命上限/历史战报失败的断言，不改变原有 CI 门槛，不更改内置世界书或 JEV vendor。浏览器使用模拟宿主，副 API 使用模拟模型；未调用真实第三方模型，也未在实际 SillyTavern/TauriTavern 会话中验收。
