# V11：低中阶压制柔化与SP总量约束

2026-09-28，版本1.3.18，继续更新PR #52。历史V10报告保留，但本页覆盖其交付版本和测试状态。未自动合并。

## 采用方案

落实用户批准的soft40，而不是此前讨论过的50%起点版本：

```
x = clamp((P-3)/4, 0, 1)
w = 0.4 + 0.6*(3*x*x - 2*x*x*x)
M_V11 = 1 + w*(M_V10 - 1)
```

P是当前攻击用于压制结算的武器/技能规格，不是单位训练等级。L1–L3保留40%的额外毁伤，L4为49.375%，L5为70%，L6为90.625%，L7以上100%。不恢复相邻保护，不改基础伤害、真实穿透门槛、护甲、盾牌覆盖、有限屏障和伤害溢出。

充分穿透且没有盾牌覆盖混合时，L2/L1从1.491变1.196，L3/L2从1.549变1.220，L5/L4从1.581变1.407；L7/L6仍1.826，L10/L9仍3.162。这是毁伤系数，不是最终伤害。高阶压制系数不变，但SP也减少，不能宣称全部高阶战斗不变。

SP选用balanced：法系6+2L，非施法配置4+L。L取单位训练等级，不取装备或技能等级。

|等级|法系原SP|法系新SP|非施法原SP|非施法新SP|
|---|---:|---:|---:|---:|
|L1|13|8|8|5|
|L3|19|12|12|7|
|L5|25|16|16|9|
|L7|31|20|20|11|
|L10|40|26|26|14|

法系判定不变：实际装备的法系主/副武器，或已准备的自学法术；未准备法术、背包未装备物品、装备附带技能、名字与职业标签本身不授予额外容量。

只降低容量，不提高单次费用。范围与单体同费；基础自然恢复L1为0.5、L10为1 SP/轮；疲劳上限8、疲劳和过载修正、完整休整与成本例外不改。免费法杖普攻不新增SP费。武技与辅助技共享SP，也会减少续航。

## 四档选型与完整战斗计数

四档都使用批准的soft40，只有SP容量不同：

|方案|法系容量|非施法容量|
|---|---|---|
|current旧容量|10+3L|6+2L|
|moderate温和|8+2L|5+L|
|balanced采用|6+2L|4+L|
|tight偏紧|4+ceil(1.5L)|3+L|

探索4×960=3840场；current与balanced更换种子复核2×960=1920场；首次远端验收240场；合入最新main后追加240場。合计6240次完整战斗执行，最后480场是回归重放，不是独立新场景。所有计入的场次均结束（含规则平局），无非法生命或无效初始化。开发中断/预试及被混写的中间输出已隔离，受影响方案从空文件完整重跑，最终每组ID唯一；不重复计数。

每组960=10等级×8模板×3环境×小战/会战×1种子×正反方位。环境平原、森林、城镇夜间；模板单体法术、范围法术、控制、治疗/屏障、召唤、超训练2级施法、纯武技、长续航。普通小战使用正常生命，会战20人/队；范围2对3、召唤1对2，不能把混合胜率当职业胜率。长续航压力场明确使用1600生命个体或100成员编队和不溃，不代表日常战斗轮数。

探索种子314159，复核161803，配对阵容、地图及镜像方位。调用生产SmallBattle/MassBattle自动AI，不调用LLM。完整日志包含初始快照、行动与最终状态。施法节奏另有240组20次自身行动的有界探针，远端重放采用档60组，均不计完整战斗数。

### 探索结果：普通施法组每档720场

|方案|胜场|平局|曾出现SP不足的战斗|技能使用次数|第3轮后技能次数|
|---|---:|---:|---:|---:|---:|
|current|271|9|16|1688|491|
|moderate|265|11|62|1616|432|
|balanced|263|10|90|1559|395|
|tight|244|11|262|1437|418|

SP不足指某次可行动时，当前SP低于全部已准备的非物品/装备法术费用；不是引擎报错，也不代表不能普攻、移动或休整。该指标不检查冷却，不能当作“被迫空过”。

选择balanced是约束续航而不过早频繁断档的取舍，不是全局最优。普通施法组相对旧容量少8胜，偏紧档少27胜且资源不足场数明显上升。所有候选的已测试同阶常用技能在满SP下都可初次施放。

|指标|旧容量|采用档|

|普通施法小战胜场/360|192|180|

后段施法377→292，减少22.5%；但秒杀77→76基本不变。SP限制持续爆发，不会降低一次合法首发的伤害，不能宣传它解决了法术秒杀。秒杀是某次主结算损失达到目标初始满生命，统计双方个体，不是首轮胜率，也不统计编队清空。

武技续航下降是实际代价。长战中自然恢复和休整仍能继续供SP，所以这不是整场技能次数的硬上限。

普通单体法术、缺SP时普攻而不主动休整的有界探针：L1与L5从连续施法5次后停顿变为3次；L10从6次变为4次。之后恢复足够仍可再施法。控制、跑位、复合效果与疲劳会改变实际序列。

```bash

python3 scripts/compare-sp-v11.py --ref 1fe26ae3d542531c9920943001fe552e2df0bfda --out /tmp/v11-sp --phase holdout --variants current,balanced

```

比较脚本git archive建立隔离副本，只替换endurance-v2容量表达式，不污染工作源码。大日志不进入安装包，聊天证据包提供全部6240场指标/战报、manifest、测试JSON、浏览器报告及SHA256。原广覆盖脚本保留历史baselineCommit字段，实际来源以本页和验证manifest为准。

固定模板、稀疏种子、相关环境与镜像，不把6240当独立同分布样本，不声称小胜率差有统计显著性，也不保证所有手操、极端自定义技能或LLM指挥得到同样结果。SP与毁伤曲线承担不同职责：前者限制储备和续航，后者收敛低中阶额外爆发。
