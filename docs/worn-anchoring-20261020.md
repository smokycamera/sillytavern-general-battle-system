# 佩戴道具修正（2026-10-20）

本次针对佩戴修正与显示；附件的问题清单作为复现资料，不直接采用其中的数值建议。

- 新实物标记 `wornEffectModel: worn-anchored-v1`，按自己的等级编译后冻结。读旧存档、开战、查看历史不会重算旧实物。
- 伤害继续用 D=0.10/0.22/0.35/0.50/0.67/0.85/1.06/1.29/1.54/1.82；满额主词条相邻级总伤害约提高10%–11%。
- 其他佩戴收益的 G 改为1/1.30/1.65/2.05/2.50/3/3.55/4.10/4.65/5.20，抬高低阶、保持原L10上限。精度、防御为qG，士气为8qG，通用/通道抗穿为0.5qG/0.75qG，q=点数/10。
- 正向速度独立改为qL；满额+10主词条从L1的+1步到L10的+10步，每升一级增加1步。负向速度仍按封顶G结算。主动道具仍用原G，不受本次调整影响。
- 负词条仍以G≤1.4、D≤0.67封顶；同方向取强、通用与通道合计上限继续执行。满额防护L10仍为2.6抗穿，单通道3.9。
- 旧道具在库存点“更新佩戴数值”，先预览，再提交。保留原名称、身份、点数、特质、归属及改造历史。无法匹配历史配方的手工冻结效果拒绝猜算。旧防御可能降低，预览同时保留旧值；这是消除原始点数与等级换算混用，不承诺对所有历史物品数值只升不降。
- 旧速度实际仍提供先攻，没有提供移动；报告的“完全不生效”不准确。显式更新后切换为等级锚定的移动效果。
- 卡片用属性网格展示实际值与单位；下一级增量直接可见。装备栏、预览、历史共用同一格式。配方在折叠说明中，特质只显示名称和等级，覆盖提示用实际值。
- 生成纯修正升级奖励以+10主词条为标准；+1/+2作为副词条，用户手填仍保留。小额词条不保证每一级跨过整格移动或士气档位；满值、免疫、无法穿透或更强来源覆盖同样可能使实际收益饱和。

针对性验证覆盖十二个方向、每方向+1至+10、L1至L10共1200个编译组合、真实命中率与移动预算、负面封顶、历史实物只读、显式升级与可信配方、库存预览及历史保存。
