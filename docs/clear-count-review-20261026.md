# clear 与数量示例复核（2026-10-26，3.0.20）

本次统一正文解除入口，补充 count 示例，并修复等价道具规格的重复交付。enchant、stabilized、protection 及主副武器配置规则保持 3.0.19 的实现与说明。

## 世界书采用原文

```text
解除状态效果使用unit_set的clear，按名称填写，多个以逗号分隔，如clear="中毒,诅咒,飞行"。clear="all"解除全部当前状态效果
```

新规范不再展示 unaffect/unbless 或要求填写来源编号；旧事件继续解析。运行时提醒也移除来源编号的填写说明。

## 数量示例

```xml
<example situation="示例：两支再生赤翼骑兵连，每支现员80、编制100">
<tb>
<spawn name="再生赤翼骑兵连" side="ally" scale="company" level="5" hp="80" hpMax="100" body="human" mount="true" speed="4" weapon="骑枪:长兵器L3" weapon2="军刀:剑L3" armor="板甲:重甲L3" shield="骑兵盾:中盾L3" skills="冲锋:物理单体L4+近战+突进L4,鼓舞:buffL3+士气L3" traits="再生L5" items="治疗药水:buffL3+治疗L3×2" count="2"/>
</tb>
</example>
```

count 是新建单位卡数，因此放在 spawn 中；已有单位的 unit_set 属性示例保留。主体与每个可分级效果分别标 L；射击、热能、环形等方式、通道和形状词不单独分级，修正仍写作 +6精度、-2治疗等。

## 实现与兼容

- clear 同时匹配普通状态和剧情授予能力的中文名称或规范 id；all 清除当前状态和有效的非装备授予来源，固有特质及装备能力保留。
- 一条来源只解除部分效果时，原记录及内容保留并标记撤销，剩余效果以新的内部来源沿用原期限、剩余次数与等级；重放旧授予事件不会重新授予或续期。
- 保留剩余效果后再撤销原来源，避免误清仍有效的再生累计值。旧 unaffect/unbless 引用部分解除前的来源编号时，也能解除该来源剩余效果。
- 同批 add 与 unit_set 以及持有、库存道具的匹配消除冗余同级标注，buff治疗L3 与 buffL3+治疗L3 视为同一规格；不同实际等级与修正仍分开处理。匹配不改写或重编冻结实物。
- 历史战斗、快照、回放与地图几何不重算，战斗规则仍为 V38。修改前世界书和运行时提醒保存在 docs/prompt-backups/ 的 before-unified-clear-count 文件中。
