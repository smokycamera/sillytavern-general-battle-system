# 非对称地图生成

新战场使用独立的 `field-v2:` 种子。取消旧生成器的旋转对称配对；标准、室内及所有环境分别生成真实格子。读档继续恢复保存的格子，不重新生成地图。

- 平原：开阔地为主，少量成片崎岖地、小林地或低丘以及掩体。
- 森林：相邻生长的林地片区、林间空地、崎岖地和掩体。
- 山地：相邻山地区域、崎岖地、通道和掩体。
- 巷战：错位短墙、转角街区、偏置广场或破碎废墟；墙段方向、长度、位置独立变化。
- 攻城：靠近守方的防线、缺口、纵深墙段及掩体；切换进攻方同时调整防线方向。
- 室内：5×7 地图允许墙段进入不同纵深，先在空地图副本中计算本场部署并保留这些位置，避免墙体随机挤掉合法单位。明确坐标与空地混编同样保留，不改动名单。
- 夜间：光照独立叠加，同一种子的地理布局不因昼夜变化而重排。

两条各自随机起点和转折的通路贯穿地图，不再保留固定的左、中、右三列直道。所有可通行格、双方部署区与任务点均连通；发现孤立区域时按最少穿墙代价打开局部缺口，不清除整张地图的墙。标准地图仍保留双方各三排部署区，护送出口及双方攻城目标预先避让。

地形仍使用已有的开阔地、掩体、墙体、崎岖地、森林、山地，沿用现有移动、视线与环境规则。这次没有增加高低楼层、破墙或新地形伤害机制。会战仍使用既有阵位系统，不生成小战格子。

设计参考：Cogmind 开发者关于布局骨架、可替代通路、布局完成后的可达性检查与模块组合的文章。采用适合小型战术棋盘的独立实现，没有复制原游戏代码或资源。

- https://www.gridsagegames.com/blog/2019/03/roguelike-level-design-addendum-procedural-layouts/
- https://www.gridsagegames.com/blog/2017/01/map-prefabs-in-depth/

验证：48 项地图/空间/部署/攻城/场景选择/飞行/AI 相关测试通过；生成测试涵盖 4 种尺寸 × 5 种环境 × 16 个种子的 320 张地图，另检查单格阻塞时的通路、光照独立性、主题差异、室内满容量部署和快照恢复。抽样 24 场自动战斗全部接敌并完成结算；这不是全面平衡性评测。
