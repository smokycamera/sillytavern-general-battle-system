基线：最新远端 test 2.5.0，提交 `2795f2b`。该提交包含最近的道具成长、traits 组合修正和取消技能准备数量上限；远端 main `a042d83` 尚缺这一笔。本次在该 test 基线上修改，发布版本为 `2.6.0`。

## 游戏与正文资料

- 经验升级后，存活个体补满升级后的最大生命；编队补满现存成员生命，保持现员、编制与可救伤员数量。未升级不触发回血，死亡档案不自动复活。
- 发给正文 AI 的单位资料移除累计 `xp`，改发 `xpProgress`（本级已有经验）和 `xpRequired`（本级升级所需经验）；满级显示“已满级”。内部累计账本继续保留，角色状态手动发送同步采用本级进度。
- hero 及主控绑定单位的发送资料使用“该单位士气锁定，请勿在tb修改”，不再向它们发送可误读为待修改字段的当前士气和士气上限。
- 装备、道具、技能及相关效果的玩家可见属性最多显示两位小数，不改存档或结算数值。
- 物品清单提示词按用户逐次确认的文字更新。旧默认模板精确匹配后使用新文案，自定义模板和关闭设置保留。

确认的物品清单提示词：

```text
【实物清单】take 为扣减已有物品（出售、消耗、遗失、交出等），id 填实物编号；reforge 为改造已有物品，id 填实物编号，spec 填改造后的类型、L等级及修正，例如 spec="剑L5+2伤害"；give 为新增物品，可填接收单位真实 id，省略则入公共库存。实物 id 与单位 id 不可混用。
{{content}}
```

## 世界书实际差异

四条正文逐字采用《修正.txt》对应的完整顶层块，不改条目触发设置。

1. **交互与战报核心**：补充 traits 必须按等级锚定分级，明确不分级的特质除外；示例的空 `traits` 改为 `再生L5`，示例单位改名为“再生赤翼骑兵连”。
2. **单位与装备**：移除最新 test 追加的“V23 特质与道具组合”详细数值和公式段。武器、盾牌枚举原本已与修正稿相同，本次没有新增种类。
3. **技能与效果**：同样移除追加的 V23 详细段，并在技能说明、traits 列表入口明确要求可分级特质填写 L1–L10。
4. **规格等级锚定**：正文与最新 test 相同，无内容变化。

这些世界书文案调整不会撤销最新 test 的道具/traits 机制。多特质增伤的 25% 协同、饰品独立伤害倍率、通道抵抗减伤、防护组合、吸血每轮预算、治疗/屏障新表、旧实物显式升级，以及不限已学技能准备数量均继续保留。
