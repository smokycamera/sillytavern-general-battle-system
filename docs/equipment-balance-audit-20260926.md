# 武器、装备与技能平衡检查

日期：2026-09-26。基线：GitHub main `e669688498d5be5ac5f850c6e4fa7cbb738118b1`（PR #15 已合并）。修改分支：`audit/equipment-skill-balance`。包含可安装的 dist；本次没有合并主线。

## 结论

已有的近战定位、护甲通道克制、直射/曲射与前排遮挡具备真实差异。本次发现并修正五类问题：投掷对轻型投射的全面优势、控制技能机会成本失衡、混合治疗预算被进战升级覆盖、回能混合治疗可零净消耗、盾击遗漏高阶装备投影。

修正后保留各自优势与代价，没有把所有武器调整成相同伤害。测试支持这些具体结论；不代表所有自定义装备、阵容、地图和 JEV 指挥下都已达到完全平衡。

## 测试方法

- 修正前后均运行 6,200 个武器对抗预览：17 类武器、L1–10、5 类护甲、小战/会战、开启/关闭连队溢出、个体/百人编队。同为 T5，固定装备种子，无额外特质；排除人形个体非法携带的三种重武器。
- 200 个护甲配置：L1–10 × 5 类护甲 × 通用/动能/热能/奥术构型。
- 300 个技能配置：15 种单独或组合机制 × L1–10 × 两种 V4 命中规则，经过实际进战升级逻辑。
- 140 个消耗品/配件配置：7 种消耗品、7 种配件，分别检查 L1–10 的实际编译结果。
- 800 场实际自动对战：10 种对抗 × 小战/会战 × 20 种固定种子 × 交换阵营。T5、装备L3；小战42生命、会战100人；开阔地、同档甲、无技能，士气固定100。小战从2格开始，会战从双方前线开始；外部30轮截止。
- 另外40场会战诊断：20场高士气延长至引擎默认40轮上限；20场恢复生成器默认士气、同样观察至40轮。后两组每情境只有一个种子及阵营互换，用来定位拖长原因，不作统计胜率结论。

武器预览是公式评估，不是随机比赛。编队、多段攻击与目标耗尽会使预览成为近似值；持续输出采用 `单次期望/(装填+1)`，没有计入装填期间改用副武器。胜负样本使用本地自动AI，未调用 JEV/外部模型。完整摘要见 [结果 JSON](equipment-balance-results-20260926.json)。

## 修正及证据

以下技能示例为 L5、对方 T5 的普通人形单位，不带抵抗强化；控制概率不包含伤害技能额外的命中门槛。

| 问题 | 原行为 | 修正后 |
| --- | --- | --- |
| 投掷挤掉轻型投射 | 同为单手、负重1，投掷射程更远、伤害更高且贴身无惩罚，同时无准备间隔 | 投掷后准备一回合；保留单发/射程优势，轻型投射获得持续火力优势。旧实物不重掷，明确自定义 reload=0 保留 |
| 控制缺乏取舍 | 眩晕、定身、沉默、缴械都是3SP、冷却3、50%成功；眩晕+定身也只需3SP。附带眩晕的伤害技能进战后冷却变1 | 专用控制2SP、冷却2、50%；眩晕4SP、冷却3、40%；眩晕+定身5SP、分别30%/40%。伤害附带硬控保留冷却和费用下限 |
| 混合治疗免费追加效果 | 纯治疗、治疗+屏障在V4进战后都恢复225，均3SP | 纯治疗225/3SP；治疗+屏障恢复113并给17屏障/4SP。治疗预算按效果数量分配 |
| 自身治疗+回能零净消耗 | 花3SP，回3SP，另得225治疗 | 花5SP，回3SP，治疗113；净耗2SP。回能强化提高返还时也同步维持额外效果的净费用 |
| 盾击不随规格成长 | 临时盾击武器缺少规格信息；L3/5/8/10同级重甲对抗均可能完全无法穿透 | V4使用真实盾牌的等级与体型投影；L5盾击穿透10，对同级重甲有实际伤害。L1盾不能靠L10技能穿透L10甲 |

旧通用技能采用一次性配方升级，保留技能身份、准备槽、已用次数与已有冷却账本；重复读取不重复叠加强化。新版配方及高阶范围参数可通过档案校验。自定义技能、装备授予技能和旧版战斗规则不被这一通用技能迁移重写；投掷准备与V4盾击按运行时规则生效。

## 差异性结果

| 类别 | 有意义的优势 | 相应限制/代价 |
| --- | --- | --- |
| 剑 | 命中+1、近战格挡+1 | 仅1格，破甲低 |
| 斧 | 较高伤害、穿透+1 | 命中−1、无剑术格挡 |
| 长柄 | 2格/2阵距，越过友军前排 | 贴身命中−2，敌军前排与墙仍阻挡 |
| 钝器 | 穿透+2，打重甲优势明确 | 原始伤害×0.8、命中−1 |
| 天生武器 | 不占手与负重，缴械后仍可用 | 伤害预算较低、无剑术或钝器性质 |
| 轻型投射 / 投掷 | 前者连续射击；后者射程、单发和贴身更强 | 前者射程短、贴身惩罚；后者有准备间隔 |
| 弓弩 / 法杖 | 可越过友军前排 | 都不能穿墙或敌方前排；弓弩受贴身限制，法杖走奥术通道 |
| 火枪 / 步枪 / 单发重步枪 | 单发爆发 / 连续两段 / 更强穿透与射程 | 单发类需要装填；重步枪贴身惩罚更大 |
| 机炮 | 三段火力、较强穿透 | 炮组或大型/载具平台、负重与射线限制 |
| 直射炮 / 曲射炮 / 爆破 | 重型单发与编队爆炸 / 越障打击 / 近距爆破 | 装填；曲射需要观察及最小射程；爆破距离短 |
| 能量武器 | 热能通道对通用/动能甲强 | 热能特化护甲可强力克制 |
| 护甲与盾 | 重甲提高抗穿；特化甲交换通道防护；盾提供防御 | 重甲有速度、负重与轻装战术限制；盾与护甲的规格耐久取较大值，不相乘 |
| 主动/被动配件、消耗品 | 回能、净化、治疗、有限屏障、炸弹、车辆维修；夜视/林行等提供功能 | 实物消耗或次数限制；配件占槽与负重；同类配件不得重复装备 |

真实小战样本，40场/情境（左右阵营互换，结论仅限本情境）：

| 对抗 | 情境 | 前者胜 / 后者胜 |
| --- | --- | --- |
| 剑 / 钝器 | 无甲 | 22 / 18 |
| 剑 / 钝器 | 重甲 | 6 / 34 |
| 剑 / 斧 | 无甲 | 19 / 21 |
| 剑 / 斧 | 重甲 | 10 / 30 |
| 轻型投射 / 投掷 | 中甲、2格开战 | 26 / 14 |
| 步枪 / 单发重步枪 | 中甲 | 23 / 17 |
| 步枪 / 单发重步枪 | 超重甲 | 9 / 31 |
| 步枪 / 能量 | 动能特化重甲 | 0 / 40 |
| 步枪 / 能量 | 热能特化重甲 | 40 / 0 |

这支持“装备随目标防护改变优劣”。例如钝器没有通吃无甲与重甲，重步枪也没有全面替代普通步枪。强通道克制由现有穿透阈值产生，不宜将此处100%样本胜率外推到其他地图或阵容。

## 保留的边界与后续观察

1. **会战节奏仍值得观察。** 高士气百人编队样本中，400场有246场在外部30轮截止时未分胜负，已与真正平局分开记录。延长到引擎40轮上限后，部分重甲对局仍判平。默认士气复查能更快因伤损/士气分胜负；这不能据此宣称所有会战配装已平衡。
2. **被动功能配件的等级不都带数值增长。** 夜视镜、林行靴、守护及耐力护符目前授予固定特质；不同L不会自动变成更强版本。净化也按清除数量阈值升级，不是每级都加量。保留现有定义，不虚构升级收益。
3. **低级武器打高级装甲为零伤害是规格代差设计。** 本次修复的是同级盾击漏接公式，没有删除跨代抗穿保护，也没有把训练等级当装备等级。
4. 自定义装备、任意技能组合、复杂地形与外部指挥不可能由这组样本穷尽。本次没有在用户手机、TauriTavern实机或真实聊天档案中运行。
