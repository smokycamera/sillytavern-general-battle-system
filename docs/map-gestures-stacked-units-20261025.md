# 3.0.13：同格单位身份与地图缩放

同格单位采用每队两行布局，上行显示小兵种图标与姓名，下行右对齐显示完整血量。紧凑格也保留小图标和姓名；长姓名使用省略显示，并在名称提示和地格详情中保留完整信息。区域效果、结构数值和同格数量标记继续位于单位与血量下层。

地图缩放直接调整视图，不在拖动、滚轮或双指移动期间触发战斗计算或整页重绘。地图内滚轮以鼠标位置为中心缩放，两指以中点为中心缩放并可同步平移，鼠标拖动或单指拖动执行平移。拖动和双指手势的兼容点击会被消费，下一次新的点选可立即执行。地图外保留普通滚动行为，Shift滚轮也不触发缩放。

“全貌”按视口宽高计算比例。现有适应/放大/紧凑预设继续保留，切换预设会恢复其100%比例；连续缩放比例保存在本机查看偏好中，状态刷新通过现有原位补丁保留地图和滚动位置。

## 实际浏览器检查

- 在1280px桌面和390px移动尺寸检查紧凑格、放大格、两队同格及区域效果重叠：小图标、姓名可见，血量独立位于第二行且未裁切。
- 使用21×27地图执行真实鼠标滚轮、拖动与CDP触摸输入。一次桌面滚轮检查的内容锚点误差约0.3px；鼠标拖动后滚动位置随移动变化，未触发地格点击。
- 双指距离从100px增加到150px时，地图比例变为1.5，浏览器整页比例仍为1；松手后的下一次点选可立即执行。单指平移也得到相应的滚动位移。
- 原位重绘保留同一个地图容器、缩放比例及滚动位置。
- 全貌按钮在390px移动视口中，将21×27地图显示为约340×436px，落在366×438px的可用视口内。

事件回归检查覆盖地图内外滚轮、Shift滚轮、普通点选、拖动点击抑制、新点选恢复和双指缩放提交。手势行为参考[MDN滚轮事件](https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event)及[MDN触摸操作声明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action)，实际结果以上述浏览器检查为准。
