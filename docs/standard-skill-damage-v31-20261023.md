# 标准技能对同级轻甲、中甲伤害（V31，2026-10-23）

本文件保留“只修武技、尚未降低法术”的历史测量基线。2.10.5 新战斗采用 V32，当前数值见[55%实施与验证报告](standard-skill-damage-v32-20261023.md)。

本次已在本地补上单体武技从 ×2.2 到 ×1.5 的校准，覆盖当前 skills-v4 及生成的 V14–V21 公式，使用新 V31 规则。V30 及以前的规则与保存战斗不变；技能实例、强化、附加效果折扣、冷却与资源账本不重写。对单位和结构使用同一校准函数。法术伤害、穿透、护甲、生命、特质与道具数值未调整。本次未发布远程分支。

## 测量口径

- 双方为 human hero / infantry；单位训练、武器、护甲和技能全部同级；品质 3，关闭个体随机浮动。无特质、正负修正、盾牌、屏障、饰品、疲劳或前置增益，目标满血，开阔地相邻。
- 标准物理主表使用同级普通剑的近战单体技法；独立动能投射另列。法术实际分别验证奥术、热能，两通道在本表默认护甲下伤害相同。换用不同武器会改变武技伤害，本表不能代替所有武器。
- 表内为护甲结算后、尚未按目标剩余生命截断的命中伤害均值；括号为占目标最大生命比例。非暴击与暴击分表，均不把未命中计为零。暴击均值超过 100% 表示具备秒杀风险，不表示每次暴击必定击杀。
- 共 160 配置、340 次实际施法（普通命中、暴击，另含旧倍率对照）；以固定均值骰验证实际执行，并核对引擎精确预览的普通命中均值。没有运行 AI 对局或蒙特卡洛循环。
- 当前生命锚定已包含 graded-v1 的 ×1.5；默认 infantry 的 +4 基础生命一并计算。低等级、其他原型或历史手工生命档案可能不同。

## 修复前后与后续调参判断

|等级|轻甲：修复前→后|中甲：修复前→后|
|---|---:|---:|
|L4|56.33 → 38.41|39.98 → 27.26|
|L5|67.65 → 46.13|48.01 → 32.74|

1. 同级剑技在轻甲与中甲之间有实际减伤差异：穿透/防护差为 +0.5 / 0，通过率分别为 77.5% / 55%。当前单体法术穿透为 2L+2，默认轻甲与中甲的热能、奥术防护均被完全穿透，两类护甲的法术伤害相同。
2. 在无增伤基准下，单体剑技普通命中未达到满血秒杀；法术单次占生命的比例总体更高。后续最值得先评估的是法术穿透与护甲通道保护关系，再决定伤害基准是否还需调整。
3. 这张表隔离了增伤组合；狂暴、佩戴和其他强化仍会放大结果，因此不能从裸技能未秒杀推断实战组合秒杀已经解决。
