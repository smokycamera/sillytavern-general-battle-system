# 3.0.9 地图review三项修复

基于最新main 2873576，并合入test已有的安装包同步提交ddfa595。3.0.8审查的固定输入与原始结果保留在本地artifacts/map-review-20261025/，不覆盖。

## 内墙楼梯

分区生成原来统一把相邻inside格作为access，inside同时包含夹道与内城。现在外墙只选夹道，内墙只选town。实际战斗验证无登城特质的攻方在夹道攀内墙被拒绝，从合法城内楼梯可登内墙，夹道仍可登外墙。

## 独立内门及通路

原来每个外门沿通往核心的路径选首个内墙格，四个外门会重用内门，只生成七座门。现在维护已用内门集合，对候选分别验证外门到内门的夹道路段、内门到核心的内城路段，选定后独立设置状态。没有合法候选时返回容量不足，交由既有扩大地图流程处理。验证四外门对应四内门，开启、关闭和外门已毁时的内门关闭均独立；全部开门后每个外门都有城内地面通路。

## 斜接墙头

保留通用neighbors为四方向，另加带单位楼层的movementNeighbors。仅当单位在完好的墙、门或塔的平台上，目标也是同类完好平台，且两个正交墙角均没有结构或旧式wall地块时，增加与现有绘制一致的斜向边。L角仍走原有正交连接，已毁墙角不重新连上。

单目标、范围可达格及反向多源寻路接受可选单位参数。手动移动、逐步执行、普通AI、整轮意图、技能估值和部署估值传入实际单位；地图构造和地面寻路保持原有四方向。实际样例C10到D11从无路变为一格墙头移动，手动执行与hold意图都保留平台楼层，快照恢复一致。四个斜向分别验证地面和空中不增加斜走、L角和已毁端点不产生捷径。
