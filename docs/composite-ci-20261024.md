# 3.0.3 CI失败与组合等级复核

## 失败证据

[PR #154的CI](https://github.com/smokycamera/sillytavern-general-battle-system/actions/runs/40076686184/job/120821425685)在全量测试阶段失败：2745项中2737通过、8项失败。5项为`check-layered-test-baseline.mjs`中已经登记的V5/V6历史回放差异，新增3项如下：

- `independent-skill-damage-v32.test.ts`仍要求共享开战入口选V32；本次已明确升级新战斗为V33。更新此项断言，并保留55%独立技能伤害校准检查，其余历史V31/V32伤害及快照断言不变。
- `traits-phase2-a.test.ts`仍要求一项技能只能写一个L；更新为独立等级的实际编译断言。复核同时发现前置共享L识别过宽，把`buff+吸血L3+偷袭L8`误读为共享L3；现在仅当L紧跟类别时采用前置共享等级，此例保留吸血L3、偷袭L8。
- `signed-enhancements.test.ts`发现真实解析回归：`魔法单体L5+热能`被规范为数值强化，热能机制丢失。恢复无点数通道词的机制含义，显式`+3热能`仍是数值修正；道具和正文技能均覆盖热能、奥术两种通道。

没有修改或扩大历史失败允许名单。

## 不可分级附加词

近战、射击、盾牌、投射、热能、奥术、战技、扇形、直线、环形、连锁只选择攻击方式、通道或形状，不接受单独的效果等级。飞行、机械化、两栖、航行、登城等不可分级特质也不接受局部等级。新输入为这些词标L时，保留词本身并忽略该局部L，不生成额外等级配方或改变临时授予的期限；技能共享等级本身继续决定正常的授予期限。

例如`（物理范围+近战L9+环形L8+惊惧L2）L4`等效于`（物理范围+近战+环形+惊惧L2）L4`；`（buff+飞行L9+治疗L2）L4`保留飞行的开关能力和治疗L2，飞行仍按共享L4使用正常授予期限。

可分级效果和旧名称的独立等级继续保留。只在新文本解析时丢弃不可分级词的局部L，已有机制编号与已存配方的读取不改写，旧战斗不重建。提示词及世界书没有新增改文。

## 验证与发布

本地5个相关测试文件42项通过；补充不可分级特质的实际授予／到期断言后，专用文件9项再次通过。检查覆盖三项CI失败、正文容错、原有组合等级、不分级的11类结构词及5项特质、通道机制与数值强化区分和保存读取。类型检查通过。

完成改动后的review确认：只在新文本解析时过滤不适用的局部L，不修改已有编号解码和存档配方；可分级效果的等级、作用及预算沿用原编译路径；没有更改提示词、世界书、历史规则及允许失败名单。

发布保留3.0.3版本，通过修复分支PR合入test；不晋级main。后续CI状态与本地结果分别报告。
