# Lorebook system explain

对应同目录 `!通用战斗系统约束.json`，核对日期：2026-09-26。本文件给使用者解释机制，不需要作为额外世界书导入，以免重复占用上下文。世界书保留原有 4 个条目及其触发设置；条目名称中的 V2 指数据/协议体系，当前战斗由 V4 规则执行。

这里区分三件事：世界书约束正文如何描述和提交事件；插件解析并核对事件；战斗引擎决定合法行动、命中、伤害、状态与胜负。正文不会因为写了一个名称就获得该名称暗示的能力。

## 条目 0：战阵 V2 交互与战报核心

### 叙述与填写规则逐项对应

| 世界书项目 | 对应机制与用途 |
| --- | --- |
| 剧情在开战前停止 | 正文提供遭遇、环境、单位与战外变化，玩家在面板开始交战。正文不能提前决定战斗结果。 |
| 事实清单、顺序与最新状态 | 战报是已经结算的事实；正文可以描写气氛与动作，但不能添加未发生的命中、伤亡或移动。 |
| 已观测敌军 | 交战中输出使用我方可观测信息；隐藏单位不因正文叙述而暴露。 |
| 阵亡与濒死 | `dead` 是死亡；`dying` 是存活但失能。非致命模式的倒地不能写成死亡。 |
| 不描写血量、骰子、回合数 | 这是正文表现约束，不是删除引擎数值；玩家仍能在面板和战报明细查看数值。 |
| 主控与指挥官 | 主控是玩家操控对象；指挥官是编队指挥角色。两个身份可以不同，不能默认主控有下令权。 |
| 仅战外、有依据、尚未应用的事件 | 战斗伤亡和经验已经由系统结算，不能再用事件重复扣血、发经验或补发战利品。战外获得、修理、休整等另行核对。 |
| 唯一末尾 `tb` 块 | 每行一个小写、自闭合事件；正文格式闭合后再输出，避免将状态栏、示例或思考当作事件。解析器可以容错，但不应主动依赖容错。 |
| 属性及转义 | 大小写按规范，例如 `hpMax`。属性双引号用 `&quot;` 转义，和号用 `&amp;`，不能把 JSON 直接夹入未转义属性。 |
| 整数与小数 | 等级、修正点、生命/人数、数量和期限为整数。`unit_set` 的经验及允许的连续数值可以是小数；有限、非负防护 1.5 有效。 |
| JSON 例外 | 只有 `unit_set.data` 接受 JSON 对象。普通事件不接受 JSON、坐标或效果脚本。 |
| 空值和清除 | 可选项不用即省略。高级补丁仅在明确删除可选字段时用 `null`，清空数组用 `[]`；不能把空字符串当作未知值。 |
| ID 不能互换 | 单位 ID 指档案，实物 ID 指库存装备，效果来源 ID 指某次效果授予。名称不是 ID。 |
| 人数、生命与卡数 | `hero.hp/hpMax` 是个体生命；`company.hp/hpMax` 是现员/编制，载具按车辆数。每位成员另有生命分组，不能把总生命填成人数。`count` 才是单位卡数。 |
| `count` 与上限 | 一条 `spawn` 的 count 为 1–20，当前场景最多 32 张单位卡。80 人的一个连队是 `hpMax="80"`，不是 80 张卡。 |
| 合并同对象事件 | 同一单位的互补更新、学习及同一实物的改造应合并；冲突不会因为排列靠后就当然覆盖。 |

### 单位事件与高级修改

| 事件/字段 | 实际作用与限制 |
| --- | --- |
| `spawn` | 新建档案，并按规格生成单位；不能用它重建已有同名档案来绕过伤亡。 |
| `deploy id` | 从已有档案派上场，沿用当前生命、装备、经验；不是克隆一张新卡。 |
| `unit_update id hp/hpMax` | 简单战外生命/人数更新，至少写一项。仅增加 hpMax 扩大上限，不自动补满现员。 |
| `unit_set id` | 战外高级修改，必须存在真实档案且当前战果已结算。未知字段、非法值或配装冲突会拒绝，不能直接写任意 Combatant 属性。 |
| `name / side / scale / archetype` | 修改显示名、阵营、个体/编队与基础原型。scale 改变必须符合转换与人数约束，不等于免费复制人员。 |
| `level` | 训练等级 1–10，影响训练能力，不代替武器和技能的 L。只改等级时本级经验进度重置为 0。 |
| `xp / xpProgress / xpValue` | 分别是累计经验账本、本级已有进度和经验价值字段；允许有限非负小数。要在改等级时保留本级进度，明确同时写 xpProgress。 |
| `hp / hpMax / memberHp` | 当前生命/人数、最大生命/编制，以及成员基础生命；不能混为同一个量。 |
| `atk / def / spd` | 基础攻、防、先攻速度字段；与 L 技术等级、地图移动档位 speed 含义不同。 |
| `morale / moraleMax` | 当前/最大士气；战斗内士气及溃退由系统结算。 |
| `state` | ready/dying/dead/routing/fled；dead/dying 要与零生命一致。复活应同时有剧情依据、合法生命和 ready 状态。 |
| `body / mount / speed` | 身体类型、真实坐骑、基础移动档位 1–5；不是地图坐标。 |
| `weapon / weapon2 / armor / shieldSpec` | 修改主武器、副武器、护甲、盾规格，并检查装备限制。普通库存物品入库不会自动替换这些槽位。 |
| `skills / traits` | 修改技能/特质；名称必须能解析。通过 data 替换数组会覆盖该数组，不能当作无条件追加。学习少数技能优先用 learn。 |
| `retired / note / reason` | 档案退役标记、备注及修改依据；文字不会自动变成战斗能力。 |
| `data` | 支持的对象递归合并，数组整体替换，bonuses 也整体替换。便捷属性和 data 同时给同字段时必须一致。 |
| `armor.values.protection` | 可仅写 kinetic/thermal/arcane 中一个，其他通道保留。保存为实物防护覆盖值，仍受身体固有防护下限约束；不再重复叠加装备防护配方。 |

单通道示例（只有剧情明确改造并且处于战外时使用）：

```xml
<tb>
<unit_set id="真实单位id" data="{&quot;armor&quot;:{&quot;values&quot;:{&quot;protection&quot;:{&quot;kinetic&quot;:1.5}}}}" reason="明确的护甲改造"/>
</tb>
```

该值是动能防护 **1.5**，不是加 1.5，也不是将其他通道归零。若希望同级配方强化，用 `+5动能防护`（折合 +1 档）等词条。

### 环境与三个原有示例

`field.env` 对应 plains 平原、urban 城镇、siege 攻城环境、forest 森林、mountain 山地；`light` 为 day/night，省略默认 day。它们用于下一场生成地图和环境修正，不把进行中的战场重画。攻城地形与攻城夺点任务是相关但不同的配置。未知环境暂缓填写。

| 世界书示例 | 应理解为 |
| --- | --- |
| 夜间森林，deploy u1，spawn 守备连 | 设置下场环境、派遣已有 u1、新建一张 80 人敌方连队卡。 |
| unit_update u1 hp=500 后 deploy | 在已有编制上限允许时补到 500 现员，再参战；不是加 500，也不是治疗每人 500 生命。 |
| unit_set 常用属性示例 | 展示受支持字段，实际只填有依据的变更。不能把所有字段复制到每次回复。 |

## 条目 1：战阵 V2 单位与装备

### 新建单位与规格

| 世界书项目 | 对应机制 |
| --- | --- |
| 必填 name、side、scale | 生成名称、ally/enemy 阵营和 hero/company 单位。company 还要 hpMax；写 hp 必须同时写 hpMax 且不能超过上限。 |
| level 默认 1 | 新建时训练档位，不是武器科技。明确有高训练依据再提高。 |
| weapon、weapon2 | 分别是主副武器；攻击仍占同一次主要行动，不因双持自动多打一轮。手数、负重、身体适配由配装检查。 |
| armor、shield | 护甲类型和 L 分别决定负担与规格；spawn 的 shield=true 表示生成盾，不是护甲等级。精确盾规格可用实物或 unit_set.shieldSpec。 |
| body | human/large/vehicle/giant 决定实际体量、容量、力量和身体防护；非装甲炮兵人员仍为 human。 |
| mount | 只表示真实坐骑，骑射也要求坐骑；车辆稳定装置不能冒充坐骑。 |
| speed | 基础移动档位 1–5；最终移动还受到身体、装备、坐骑、地形和状态影响。 |
| skills、traits | 给实际已知技能与规范特质；名字不能生成额外能力。 |
| 名称:类别L等级 | 名称用于显示，类别提供机制，L 给强度预算。L1–10 需按第四条等级参考选取。 |
| 盾L、治疗L | 分别生成盾或治疗消耗品；不是任意名词加 L 就能生成装备效果。 |

### 武器类别逐项对应

| 类别 | 机制差异 |
| --- | --- |
| 投掷冷兵器 | 标枪、飞刀等短距单手投掷；可抵近使用，投出后准备一回合；单发强于轻型投射，持续火力较低 |
| 单发重步枪 | 高威力单发，穿透比普通步枪高1；射后装填一回合，抵近命中降低3 |
| 天生武器 | 拳脚、爪牙等身体攻击，不占双手与负重，不受缴械影响；失能时仍不能行动 |
| 轻型投射 | 单手轻型投射：短射程，可作为副武器，占同一主行动 |
| 爆破装置 | 短距爆破：距离1正常、距离2命中−2；英雄一份、编队最多两份攻击，每份最多六名成员暴露；较强穿透，使用后准备一回合，不跨单位溅射 |
| 剑 | 剑术攻守：触及1格／1阵距，命中+1、对近战武器防御+1；缴械或失能时不能格挡 |
| 斧 | 重斧劈砍：触及1格／1阵距，保留高伤害，穿透+1、命中−1 |
| 长兵器 | 长柄支援：触及2格／2阵距；距离0–1命中−2，可越过友军，不能越过墙体或存活敌方前线掩护 |
| 弓弩 | 远程射击：可越过友军，不能越过墙体或存活敌方前排 |
| 火枪 | 单发火枪：高单发威力、穿透额外+1，射后装填一回合 |
| 步枪 | 自动步枪：每回合两段速射 |
| 机炮 | 直射连续点射：三段分摊火力，穿透额外+2，擅长连续火力和装甲交战；重型攻击需要炮组或大型/载具平台 |
| 直射火炮 | 直射重火力：受地形与单位视线遮挡，隔回合一发 |
| 曲射火炮 | 间接重火力：可越过遮挡，需己方观察者；最小射程2，隔回合一发 |
| 能量武器 | 等离子/激光：护甲破甲优势 |
| 法杖 | 魔弹：部分无视护甲；可越过友军，不能越过墙体或存活敌方前排 |
| 钝器 | 钝器破甲：触及1格／1阵距，穿透+2、命中−1；原始伤害上限×0.8，专攻重甲 |

武器描述是类别行为，实际伤害还受 L、训练、通道、防护、耐久、距离和场景影响，不能仅凭表里一个倍率断定胜负。导弹按实际发射方式归直射或曲射火炮；普通施法攻击归法杖，但法杖普通攻击与魔法技能不相同。

### 防具、通道与射界

| 项目 | 对应机制 |
| --- | --- |
| 无甲/轻甲/中甲/重甲/超重甲 | 类型 0–4；负担与机动代价递增。同类型仍可有不同 L；高 L 既影响抗穿也影响等效耐久。 |
| 动能 kinetic | 冷兵器、普通投射等常见通道；只读取目标对应的动能防护。 |
| 热能 thermal | 热能武器/附魔/技能使用热能防护，不把防御最低通道自动当弱点。 |
| 奥术 arcane | 奥术武器/技能使用奥术防护；未附魔武器不能凭强化词条生成这个通道。 |
| protection=balanced | 保留该护甲原本的三通道分布，不保证三项数值相等。 |
| protection=kinetic/thermal/arcane | 最多从另外两通道转移合计 2 档给选中通道，存在取舍；与独立的通道防护词条不同。 |
| enchant=none/thermal/arcane | give/reforge 的武器通道配置；改变伤害所属通道，不生成并行的多通道攻击。 |
| stabilized=true/false | 车辆武器稳定能力，影响移动后的射击适用性；不能替代真实坐骑。 |
| 直射与直射火炮 | 墙及地面射线上的存活单位可能挡住射界，火炮不自动豁免。 |
| 曲射火炮 | 可越过遮挡，但需要己方观测目标，保留最小射程和装填限制。 |
| 弓弩、法杖、长兵器 | 可越过友方前排，不能越过存活敌方前排；地形射界仍生效。 |
| 旧“火炮”与 indirect=true | 前者兼容直射；旧档明确曲射标记仍按曲射，不按名称猜测。 |

### 物品事件与示例

| 事件/字段 | 机制 |
| --- | --- |
| give item/spec/qty | 新物品入公共库存。机械效果必须提供 spec；qty 默认 1，范围 1–9999，单批机械装备至多 64 件。入库后由玩家分配。 |
| take id/qty/note | 按实物 ID 扣除库存数量，不能超库存；说明出售、消耗或移交原因，不按名称随意删除。 |
| reforge id/spec/name | 改造既有装备并可改名；不是新发一件，也不能重铸消耗品。 |
| body/stabilized/protection/enchant | 仅在该物品种类支持时使用，必须和 spec 相容。 |
| 自行火炮连示例 | 12 辆车的编队，车体、曲射火炮、重甲分别独立指定。 |
| 恢复剂、移交、附魔炮示例 | 给 2 份治疗品、扣 1 件既有物品、原位改造一件炮并换奥术通道；不是三个换装命令。 |

### 属性修正逐项对应

| 修正 | 计算及限制 |
| --- | --- |
| 全部后缀 | 每方向 −10…+10 整数；0 无效果；不能重复同方向，负面不兑换正面额度。 |
| 强度 | 对该来源支持的伤害/治疗倍率生效；防具中负责等效耐久，不等于增加所有属性。 |
| 伤害/治疗 | 每点 5%；同一来源的本项、强度和匹配通道伤害合计受 0.5–2 倍限制。不同来源不是全局统一一项。 |
| 穿透/防护 | 每点 0.2 档；通用与匹配通道合计最多 ±2 档。护甲与盾的防护词条共用此限制。 |
| 单通道伤害/穿透 | 只对实际使用的通道生效；不会转换武器通道或复制伤害。 |
| 单通道防护 | 只增减指定通道，不借用其他通道；最终不能低于身体固有防护。 |
| 精度/防御/速度 | 按离散步长换算，通常每 3 点一档，余数向远离 0 取整；它们不是每点 5% 命中率。 |
| 射程/持续 | 通常每 5 点一档，保留整数格/结算次数；近战技能不凭射程强化变成远程。 |
| 生命/士气/回能 | 按相应单位或技能编译公式作用；保留最小生命、士气和资源容量/消耗限制。 |
| 单位可选方向 | 强度、伤害、精度、防御、生命、速度、士气、三通道伤害。训练写法可用 level="L5-3生命+2热能伤害"。 |
| 武器可选方向 | 强度、伤害、精度、穿透、射程，及三通道伤害/穿透。 |
| 护甲与盾可选方向 | 强度、防御、防护、三通道防护；防护不再同时提高等效耐久。 |
| 治疗等消耗品方向 | 强度、治疗；只能改变该物品已有机制，不能靠词条生成新效果。配件不支持这些后缀修正。 |

穿透通过比例由“穿透 − 对应通道防护”计算；整数点间线性插值：

| 差值 | ≤−3 | −2 | −1 | 0 | ≥1 |
| --- | --- | --- | --- | --- | --- |
| 通过比例 | 0% | 12% | 30% | 55% | 100% |

所以穿透 2 对防护 1.5 的差值为 0.5，通过比例是 77.5%。这是抗穿环节的比例，不是命中率，也不包含等效耐久、守护等后续修正。

### 可选消耗品与配件逐项对应

| 物品 | 机制 |
| --- | --- |
| 治疗/治疗药剂 | 恢复合法容量内的生命或可恢复成员生命，不能凭空补回已死亡成员。 |
| 回能药剂 | 恢复精力，受资源上限约束。 |
| 净化药剂 | 去除可净化的负面状态，不复活。 |
| 强攻药剂 | 短时提高已能造成的伤害，不绕过防护。 |
| 屏障药剂 | 提供有限屏障，由实际吸收容量结算。 |
| 投掷炸弹 | 有射程、伤害与使用动作的投掷消耗品，不是免费附加攻击。 |
| 维修包 | 恢复机械目标的合法损伤容量。 |
| 守护护符 | 提供守护特质，仍遵守来源与叠加规则。 |
| 夜视镜 | 提供夜战适应。 |
| 林行靴 | 提供森林行动适应。 |
| 耐力护符 | 提供耐力训练。 |
| 治疗护符 | 提供装备来源的治疗技能。 |
| 屏障护符 | 提供装备来源的屏障技能。 |
| 净化护符 | 提供装备来源的净化技能。 |

携带消耗品要先分配，使用消耗库存并占主要行动；配件要先装备，卸下后不继续提供效果。仅剧情明确获得时输出 give。

## 条目 5：战阵 V2 技能与效果

### 技能格式与类别

| 项目 | 机制 |
| --- | --- |
| spawn.skills / learn id skills | 前者随新建生成，后者学习或更新指定技能，保留其他已学技能；相同规格的重复声明不能无限叠加。 |
| 名称:效果L等级±强化 | 名称只显示；效果选择执行机制，L 决定规格。多项用英文逗号分开。 |
| 物理单体/物理范围 | 默认使用实际主武器，因此受手持武器、射界、缴械及其通道约束。范围不保证命中所有目标。 |
| 魔法单体/魔法范围 | 默认奥术，可明确热能；受精力、沉默、目标/射程和对应防护限制。 |
| 增益/减益 | 默认分别为攻防增益/虚弱；可以按下表明确效果。 |
| 近战/射击/盾牌/投射 | 分别约束所需攻击方式；盾牌要求合法盾，投射由技能提供动能，不凭名称使用并不存在的装备。 |
| 热能 | 替代默认奥术通道，不能两种能量同时使用。 |
| 范围/战技 | 范围改变目标覆盖方式；战技标明非魔法，其装备和动作前提仍存在。 |
| 附加词上限 | 类别后最多 3 个、不重复；攻击方式、能量、战技和效果都计数。 |
| 扇形/直线/环形/连锁 | 范围伤害形状，四选一；覆盖和目标由地图几何与技能规则计算。 |
| 直接简写 | 眩晕、定身、沉默、缴械、惊惧、减速、击退、拉拽、屏障、治疗、净化、回能可单独作为技能效果名。 |

### 效果词逐项对应

| 效果词 | 执行含义 |
| --- | --- |
| 攻击/防御 | 增益提高，减益降低相应攻防修正；不改装备实物。 |
| 伤害/易伤 | 前者增强输出；后者让目标更易受伤。都不凭空绕过未穿透防护。 |
| 守护 | 减少受到的伤害，不是额外防护通道或永久无敌。 |
| 加速/减速 | 影响先攻和移动；减速在会战中也限制冲锋。 |
| 振奋 | 改善疲劳/状态表现，具体按技能编译，不等于直接复活。 |
| 治疗 | 受缺失生命及可恢复伤员容量限制，满状态不会凭空增加编制。 |
| 净化 | 去除可清除负面状态，自动 AI 按实际解除价值判断。 |
| 回能 | 恢复精力，受资源上限及技能自身成本约束，正强化不能无限净赚。 |
| 召唤 | 通过召唤规则生成临时作战实体，受数量和战场容量约束。 |
| 士气 | 增益提高、减益降低当前士气，溃退仍由士气规则判断。 |
| 特质+规范特质名 | 技能授予对应特质效果，装备/身体前提和同源叠加限制仍有效。 |
| 虚弱 | 减益修正包，降低当前作战表现。 |
| 定身 | 禁移动、起飞与冲锋并降防；仍可进行其他合法攻击/技能。 |
| 眩晕 | 跳过相应行动窗口，不是直接造成额外伤害。 |
| 缴械 | 禁止手持武器攻击；天生武器仍能用。 |
| 沉默 | 禁魔法技能；普通武器动作（包括普通法杖攻击）不自动被禁。 |
| 诅咒 | 降低攻击与防御的状态修正。 |
| 惊惧/士气低下 | 分别施加恐惧压力/士气减益；不溃等抵抗仍生效。 |
| 重伤 | 限制恢复并施加对应作战减益，按状态规则结算。 |
| 中毒/流血/燃烧 | 持续损伤；伤害型附带效果需要满足命中、穿透或实际损伤等触发前提，身体抗性仍生效。 |
| 驱散 | 去除可驱散的增益/效果，不删除装备实物。 |
| 耗能 | 扣减目标可用资源，不制造负资源。 |
| 击退/拉拽 | 按推力、目标体量、稳固姿态和合法落点位移；不能穿墙或占用非法格。 |
| 屏障 | 吸收有限损伤，受容量和持续时间约束，不修改基础生命。 |
| 火墙/毒雾 | 持续区域，会伤害友军；不能把它当作只打敌人的普通范围攻击。 |
| 烟幕 | 影响视线/观测的持续区域。 |
| 治疗区域 | 对区域内合法目标施加受容量约束的治疗。 |
| 陷阱 | 对敌方触发的区域机制，不伤害友军。 |

火墙、毒雾、烟幕、治疗区域和陷阱分别单独使用，不再拼接其他效果。技能的抵抗、范围、持续和目标数量由插件计算，正文不提供执行脚本。

### 强化与示例

技能可选强度、伤害、精度、穿透、射程、治疗、持续、回能、士气，以及三通道伤害/穿透；范围、倍率和点数规则同第二条。物理技能按实际武器通道匹配；不匹配修正没有效果。正持续不会延长眩晕、沉默、缴械等硬控制，负持续可缩短但至少一次状态结算；射程、持续保留整数。增益回复与屏障仍受实际容量限制。

“新学四项技能”示例是在原技能库基础上学习，不是清空其他技能。“两战守护及诅咒”示例创建独立来源，解除 s1/s2 只撤对应来源，不能直接把所有同名效果清掉。

## 面板功能与世界书的关系

| 功能 | 与世界书的分工 |
| --- | --- |
| 发送新增战况 | 从该战报上次确认发送新增战况的事件游标继续；第一次从开头发送。发送未确认时先核对，避免重复投递。 |
| 发送完整逐轮战报 | 发送本场截至当前的全部逐轮记录，包含此前发送过的内容；不等同于新增战况。 |
| 叙述战斗终章 | 战斗结束后发送开局/结束状态、伤害来源及结果的终章材料，不替代逐轮过程。 |
| 普通 LLM 读取上下文 | 设置中选择层数，开战前读最近完成的用户/AI 消息，一条消息为一层。只选支持的指挥能力/风格、小战/会战、地形、昼夜、地图、任务；不生成武器、伤亡、骰子或战斗行动脚本。 |
| 双方指挥能力 | 新手/常规/熟练/专家/大师分别对应候选估值最大误差 18%/10%/5%/2%/0% 的尺度；哈希误差可回放，不消耗战斗骰子。不是伤害倍率，也不保证高能力每场获胜。 |
| 双方指挥风格 | 均衡不加偏好；积极进攻偏进攻，谨慎偏防守，迂回偏带攻击的机动，集中火力偏远程，伏击固守偏防御或原地进攻。偏好最多为候选最高正评分尺度的 6%，只作用于合法自动候选。 |
| 无指挥依据 | 没有可信选择的一方沿用原自动决策；只选出风格时能力默认熟练，只选出能力时风格默认均衡。 |
| 连接持久保存 | URL、Key、模型列表、所选模型独立存本机，不写入聊天或角色卡。更换聊天/删除卡不重置；清空站点数据与换设备不在此保证范围。 |
| JEV 提示 | 当前只有设置中的禁用提示“jev指挥功能(未完成，勿选)”，不参与开战或逐回合行动。 |
